# D731: A described state's title and description rows break only at a written `\n`

A state with more than one description line (v12's `rectWithTitle`: `state "…" as X` plus `X : …`) draws its title and its description rows unwrapped. Each breaks only at a written `\n`, never at `wrappingWidth`, and the box grows to the longest line. This holds in px and in cells, so the text output of described states changes too. v12 built these labels with `createLabel`, whose width is infinite.

A state with one description keeps today's wrapping.

Clarifies D564: its "plain, breaking at a written `\n`" means no wrapping at `wrappingWidth` for these labels.

(Knut, 2026-11-27, spec #1338, #1214.)
