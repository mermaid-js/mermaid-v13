# D761: `swimlane.curve` belongs to the swimlane diagram, not to the swimlane layout

`swimlane.curve` is configuration for the `swimlane-beta` diagram, not for the swimlane layout engine.

- **In a `swimlane-beta` diagram,** `swimlane.curve` wins whenever it is set, wherever it is set: front matter, a directive or `initialize()`. When it is unset, the curve is `flowchart.curve`, then the top-level `curve`, then `rounded`. Per-edge curves (`curve:` on an edge, `linkStyle … interpolate`) stay above every config key.
- **In a `flowchart` drawn with `layout: swimlane`,** `swimlane.curve` is ignored. The curve is `flowchart.curve`, then `curve`, then `rounded`.

This replaces the order C1 (#1377) first shipped on this branch. There, the `swimlane` section was layered over `flowchart` within each config source (D534), so a front-matter `flowchart.curve` beat an `initialize()` `swimlane.curve`. With nothing set, the output does not change.

Amends D733 and D760.
