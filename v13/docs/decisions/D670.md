# D670: The core budget rises to 104,448 B gz and the R-PERF-1 loaded limit to 153,600 B gz for flowchart render performance; amends D662 and D669

Two budgets in `packages/mermaid/size-budget.json` rise for 31 flowchart render-performance commits (#1056, #1057): `core` (R-PERF-8: the `mermaid` entry's static import closure on the CDN build's ESM entry, gzip level 9) from 103,680 B to 104,448 B (+768 B, 102 KiB), and `loaded` (R-PERF-1: core + flowchart as a page loads them for one flowchart render, gzip level 9) from 152,448 B to 153,600 B (+1,152 B, 150 KiB).

The commits make a flowchart render about 14% faster: a formal six-block measurement of the same commits on the round-3 base gave 13.97% against the identical-build median. Rendered output is byte-identical.

| | core, B gz | loaded, B gz |
| --- | --- | --- |
| On `mermaid-v13` at `19cc36af9` | 103,677 | 152,362 |
| #1057, merged with `19cc36af9` | +641 | +1,051 |

The core figures are `cdn-build.spec.ts`, the larger of the two measures that enforce the core budget; `core-size.spec.ts` measures 103,428 B before and 104,064 B after. The loaded figures are the bench's fetched size. Each limit is the first 128 B step that leaves at least 64 B of margin: 130 B for core, and 187 B for loaded, since 153,472 B would leave 59 B.
