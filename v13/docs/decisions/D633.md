# D633: An embedded block's body loses its common indentation before it is detected and parsed (amends D547)

D547 passed the body through as written, so syntax that is read by column broke once indented as `embedded-diagrams.md` shows: eventmodeling closes a data block only on a `}` at column 0, as v12 does (#750). The block pass removes the indentation common to the body's non-blank lines (ts-dedent's rule, as `dom.ts` `dedent`), and positions map back line by line, so errors still name the author's line and column. The language service does the same. Rejected: keeping the body raw and documenting that column-read syntax starts at column 0.

(Knut, 2026-11-19, spec #962, decision 1.)
