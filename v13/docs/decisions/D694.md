# D694: HTML labels are an optional plugin; core's guarantee covers what `render()` returns

HTML labels come back as an optional package, `@mermaid-js/plugin-html-labels`, for v12 parity. D5 (SVG-only labels) and D6 (safe by construction, no sanitizer) are unchanged: what `render()` and `renderSync()` return is inert and inside the allow-list (R-SEC-1, R-SEC-2), with the plugin registered or not.

An extension's `afterMount` hook may add DOM that is not on the allow-list to the mounted diagram, as `@mermaid-js/plugin-interactions` binds handlers there (R-PLUG-9). That content is the extension's responsibility, not core's. `plugin-html-labels` sanitizes every label with DOMPurify before it enters the DOM; the sanitizer cannot be turned off, and `href` and `src` go through the integrator's `linkSchemes`.

The plugin is also a test of the extension API: its gaps are listed in `v13/docs/plugin-api-gaps.md`.

(Knut, 2026-11-26, spec #1278.)
