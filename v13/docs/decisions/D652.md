# D652: Flowchart, sequence, class, state and ER draw the front-matter title, through one shared helper; replaces D122

A front-matter `title` is drawn above a flowchart, class, state or ER diagram as v12's `insertTitle` drew it: one `<text>` centred over the drawing, its baseline `<type>.titleTopMargin` (default 25) above the drawing's top, and the viewBox grown to hold it with the diagram's padding around it (8, or `flowchart.diagramPadding`). The text keeps v12's class: `flowchartTitleText`, `classDiagramTitleText`, `statediagramTitleText`, `erDiagramTitleText`. Its fill is `textColor`. Flowchart and state draw it at 18 px, as v12's CSS did; class and ER draw it in the root's font size, because v12 had no rule for them (class's `.classTitleText` never matched the class the renderer wrote).

Sequence draws a front-matter title where an in-text `title` goes, when the text has none; an in-text `title` wins (D218's rule).

The placement is one helper in `@mermaid-js/shared/svg/document` (`placeTitle`, `titleAt`, `titledViewBox`), which agentflow and requirement use too; their output is unchanged byte for byte. It is in that subpath, not one of its own as spec #988 planned, because a file of its own is one more chunk on the flowchart path: measured with the size report, a subpath of its own cost 505 B gzip on R-PERF-1's `core + flowchart`, and inside `svg/document` 367 B. Even so, the R-PERF-1 limit rises by 128 B for it (D653). Each type's parser copies the front-matter title onto its model as `title`, as pie, requirement and agentflow already do (D218). The four `titleTopMargin` keys are honoured in the schema.

The title is plain text: an inline tag in it is dropped and reported with `HTML_DROPPED`, as in every title (D566). It does not name the diagram: the accessible name stays `accTitle` (D133).

This replaces D122, which said state draws no title "as flowchart's doesn't". v12's flowchart does draw it, as do sequence, class, state and ER (#753). D122 left the cross-type choice for later; D218 had already made it for the M4 types.

Rejected: keeping the title undrawn and listing it as a deliberate loss per type.

(Knut, 2026-11-19, spec #988, #753.)
