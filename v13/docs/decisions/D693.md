# D693: The hand-drawn plugin gives sketched mindmap nodes v12's nodeBorder outline

With `look: handDrawn`, a mindmap node that has a fill and no stroke of its own is sketched with a `nodeBorder` outline, as v12 sketched it. This amends D307 ("sketches take the theme's paints"), which sketched only the paints the diagram writes.

v12 sketched every shaped mindmap node through `userNodeOverrides`, whose stroke falls back to `nodeBorder` when the node has no style of its own. A mindmap node never had one: its section colour came from CSS, which the sketch did not see. So every v12 sketch had a `nodeBorder` outline, though mindmap draws no outline without the look. v13's mindmap draws a node with no stroke in the themes that draw no outline (the classic families), and under D307 its sketch had none either (#1256, #1243, #1259).

The outline is the hand-drawn plugin's, not mindmap's or core's: hand-drawn behaviour stays in the plugin. The plugin's drawer adds it for an outline of role `node` in diagram `mindmap` (the `diagram` of its hook context) that has a fill and no `stroke` attribute, with the paint `theme.color('nodeBorder')` of the render, so a theme or an author's `nodeBorder` and the `--mermaid-nodeBorder` custom property reach it. It keeps v12's stroke width of 1.3. Its `postLayout` hook reads `nodeBorder` first, so the root `style` declares the alias before any outline is drawn. It does this only where the theme's `mindmapOutlinedNodes` is off; other themes and diagrams keep their output.

Not given the outline:

- The plain node (class `node-default`), which v12 did not sketch and drew without an outline (D308). The plugin finds it by mindmap's class name.
- A node with a stroke, as in the redux and neo families, which keeps its own.
- Other diagram types. A venn overlap styled with a fill and no stroke, for example, stays as it is.

The hachure keeps the section colour (D307). v12 drew its hachure in `mainBkg`, and its section colour showed only where its CSS reached the sketch's paths, which differed by shape; that is not reproduced.

Rejected: a sketch-only paint on `w.outline`, set by mindmap, which would put hand-drawn knowledge into core's outline contract and the diagram; a fallback outline for every type's filled node, which also changed venn.

(Per Brolin, 2026-11-25, #1256.)
