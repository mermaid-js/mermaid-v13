# D677: The `preprocessed` parse option is in core's `ParseOptions`

Core's `ParseOptions` (`@mermaid-js/core/parser-kit`, `packages/core/src/parser-kit/result.ts`) has the optional field `preprocessed?: PreprocessResult`: the preprocess result for the text, which the parser computes, keeping its diagnostics, when the field is absent. Every diagram type already declared this same field on its own `<Type>ParseOptions`. A diagram type's parse options inherit it from core and need not declare it again. Ticket #1100 removed the copies in info, pie, quadrant, XY chart and the shared flow parser; the other types' copies are redundant and can go in a later change. This is an addition to core's API. No parser's behaviour changes.

(Knut, 2026-11-20, spec #1096, step C-101.)
