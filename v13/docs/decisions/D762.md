# D762: An architecture service label hangs from its icon as in v12

A service's label hangs from its icon as v12 hung it with `dy="1em"`: the middle of its first line sits `fontSize` below the icon's bottom edge, `fontSize` being the theme's `fontSize`. The label's box therefore starts `fontSize − lineHeight / 2` below the icon (`labelGap` in `architectureSizes`, about 6.7 px at 16 px in the default font), and the service's box handed to the layout engine grows by the same amount, so the layout reserves the room. A service with no label is unchanged. Until now the label's box started at the icon's bottom edge, so glyphs that rise above the Latin ascent, such as colour emoji, touched the icon (#1210).

This amends the migration row that cites D501 ("a few px higher"), which now says the label hangs as in v12. D501 itself is unchanged.

(Knut, 2026-11-27, spec #1336 T1, #1210.)
