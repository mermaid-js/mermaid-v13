# D644: The table measurer has a Courier New table, and the monospace names map to it

The table measurer has a fourth table, Courier New, regular and bold, generated by `tools/gen-metrics` from the font files like the other three (`FACES` in `packages/core/src/text/metrics.ts`). Every Courier New advance in the table's ranges is 600/1000 em, and its hhea metrics are ascent 833, descent 300, line gap 0.

These family names are measured with the Courier New table: `courier`, `monospace` and `ui-monospace`, and the monospace fonts whose advance, read from their font files, is within 1% of 600/1000 em: Andale Mono, Liberation Mono, Monaco and PT Mono (600), and DejaVu Sans Mono and Menlo (602). As before, the first family in the stack that has a table or an alias wins, so `Consolas, monospace` is measured as Courier New. A name with neither still falls back to Arial. The candidates that were measured and left out are listed in the PR.

This amends DESIGN §5.2 and D17's table measurer, which had tables for Trebuchet MS, Verdana and Arial only, so every monospace family was measured as Arial, about 25% narrower than the Courier it is drawn in (#759). It changes Node and worker renders, the CLI, `deterministic: true`, unit tests and the visual baselines; the browser default, the canvas measurer, already measured the font that is drawn.

(Knut, 2026-11-19, spec #1000, #759.)
