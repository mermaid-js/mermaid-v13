# D695: `ExtensionPlugin.label` is a whole-label provider

An extension can lay out a whole label: `label.box(raw, request, ctx)` returns an `InlineBox` or declines with `undefined`, and core then lays the label out as usual. Label layout asks the registered providers, in registration order, before it looks for inline spans (D177, D293); the first box wins and the label is that one box. Text output never asks (D179).

The request is the inline request with the label's wrap width (`maxWidth`) and its `markup` mode (D562). `ctx` is the render's hook context, as the outline drawer gets it (D655), so a provider reads the config and shares `ctx.state` with its `afterMount` hook without a `postParse` hook or module state. The box's node is checked against the allow-list like any inline box.

`RenderContext.deterministic` is true when the integrator asked for a deterministic render, so a provider that measures with the DOM declines.

Core may grow by about 1 KB for this at most.

(Knut, 2026-11-26, spec #1278.)
