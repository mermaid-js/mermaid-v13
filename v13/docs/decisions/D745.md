# D745: Wardley warns about an `evolve` of a pipeline component under its own code

An `evolve` that names a pipeline component by its name (`evolve c` for `component c` inside `pipeline P { … }`) is still skipped, as v12 skipped it: v12 finds a pipeline component by its id, `P_c`, only. It now raises the warning `WARDLEY_EVOLVE_PIPELINE_COMPONENT`, which names the pipeline:

> `c` is a pipeline component of `P`; pipeline components cannot evolve.

Before, it raised `WARDLEY_UNKNOWN_TARGET` (D425), whose message said that `c` names no anchor or component, which was wrong (#1273). With a code of its own, an author or a tool can filter this case apart from a misspelt name. When the name is a component of several pipelines, the message names the first.

`WARDLEY_UNKNOWN_TARGET` keeps its message for a name that matches nothing, without the closing "(a pipeline component cannot evolve)".

Two smaller points come with it:

- A dropped link written without an arrow (`click A href "https://example.com"`, which v12 and v13 both read as a link from `click A href` to `https://example.com`) is quoted in `WARDLEY_LINK_DROPPED` as written, not as `from -> to`.
- The drawing does not change. Both warnings are reported as before: once per kind, with the other places in `related`.

Amends D425.
