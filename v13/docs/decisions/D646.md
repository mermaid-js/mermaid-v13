# D646: A zero-width space stays in the drawn text

A zero-width space (U+200B) in a label is kept in the drawn text and in the label's text runs, in every diagram type. It is still a break opportunity when the label wraps (R-TEXT-8). A line that breaks at one ends with it, and a label that does not break keeps it where the author wrote it. The table measurer gives it no width, so nothing visible changes. Copy-paste and search keep the author's text, as in v12.

Before this, core's label layout (`core/src/text/label.ts`) used it as a break hint and then removed it, so `a<U+200B>b` drew `ab`. No decision chose that.

The soft hyphen (U+00AD) keeps its handling: a `-` at a line break, nothing otherwise.

Rejected: keep removing it and record the difference in MIGRATION. It changes the text the author wrote, for no visible gain.

(Knut, 2026-11-19, spec #996, #774.)
