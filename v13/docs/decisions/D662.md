# D662: The core budget rises from 103,424 B to 103,680 B gz (+256 B) for font tables; amends D625

The `core` budget in `packages/mermaid/size-budget.json` (R-PERF-8: the `mermaid` entry's static import closure on the CDN build's ESM entry, gzip level 9) rises by 256 B, from 103,424 B to 103,680 B, for integrator font tables (#1000 T2, D645, #1046).

On `mermaid-v13` at `7bba09d3e`, after #650's fix (#1050, D660), `cdn-build.spec.ts` measures core at 103,274 B, 150 B under the old limit. #1046 adds 272 B to it (103,546 B), 122 B over. The font tables' check, hash and measurer factory already load in a chunk of their own (`@mermaid-js/core/text/font-tables`, D645); what stays in core is the lookup every table measurer shares, the label-layout slice marker, and the code in `mermaid` that notices `fontTables`, loads the chunk and keys on the tables. Trimming that further saved about 8 B. The 256 B leave 134 B of headroom.

REQUIREMENTS R-PERF-8 and DESIGN's size table, which still said 100 KB, now give the limit in bytes.

As D546, D599 and D625 did, the raise is a decision, not a gate loosened to make a change pass. Rejected: holding #1046 back until core has room.

(Knut, 2026-11-19, spec #1000, #1046.)
