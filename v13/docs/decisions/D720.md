# D720: Compass honours a second compatible side, and a detour never leaves a run on a node

`compass` placed each node from the first link that reached it and never looked at the others. It now also honours a second link when both can hold. A link holds when its far end lies past the side the link names, and its own end past its own side: `a:R -- L:b` holds when `b` is right of `a`, whether or not the two are in line. When a link puts a node in a cell and a link from another placed node does not hold there, the node moves the way that link asks, to the nearest free cells that way. The move is kept only if every placed link into the node holds at the new place. Otherwise the first link's place stays, with no warning. `align` hints are kept as written. A second link between the same two nodes does not move a node, since it is drawn as a route of its own.

A group is placed whole, so the first link into it used to fix where its members sat relative to the rest (D326's known gap). When one outside node reaches two members of a group through two sides, those members are now linked to each other in the places the two sides ask for. These links are followed after every edge, so the group is built the way both sides can hold. In the nested Azure fixture (#1218), `web:B --> T:pe2` and `vm1:R --> L:pe2` both hold: PE Bus sits below Web App and right of VM, and the VM line crosses no service.

A route with two or more bends keeps every run off the nodes it does not end on (#767 covered only the runs between two bends). A run that crosses a node slides across its direction past that node, and on past any other node the slide lands on. An end run slides from a stub out of its port, where the route gains an elbow. The run on either side stretches with it; if that run now crosses a node, it slides too. The slide is kept only if all three runs are clear and keep their direction. Otherwise the run stays where it was. A route with at most one bend keeps v12's look (D507).

Refines D326 ("ported as is") and D507. The layout stays deterministic. A diagram whose links all hold, and whose detours were already clear, is laid out as before.

(Knut, 2026-11-26, spec #1335, decision 4.)
