# D741: Kanban columns lighten under `theme: dark`, as in v12

Under the classic family's dark theme (`dark`), kanban's column fills are `lightenHsl(cScale<n>, 10%)`, as v12's `adjuster` gave them: v12's `dark` theme never set `darkMode`, so its kanban lightened. v13 had darkened them on the theme's `dark` trait (D374), which made the columns of `theme: dark` near black (#1299).

The rule is a `families.classic.dark` entry in kanban's theme table (`packages/diagram-kanban/src/theme/table.ts`). Core applies family entries after the table's dark rules, so no file in core changes. The table's `rules.dark` (darken) stays:

- a light classic theme with `themeVariables.darkMode: true` still darkens, as in v12;
- `neo-dark`, `redux-dark` and `redux-dark-color` keep D374's darkening, a listed theme difference from v12, which lightened them.

`theme: dark` with `themeVariables.darkMode: true` lightens, where v12 darkened. The family entry follows the theme, not the author's `darkMode`. This is a listed divergence (`packages/conformance/divergences/kanban.json`, `v13/docs/migration/220-kanban.md`).

`packages/conformance/src/kanban/theme.spec.ts` checks every column fill against v12 12.2.0's kanban style sheet in all eleven themes.

Amends D374.

(Knut, 2026-11-27, spec #1339 T3, #1299.)
