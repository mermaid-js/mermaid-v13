# D671: The core budget rises to 104,960 B gz and the R-PERF-1 loaded limit to 154,240 B gz for the lean parse mode; amends D670

Two budgets in `packages/mermaid/size-budget.json` rise for the lean parse mode in the parser kit, the pipeline and the API (#839, #840): `core` (R-PERF-8: the `mermaid` entry's static import closure on the CDN build's ESM entry, gzip level 9) from 104,448 B to 104,960 B (+512 B, 102.5 KiB), and `loaded` (R-PERF-1: core + flowchart as a page loads them for one flowchart render, gzip level 9) from 153,600 B to 154,240 B (+640 B, 150.625 KiB).

The lean parse keeps no AST, symbols or statement spans in the analysis cache: memory per cached flowchart analysis falls by 63%. Rendered output is byte-identical over every type's fixtures.

The loaded figures are the bench's fetched size in CI. Each limit is the first 128 B step that leaves at least 64 B of margin: 92 B for core, and 180 B for loaded, since 154,112 B would leave 52 B.
