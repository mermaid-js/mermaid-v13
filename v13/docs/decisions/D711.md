# D711: Timeline draws its label tags

Timeline labels (sections, periods, events and the title) follow the label rule of D710:

- A label wholly in backticks, with or without double quotes, is a markdown string: it is laid out as Markdown without its wrapper.
- Any other label is plain. `<br>` breaks the line, `<b>`/`<strong>`, `<i>`/`<em>`, `<u>`/`<ins>`, `<s>`/`<strike>`/`<del>`, `<sub>` and `<sup>` draw their formatting without the tags, and character references decode. Any other HTML tag is dropped with its text kept and one `HTML_DROPPED` warning (D566). Markdown syntax without backticks (`**x**`) stays as written, and text such as `List<T>`, which is not a tag, stays text.

This amends spec #291 and D225 for timeline. Spec #291 escaped every `<` but `<br>` before core's label layout, so that `<b>` and `<i>` showed as written, as v12 drew its labels with d3's `.text()`. v13 now draws them. Markdown strings, which D225 listed for timeline, were drawn with their backticks until now; they render. Both are deliberate differences from v12, listed in MIGRATION.md. A label with no tag and no markdown string is laid out and drawn as before, byte for byte. A tag escaped by its author (`#lt;b#gt;` or `&lt;b&gt;`) still shows as written.

(Knut, 2026-11-26, spec #1333, ticket T6, part of #1230.)
