# D687: Agentflow with no curve set draws the default curve

Agentflow draws its edges the way flowchart does when no curve is set: with no `flowchart.curve` and no `linkStyle default interpolate`, the edges are drawn with the default curve, `rounded` today, not with S-curves. The value is `DEFAULT_CURVE` from `@mermaid-js/shared/svg/route` (D681), which a diagram-flowchart spec pins to the schema default of `flowchart.curve`, and which class and requirement also take when the key is unset. There is no second literal in agentflow. Explicit curves keep their order: a per-edge `interpolate`, then `linkStyle default interpolate`, then `flowchart.curve`. As in flowchart, the diagram's curve also picks the routing, so `rounded` routes edges in steps and nodes and labels can move; a per-edge curve is drawn through those points.

This is a divergence from v12, whose agentflow read `flowchart.curve` from the global config and so drew `basis` S-curves, v12's default. Set `flowchart.curve: basis` to keep them.

(Knut, 2026-11-23, spec #1163, decision 11, #1181.)
