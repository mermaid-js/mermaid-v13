# D657: Gantt's rules read `mainBkg` where they read `primaryColor`, so an override of `primaryColor` leaves the bars alone in the named classic themes; within D574

D574 keeps gantt on the shared derivation and rules out v12's per-theme gantt colours (D331). Under that derivation the task bars, the active bar and the alternate section band read `primaryColor`, so an author's `primaryColor` recolours them in every theme (#838), where v12's `default`, `forest`, `neutral` and `dark` keep their own.

Gantt's rules read `mainBkg` in those places instead. With no override nothing moves: D570 pins `mainBkg` to the value each of the four themes gives `primaryColor`. Under an override the bars stay, as in v12. In `base`, `mainBkg` derives from `primaryColor`, so the bars still follow it, as v12's do. Gantt's colours with no override still differ from v12, as D574 decided.

Rejected: keeping the rules and adding a MIGRATION row for the override case.

(Knut, 2026-11-19, spec #1035.)
