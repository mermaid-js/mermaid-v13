# D653: The R-PERF-1 loaded limit rises from 151,552 B to 151,680 B gz (+128 B); amends D651

The `loaded` budget in `packages/mermaid/size-budget.json` (core + flowchart as a page loads them for one flowchart render, gzip level 9) rises by 128 B, from 151,552 B to 151,680 B, for the front-matter title (#753, D652).

On `mermaid-v13` at `3b227943f` the gate fetched 151,198 B (147.7 KB). Drawing the front-matter title costs 365 B on that path, measured with the size report's static stand-in (152,452 B before, 152,817 B after), so about 151,563 B: 11 B over the old limit. The 128 B leave about 115 B of margin for the difference between the static and the fetched measurement. The title helper already sits in `@mermaid-js/shared/svg/document` rather than a file of its own, which would have cost 505 B to 591 B (D652).

Knut allowed up to 250 B for spec #988 (2026-11-19). This raise does not make room for #650's fix (about +530 B, spec #995), which needs its own decision.

As D546, D625, D600 and D651 did, the raise is a decision, not a gate loosened to make a change pass. Rejected: holding the front-matter title back until the flowchart path is smaller.

(Knut, 2026-11-19, spec #988, #753.)
