# D641: Correction to D372: v12 also broke a kanban label at a raw line break

D372 said that a raw line break inside a quoted kanban label breaks the line in v13, "where v12's HTML folded it to a space". v12 did not fold it. Its kanban labels are markdown (`labelType: 'markdown'`), and v12's `markdownToHTML` turns each line break in the text into a `<br/>`, so `c["A quoted label` / `with a line break"]` draws two lines in v12, as in v13. Only the recorded reason was wrong; the behaviour is the same in both. The rest of D372 stands.
