# D636: Decisions are one file each

A decision is a file in `v13/docs/decisions/`, named after its id (`D636.md`), with the heading `# D<n>: <title>`. `v13/docs/DECISIONS.md` is closed at D632 and gets no new rows; its rows stay valid and are cited as before. There is no index file: a generated list would be one more file that every such PR changes.

The reason is merge conflicts. Each PR that recorded a decision added a row to the same table, so any two of them conflicted; the file was changed in 204 commits between 2026-11-02 and 2026-11-19. Two PRs that add two files do not conflict, and two that take the same id conflict on that one file, where before the clash was silent.

The existing rows are not split into files. `DECISIONS.md` is a document of some fifty sections with prose between its tables, and nothing is gained by rewriting it.

(Knut, 2026-11-19.)
