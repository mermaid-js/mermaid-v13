# D634: `securityLevel: 'loose'` raises no `SECURITY_LEVEL` warning (amends D554)

Since D554, `loose` is the setting that turns click callbacks on, and MIGRATION tells integrators to set it, so a warning on every render that calls it unsupported was wrong (#749). `loose` still acts as `default` for link URLs (D48, D75). `antiscript`, `sandbox` and unknown values keep the warning. Rejected: a warning with new text.

(Knut, 2026-11-19, spec #962, decision 2.)
