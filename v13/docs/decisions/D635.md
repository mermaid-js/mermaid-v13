# D635: c4-beta `style` colours take the CSS forms flowchart `style` takes (amends spec #730's `HEX`)

A hex colour has 3, 4, 6 or 8 digits, and `rgb()`, `rgba()`, `hsl()` and `hsla()` are one value. A bare word that is not a CSS colour name is dropped with `C4_COLOR_INVALID` and the element keeps its theme colour; a value the lexer still cannot read drops its `style` line with a warning instead of failing the diagram (#929). Legacy C4's `UpdateElementStyle` values are unchanged. Rejected: keeping 3 and 6 digits and only improving the message.

(Knut, 2026-11-19, spec #962, decision 3.)
