# D673: The parser kit exports `cut` and `markDroppedSemicolons` from the source view

`@mermaid-js/core/parser-kit` exports two of the source view's helpers (`source-view.ts`, D114) that were private: `cut`, which gives the text of a source without its removed spans and the runs that map it back, and `markDroppedSemicolons`, which marks the `;`s v12's `encodeEntities` dropped from `style` and `classDef` lines.

Agentflow builds its own source view, because v12 parsed agentflow with its comments kept, and kept line-for-line copies of both helpers. It now imports them, so the semicolon rule exists once (audit finding diagram-agentflow-01, ticket #1086, spec #1085). Core's `sourceView` is unchanged, and so is what both views return.

(Knut, 2026-11-20, spec #1085.)
