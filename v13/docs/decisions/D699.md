# D699: A label has an optional role, which a whole-label provider gets

`LabelOptions.role` says what a label names in its diagram: `'node'`, `'edge'` (a relation between nodes) or `'group'` (a container of nodes). Label layout passes it to a whole-label provider as `LabelRequest.role` (D695). Core itself lays every role out the same way.

The role is optional, and `undefined` says nothing about the label, so diagram types adopt it one at a time. Flowchart sets it for its vertex, edge and subgraph labels. The other types follow when they are next touched; class, state, ER and requirement first, since v12 drew HTML labels there.

`@mermaid-js/plugin-html-labels` gives the label's wrapper the class v12 gave it: `nodeLabel` for a node's label and a group's, `edgeLabel` for an edge's. A label with no role has only `html-label`.

Core and flowchart grow by about 27 B gzipped together for this.
