# D705: A directive above the front matter still applies, and wins over it

A `%%{…}%%` directive on a line before the opening `---` (D704) is read as if it were below the front matter. `preprocess` finds directives before the fence and after the closing fence, never inside the YAML, and lists them in source order.

The config order does not change: the front matter's `config` is merged first, then the directives in source order (`packages/mermaid/src/prepare.ts`). So a key set in both takes the directive's value, wherever the directive is written. This is v12's order: v12 merges the front-matter config and then the directives (`cleanAndMerge(frontMatterResult.config, directiveResult.directive)`), and v12 reads directives over the whole text, so a directive above the fence applied in v12 too.

(Knut, 2026-11-26, spec #1331, #1204.)
