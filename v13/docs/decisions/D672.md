# D672: Line hops are on by default and part of core; replaces D537's default and its lazy chunk

The shared `lineHops` key defaults to `true` (D537, a row in `DECISIONS.md`, had `false`). Where two straight edge runs cross, the one that gives way draws a 6px arc, in every diagram that draws edges and under every layout, unless a config layer sets `lineHops: false`. This follows mermaid-js/mermaid#8835 (#1060): v12 hops under ELK, which was its default layout in 12.2.0, and release 12.4.0 turns hops on for its `layered` layout too.

The hop step moves into core. D537 (as amended, "Lazy chunk for hops") kept it in a lazy chunk that `mermaid` loaded as the lazy layout `lineHops` when the key was on, and `renderSync` without it threw `NotLoadedError`. With hops on by default that would make every `renderSync` caller preload the chunk first. So `mermaid` imports `@mermaid-js/core/layout/hops` statically, `renderSync` draws hops with nothing to preload, and `lineHops` is no longer a lazy layout name: `preload({ layouts: ['lineHops'] })` still resolves and loads nothing, and the `swimlane` and ELK engine modules no longer carry the step.

The rest of D537 stands: one shared key that every edge-drawing diagram reads through the shared edge-path step, the rules (D650 included), and the precedence, with `true` as the last step: a top-level `lineHops: false` the author set, the engine's key the author set, the top-level key the author set, the engine's default, the shared default.

No budget changes. Hops add 1,850 B gz to core (`cdn-build.spec.ts`), which D671's limits hold.

63 fixtures draw differently: 38 flowchart, 11 class, 6 C4, 4 event modeling and 4 architecture. 14 of them are in the tiers photographed on every push (`pr-check`, `baseline`).

Rejected: keeping the lazy chunk, with `renderSync` throwing until it is preloaded or drawing plain crossings without it (sync and async output would differ); and a default for flowchart alone, which needs the per-diagram key D537 chose not to have.

(Knut, 2026-11-20, #1060.)
