# D639: State's start dot, transitions, outlines and arrowheads stay on the shared variables

In the classic themes v12 drew some state colours from per-theme literals: `neutral` set `transitionColor` and `stateBorder` to `#000` and `specialStateColor` to `#222`, `dark` left `specialStateColor` unset (`#f4f4f4` rendered), and `forest` and `neutral` drew black state arrowheads. v13 keeps drawing them from `lineColor`, `arrowheadColor` and `nodeBorder` in every theme, as MIGRATION "State" describes (#827).

A state theme table cannot reproduce them: D331 keys a table by family and dark, and `neutral` shares both with `default` and `forest`. Rejected: generic shared inputs that the three themes write (D332's route). D332 allows one only when it means something to more than one diagram, and these mean something to state only.

(Knut, 2026-11-19, spec #975, decision 1.)
