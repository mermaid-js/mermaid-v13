# D714: The class edge-label tag reads `edgeLabelBackground` and gets `classEdgeLabelColor`

The class diagram's relation-label tag is filled with the shared `edgeLabelBackground` (default `background`, D628), as flowchart and state already are, instead of a fill hard-coded to `background`. An author can now recolour the tag without recolouring the canvas. A class-only fill variable was not chosen.

Class gains one theme variable for the tag's text, `classEdgeLabelColor`: `contrast(edgeLabelBackground, classText, contrast(edgeLabelBackground, #000000, #ffffff))` (D713). With no overrides it equals `classText` in every built-in theme. Multiplicities keep `classText`, since they sit on the canvas, not on the tag.

D626 forbids new config keys and style properties, not theme variables. Unlike D572, which kept ER from adding a variable for the same case, this one adds it.
