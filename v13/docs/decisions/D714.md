# D714: The C4 relation-label tag follows the edge-label pattern, and `c4RelationColor` defaults to `textColor`

C4's relation-label tag no longer hard-codes its fill to `background`: it reads `c4EdgeLabelBackground` and `c4EdgeLabelColor` (D715). `c4RelationColor` takes its default from `textColor` in every theme; the dark themes' `c4RelationColor: lineColor` rule is gone. It now colours the relation lines only, not the label text. A colour set with `UpdateRelStyle` (`textColor`, `lineColor`) still wins as written (D713).

(Knut, 2026-11-26, spec #1334, #1351.)
