## Renderer

- Structure as the spec: `g.sections > g.cluster.section-<k>[ classes]` (`rect`, `g.cluster-label`), `g.items > g.node[ classes]` (`rect.basic.label-container`, `line.kanban-priority`, `g.label` ×3, the ticket's inside `a.kanban-ticket-link`). `data-id` = `data-ast` = item AST id on columns and cards only; no element id. viewBox = `layout.bounds`; `kanban.useMaxWidth`. Root font from `layout.font` (theme variables when it is the theme font).
- Theme table: `kanbanColumn0`–`11` (aliases `kbc0`–`kbc11`), `rules.light` `lightenHsl(cScale<n>, 10%)`, `rules.dark` `darkenHsl(cScale<n>, 10%)`; column k uses slot `(k + 1) mod 12` (`render/slots.ts`). Cards `background`/`nodeBorder`, labels `textColor` (core `usedBy` gains `kanban` for the three).
- Links: `render/links.ts` `ticketUrl` (first `#TICKET#`, function replacer, `checkUrl` with `securityLevel`/`linkSchemes`); the writer adds `rel`. `priorityWarning`: one `KANBAN_PRIORITY` per render, values in board order, `astIds` of the cards; `priorityKind: 'other'` always named; column priorities ignored (D376).
- Hand-drawn: columns `w.outline('group', 'rect')`, cards `w.outline('node', 'rect')`; the bar is a plain `line`.
