## Exports (`@mermaid-js/diagram-kanban`)

- `parseKanban(src, { preprocessed?, keepTokens? })` → `ParseResult<KanbanModel, KanbanDocument>`; never throws. `detectKanban(src)` (v12's case-sensitive `/^\s*kanban/` after front matter and directives, no `\b`; for T5).
- `KanbanModel` (`src/model.ts`; `kanbanBoardOrder(model)` lists each column, then its cards): `items` in source order, each `{ ast, id, label, level, isColumn, column, parentId?, ticket?, assigned?, priority?, priorityKind?, icon?, classes }`; `columns: { item, cards }[]` (indexes into `items`, cards by position, D373); `warnings`. `level` is the raw indent (tabs count 1), `column` the column ordinal (its own for a column). Labels raw (entities as `&…;`, line breaks kept, `<br/>` from quoted data); every label is markdown. `priorityKind: 'text'` for a YAML string, `'other'` with the value's YAML text as written (`[1, 2]`, `true`) for D375's warning. `icon` is the last of `@{ icon }` / `::icon()` (not drawn, D376).
- AST (`src/parser/ast.ts`), flat in source order: `Item` (`n:<id>`, `n:<id>@k`; id trimmed, an id-less item's text), fields `nodeId?`, `text` (shape text before `label:`), `indent`, `data?: { text, range }` (YAML text as v12 read it; back-to-back blocks one), `decorations`. Statement spans: `header`, `column` (block to its last card/decoration, for T6 folding) holding `card`, `icon`, `class`.
- Errors: `UNEXPECTED`, `UNCLOSED_SHAPE`, `UNCLOSED_STRING`, `UNCLOSED_ICON`, `UNCLOSED_SHAPE_DATA`; semantic (parse goes on): `KANBAN_ITEM_WITHOUT_COLUMN` (at the shallow item, `related` at the next item, v12's message then a hint), `KANBAN_DECORATION_BEFORE_ITEM`, `SHAPE_DATA` (bad YAML; exact range when read in place, else the block), `KANBAN_DATA_EMPTY` (empty or `null` data), `KANBAN_SHAPE` (upper case, `_`, or a non-string). An item failing inside its shape or data is still added (one error, one diagnostic). A `}` in a shape's text (v12's `<NODE>.+`) gives one diagnostic over all the text it took in, saying how far it ran. Diagnostics are sorted by position.
