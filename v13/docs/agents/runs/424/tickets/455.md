## Exports (`src/layout/index.ts`; T4 wires them into the plugin)

- `layoutKanban(input: KanbanLayoutInput, ctx: KanbanLayoutContext): KanbanLayout`. `ctx` is `Pick<RenderContext, 'config' | 'measurer' | 'units' | 'theme' | 'warn'>` plus an optional `inline`. It reads `config.kanban.{sectionWidth, padding}`, the theme's `fontFamily` and `fontSize`, and lays out in `ctx.units` (px, or cells for T7: rerun it with `cellMeasurer` and `cellProfile()`, as `diagram-sequence/src/ascii.ts` does).
- `KanbanLayoutInput` (`input.ts`) is a narrow input: `columns[]` in source order, each `{ ast, title, cards[] }`, each card `{ ast, title, ticket?, assigned?, priority? }`. **After T2 merges, an adapter from `KanbanModel` is all that is needed**: column items → `{ ast, title: label }`, `cards` by position (D373), `ticket`/`assigned` as strings, and `priority` only when it is a string (pass none for `priorityKind: 'other'`).
- `KanbanLayout` (`types.ts`, plain data): `columns[]` (`Rect`, `ast`, `slot` = column number from 1, v12's `section-<slot>`, `title?`), `cards[]` flat, column by column (`Rect`, `ast`, `column`, `index`, `title?`, `ticket?`, `assignee?` as `PlacedLabel { x, y, width, height, text: MeasuredLabel }`, `bar?` `{ x (centre), y1, y2, width, priority }`), and `font` (the `FontKey` every label was measured in: draw in it, pitfall 16), `sectionWidth`, `titleRow`, `radius`, `stroke`, `bounds`, `units`. A label with no text is left out.
- `kanbanLayoutViolations(input, layout): string[]`: the invariants. `KANBAN_METRICS` (the one metrics table, px, converted along `METRIC_AXIS`), `MIN_SECTION_WIDTH` (26 px) and `KANBAN_CONFIG_IGNORED`.

## Geometry

- v12's coordinates are kept: column k (from 1) centred at `W·k + 5(k − 1)`, all tops at `−1.5 W`. Everything else as the spec's Layout section. Card ticket and assignee also wrap at `W − 25` (v12 `options.width`, 01 §3).
- The bar is drawn only for `Very High`, `High`, `Low`, `Very Low`, matched exactly (D375). The `KANBAN_PRIORITY` warning is left to T4, so a rerun for ascii does not warn twice.
- Bounds: everything drawn (columns and cards with half their 1 px outline, every label, bars), `kanban.padding` (default 8) around it. An empty board is `(−8, −8, 16 × 16)`.
- **Checked on v12 renders** (mermaid@12.2.0 in headless Chromium, via `packages/bench`'s `mermaid-v12-frozen` dist and Playwright, reading `rect` and `g.label` attributes). A card without metadata is `title + 20` (44 for one line): the empty ticket and assignee labels measure 0 high, so `a = 0`. With a ticket and assignee it is 56, a three-line title 92, the column 237, an empty column 50. A 72 px column title made every column's title row 72 (heights 126, 126, 97). `sectionWidth: 0` gave W = 200. The specs pin these numbers (`layout.spec.ts`, top comments).

## Tests

Invariants (including no negative box size) on every fixture × {fixture config, `sectionWidth: 80, padding: 0`, `sectionWidth: 10`}, with `tableMeasurer` and in cells. Deep and misplaced indents are their T2 result: cards of the last column.
