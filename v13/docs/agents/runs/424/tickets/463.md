## Parser changes (T2's output)

- **Symbols:** each item id a `node` `def` (range without the blanks around it; a range the source does not read as the id keeps the token's, which the service drops); each word of a `:::` line a `class` `ref` (mindmap's word pairing, `parser/symbols.ts`); each `assigned` value v12 keeps an `assignee` occurrence at its YAML tree value range, mapped to the source through v12's CRLF/CR normalisation, the first of a name `def`, the rest `ref` (journey's actors); an unplaceable one gets the block range and its rename is refused on every card (GAPS #463). Data is read once in the YAML editor mode (the default mode again on an error). Id-less items have none.
- **Diagnostics:** an `UNEXPECTED` range is now the token its message names, not the indent before it.
- **Folding:** a column's span now runs to the line before the next column (blank and comment lines included), the last to the end of the text. Cards with multi-line data fold too.
- **Probe** (R-LANG-7): `ProbeCursor`; the lexer records its jison start condition (`INITIAL`, `NODE`, `NSTR`, `NSTR2`, `ICON`, `CLASS`, `SHAPE_DATA`, `SHAPE_DATA_STR`). Expected: `Kanban` before the header, statement starts after each separator, shape and `@{` after an id, `@{` after a shape, text and closer in a shape. After the v12 blank-line error the probe freezes on that line.
