Branch `feature/388_mindmap-renderer`. Adds `packages/diagram-mindmap/src/render/`, three core theme flags, and a verbatim copy of gitGraph's git palettes. No plugin export or manifest (T5).

## Exports (`@mermaid-js/diagram-mindmap`)
- `renderMindmap(model, layout, ctx, w)`; `ctx: MindmapRenderContext` = `Pick<RenderContext, 'config' | 'theme' | 'idPrefix' | 'version' | 'warn'>` + optional `inline`. T5: `render: (m, l, ctx, w) => renderMindmap(m, l, ctx, w)`. `ICON_NOT_RENDERED`.
- Reads `mindmap.useMaxWidth` (default true) and the theme only. Root `svg.mermaid.mermaid-mindmap`, `aria-roledescription="mindmap"`, no title/desc (v12's grammar has none), no ids but the gradient's.
- Structure: `g.mindmap-edges` (each `path.edge.section-edge-<n>.edge-depth-<parent.level+1>[data-id=edge:<child ast>]`) under `g.mindmap-nodes` (each `g.mindmap-node.section-<n>` / `.section-root.section--1` + author classes, `data-id` = `data-ast` = AST id; inside: the outline `.node-bkg.node-<shape>`, `line.node-line-<n>` under a plain node, `text.mindmap-icon`, `text.mindmap-node-label`). Absolute coordinates, no transforms.
- Every outline and edge goes through one call of `w.outline` (`render/shapes.ts` `nodeOutline`, `render/edges.ts` `drawEdge`, the rule as `divider`), paint on the call.
- `MindmapNodeView.shape` is now the shape drawn (plain → `rounded` under `mindmapRoundedNodes`); `MindmapIconSlot` gains `text` (the reference as written, fitted to the 40 px glyph square) and `size`. #328 draws the glyph through `ctx.icon` instead of `text`.
