- Language (#389's list): unlisted-facet row and conformance eager row removed; `LEZER_HIGHLIGHTERS` / `MONARCH_HIGHLIGHTERS` rows and generated files (each adapter's `gen`); `adapters-agree`, both highlighter specs, keyword completion, both first-paint e2e specs cover mindmap.
