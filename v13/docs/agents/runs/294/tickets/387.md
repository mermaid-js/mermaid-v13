# #387 T3: layout (builder, shape sizing, icon slot)

Branch `feature/387_mindmap-layout`. Adds `packages/diagram-mindmap/src/layout/` and the `./testing` subpath.

## Exports (`@mermaid-js/diagram-mindmap`)
- `layoutMindmap(model, ctx): MindmapLayout` — `prepareMindmap` then `ctx.layout(graph)` only (no bundled engine). `MindmapLayout` = the engine's `LayoutModel` + `mindmap: MindmapPrepared`. `ctx` is `MindmapLayoutContext` (a `RenderContext` pick: config, measurer, units, theme, layout, warn, inline).
- `MindmapPrepared { graph, nodes: MindmapNodeView[], edges: MindmapEdgeView[] }`, both in model order. Layout node id = the node's AST id; edge id `<parent ast>~<child ast>`.
- `MindmapNodeView`: `index` (into `model.nodes`), `shape`, `label` (MeasuredLabel), `width`/`height` (layout box), `frame { dx, dy, width, height }` (v12's `w` × `h`, offset from the box centre; a circle's is its diameter), `labelAt` (label centre from the frame centre), `point` (hexagon `h/4`), `outline` (cloud/bang arcs, frame-centred), `icon { at, slot, glyph }` (D297 slot centre from the frame centre, 50 square, 40 glyph).
- `cloudOutline(w, h)`, `bangOutline(w, h)`: v12's paths as absolute `A` arcs (`Outline`), for T4 to draw with `w.path().arcTo(...)`. `MINDMAP_CONFIG_IGNORED`.

## How to use (T4, T5)
- `plugin.layout = layoutMindmap`; `layoutKind: 'graph'`, `layoutEngine` per #380. Render each node at its model centre + `frame.dx/dy`; the label at frame centre + `labelAt`.
- Section, classes and the icon reference come from `model.nodes[view.index]`.
- Family sizes (D288, neo geometry) must be read in `prepare.ts` `frameOf` (GAPS #387 "For #388").
- `mindmap.padding` → shape padding (default, circle, cloud, bang; hexagon ×2) and `diagramPadding`; `maxNodeWidth` wraps every shape. Config defaults live in `layout/metrics.ts` until T5's generated `config-defaults.ts`.
