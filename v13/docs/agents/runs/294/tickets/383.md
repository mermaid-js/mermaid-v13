## Exports (`@mermaid-js/diagram-mindmap`)

- Internal for #386: `lex(src, bodyStart, view)` in `src/parser/lexer.ts` returns the full `TokenStream` (trivia included, ends in `Kind.EOF`); build `view` with `sourceView(src, pre.bodyStart, directives)` as `parser/index.ts` does. No probe argument yet (T6 adds the lexer mode, as timeline's #318 did).

## Token facts the parser needs (all v12's, oracle-checked)

- Images are raw: `SpaceList` is the indent (`$1.length` is the level; tabs count 1); `NodeDescr` keeps line breaks and blanks (`root(\n  The root\n)` → `"\n  The root\n"`); in a string it is the inside only.
- `SpaceLine` is either `\s*%%.*` (a mid-line or bare `%%` v12 kept, with the blanks and line breaks before it) or `[\s]+[\n]` up to the last LF of a blank run; the trailing indent after it is a separate `SpaceList`. A lone LF is `NL`; `\n\n` is `SpaceLine`.
- `NodeId` holds blanks, `:`, `%`, `]`, quotes: `a:::b` and `a %% c` are one id each (GAPS #383). `mindmap` is a keyword wherever a token starts (`  mindmap` as a child is `SpaceList Mindmap`), word-bounded (`mindmapx` is an id).
- Openers `-)`, `(-`, `))`, `)`, `((`, `{{`, `(`, `[`; closers `))`, `)`, `]`, `}}`, `(-`, `-)`, `((`, `(`. An id may end in `-` (`k-)l(-` is `NodeId "k-"`, `)`). A `}` in a shape takes the rest of its line as `NodeDescr`.
- `Eof` only when the text ends in INITIAL; inside a shape, string or icon the stream just ends (jison `$end`).
- `Kind.Error` (one character, lexing continues in the same state) where jison throws: `{` (not `{{`) or `}` outside a shape, a lone backtick or quote in a markdown string, U+2028/U+2029 right after `:::`.
