## Parser changes (T2's output)

- **Symbols (D289):** each node id is a `node` `def`, its range the id without the blanks around it (an id cut by a removed span keeps the token range, which the service drops); each word of a `:::` line a `class` `ref`, paired in order with the source words (an encoded `#35;` or a word cut by a directive keeps the token range; the rest rename). Id-less nodes have none. A node's span also takes the trailing `%%` lines indented deeper than it (folds).
- **Probe** (R-LANG-7): `ProbeCursor`; the lexer records its jison start condition (`INITIAL`, `NODE`, `NSTR`, `NSTR2`, `ICON`, `CLASS`). Follow kinds: `SpaceList`, `SpaceLine`, the delimiters and a shape's text. Expected: `Mindmap` before the header, statement starts after each separator, `NodeDStart` after an id, `NodeDescr`/`NodeDEnd` in a shape, the stops. After the v12 blank-line error (a node after two blank runs, or one right after `mindmap`) the probe freezes on that line, so nothing is offered there.

## Core and service (shared, additive)

- `LanguageFacet.standalone?: readonly string[]` (core type, 0 B): an occurrence of such a kind is a symbol of its own. `language-service/src/symbols.ts` keys its name space by the occurrence's start; definition and references give it alone, rename edits it alone, a name another occurrence has is no clash. DESIGN §4.5 and language.md step 5 say so. `service.spec.ts` checks it on flowchart with `standalone: ['node']`.

## Behaviour

- Completion: `mindmap` where the header goes; `::icon()` and `:::` at a statement start once a node is above; an id ending its line in each shape (`a` → `a[a]`; lexed alone, quoted or dropped when it would not read back); the closer of the shape after its text at the line end; class names of the other `:::` lines in a `:::` line. Nothing in strings, icons, comments, front matter.
- Hover: a node (id, delimiters or text) names its shape as written (`Shape: circle, written ((…))`), its place (root / depth and parent, children), classes and icon; a class its use count; `mindmap`, `::icon(`, `:::` their grammar doc.
