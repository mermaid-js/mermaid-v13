**`@mermaid-js/diagram-treemap`** (new, private, no manifest until T5). Runtime entry `src/index.ts` is empty (`export {}`) until T2 lands the model. Subpath `@mermaid-js/diagram-treemap/testing` (`src/testing.ts`):

**Rules T2 must know** (all gated): 2.0.1's lexer has no `BOOLEAN` token and no keywords (only terminals), so no rule has a longer alternative: `treemapx` = `TREEMAP_KEYWORD` + `ID2 x`, `titleX` = `TITLE "title"` + `ID2 X`. `NL` and `WS` are Chevrotain *skipped* (in neither list); `ML_COMMENT` is the only hidden token. Every blank run is `INDENTATION` (trailing blanks, between `"a"` and `:`, before `%%`), unless `ACC_DESCR`/`ACC_TITLE`/`TITLE` (which start `[\t ]*`) take it. `CLASS_DEF`'s `\s+` crosses line breaks: `classDef ab\n"a": 1` is one token, and a one-character name is `ID2 classDef` + `INDENTATION` + `ID2 c`. NUMBER2 never starts with `_` or `,` (ID2/COMMA first): `_1` is an ID2, `,5` is COMMA + NUMBER2. v12's `encodeEntities` drops a classDef line's last `;` (a `drop` hole; the token's range covers it, its text does not).
