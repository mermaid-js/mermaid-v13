# Ticket 484: treemap T2, grammar, parser, model, AST and ported specs

**Exports** (`@mermaid-js/diagram-treemap`, runtime entry): `parseTreemap(src, options?) → TreemapParseResult` (`ParseResult<TreemapModel, TreemapDocument>`, never throws; `options.preprocessed` as radar's), `detectTreemap(src, pre?)` (v12's `/^\s*treemap/` after front matter, directives, comments: `treemapx` detects, then fails), `classStyles(model, name)` (v12's `cssCompiledStyles` for a node), warning codes `TREEMAP_ROWS_ON_ONE_LINE`, `TREEMAP_TRAILING_BLANK`, `TREEMAP_CLASSDEF_NEXT_LINE` (D401), `TREEMAP_INVALID_VALUE` (D402), types `TreemapModel`, `TreemapNode`, `TreemapClass`, the AST types (`TreemapDocument`, `TreemapStatementNode`, `Treemap{Header,Section,Leaf,ClassDef,Text,Row}Node`), `TreemapParseOptions`/`Result`.
- **Plugin hook for T4/T5:** `parse: (text, ctx) => parseTreemap(text, { preprocessed: ctx.preprocessed })`.
- **Model for T3** (`src/model.ts`, frozen, additive changes only, note them in GAPS): `roots` (v12's `getRoot().children`, source order, several allowed), each `TreemapNode` `{ type: 'Section'|'Leaf', name, value? (leaf only; `NaN` for `.`), classSelector?, depth (0 at the top; d3's depth is +1), children (empty on a leaf), astId }`; `classes` in first-`classDef` order `{ name, styles, textStyles, astId }` (repeats append; a `classDef` with no styles adds `''`; `textStyles` is v12's `isLabelStyle` on the whole style, so `color:red` is not one); `title` (in-text if non-empty, else front matter, D218; absent when neither), `titleAstId`, `accTitle`, `accDescr`, `warnings`. Tree building is v12's: pop while the top's indent ≥ the row's, only sections pushed.
- **AST** (flat, source order, root `doc`): `Header` `treemap`; `Section`/`Leaf` `node:<path>` (`node:Root/Child`, `@2` for a repeated path, `%`, `/`, `@` percent-encoded) with `name`, `nameRange` (quotes included), `indent`, `depth`, `classSelector?`, `classRange?`, a leaf's `value`, `valueText`, `valueRange`; `ClassDef` `classDef:<name>` (`@2`…) with `name`, `nameRange`, `styleText?`; `Title`/`AccTitle`/`AccDescr` `title`, `title@2`, … with `text`. Ranges from the name (blanks off) to the value or class.
- **Symbols** (D408): `node` def per name (range = the quoted string); `class` def at the first `classDef`, ref at repeats and at every `:::name`. **Statements:** `header`, `section`, `leaf`, `classDef`, `title`, `accTitle`, `accDescr` (flat; folding is T6's). No probe hooks yet, and class rename (D408: keeps the quotes, refuses a name `ID2` rejects or one character long) is T6's.
- **Diagnostics:** `UNEXPECTED` (Expected … got …, with causes: unquoted name, `:::` after a blank or before one, `class names need two characters`, a value with an exponent or unit, a second header, `treemapx`, a value with no name, `accTitle`/`accDescr` without `:`), `STRAY_BLANK` (D401's rejected trap: `a blank at the end of line N`, `a blank before the %% comment on line N`, `line N holds only blanks`, at the blank), `UNEXPECTED_CHARACTER` (`-`, `;`, `{`, others), `UNCLOSED_STRING`, `UNCLOSED_ACC_DESCR`. Newlines are skipped by the grammar (v12's `NL`); the parser reads the lexer's `Kind.Newline` tokens only for messages, warnings and recovery (to the next token that starts a line). `TREEMAP_INVALID_VALUE`: one per parse at the first value, the others `related`; "not as written" = not digits with `,` between groups of three (or trailing) and one `.`.
