# Ticket 335: pie T3, custom layout (`PieLayout`)

**Exports** (`packages/diagram-pie/src/layout/index.ts`, internal to the package; not re-exported from `src/index.ts`):
- `layoutPie(model: PieModel, ctx: PieLayoutContext): PieLayout`. `PieLayoutContext` = `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `inline`. Reads `config.pie` (`textPosition`, `donutHole`, `legendPosition`, `highlightSlice`) and `theme.value('fontFamily')`. px only (D216).
- `PieLayout` (`types.ts`): absolute diagram coordinates, no group transform needed. `center`, `radius`, `innerRadius` (donut), `textRadius`, `outerRadius` (`radius + pieOuterStrokeWidth/2`), `outerStrokeWidth`, `strokeWidth`; `slices[]` (`index` = section index, `ast`, `label`, `value`, `startAngle`/`endAngle` radians clockwise from 12 o'clock, `colour` = index mod 12 → `pie${colour+1}`, `anchor` = centroid at `textRadius`, `percent: PlacedLabel`, `highlighted`); `legend[]` (one per section: `index`, `ast`, `colour`, `swatch: Rect`, `label: PlacedLabel`); `title?: PlacedLabel`; `hover` (`highlightSlice: 'hover'`); `highlightScale` (1.05); `fonts {title, section, legend}`; `bounds` (v12 viewBox grown to cover everything drawn, D224; may start at negative x/y).
- `PlacedLabel` = `Rect & { text: MeasuredLabel }`; v12's baseline is at `y + text.baseline`. Title: middle-anchored on x = 225 (`x + width/2`); percentages centred on `anchor`.
- `slicePath(angles, inner, outer): PathData`: d3 `arc()` about (0, 0), so the renderer draws it in a `translate(center)` group and scales a highlighted slice there (D222). Also `pieAngles`, `centroid`.
- `pieLayoutViolations(model, layout): string[]`: no NaN/Infinity anywhere; legend rows = sections in order; slices in input order = exactly the sections ≥ 1% (D223); angles from 0, contiguous, end at 2π; colour = index mod 12; anchors at `textRadius`; percentages centred; rows apart; outer circle, (scaled) slices, labels, swatches, title inside `bounds`.
- `PIE_METRICS` (`metrics.ts`): the one px table (450, 40, radius 185, swatch 18, row 22, `12*18`, `(450-50)/2`, 1.05).

**Theme stand-ins for #325** (`PIE_THEME_DEFAULTS` in `metrics.ts`, read through `pieThemeLength`): `pieTitleTextSize` 25, `pieSectionTextSize` 17, `pieLegendTextSize` 17, `pieStrokeWidth` 2, `pieOuterStrokeWidth` 2. Once a name is in `THEME_VARIABLES`, `theme.number(name)` is read instead (must be kind `length`); #325 then deletes the table. A non-finite or negative value falls back to v12's default.

**Shared edit:** `fontFamily`'s `usedBy` now lists `pie` (`packages/core/src/theme/vocabulary.ts`, `gen:theme`), as `theme-used-by.spec.ts` requires; its "pie reads nothing yet" skip is still there for #306 to drop.

**Not in the layout (for #306):** colours, opacity, `PIE_HOVER_IGNORED` warning (layout only sets `hover`), `data-ast`/`data-id`.

**Test helpers:** `layout/fixtures.ts` (`model([[label, value], …], extra)`, `section`, `FIXTURES`: pets, showData, hidden, single, empty, zero, many (30), wide, breaks). `layout.spec.ts` has a 10 px-per-character measurer for hand-worked v12 positions and runs the invariants over every fixture × 5 legend positions × 2 configs. `arc.spec.ts` compares paths with d3-shape's output. **Deviations:** an empty `highlightSlice` (the default) highlights nothing, where v12 highlighted a slice labelled `""`. No sections no longer gives NaN legend offsets. Bounds include the outer circle's stroke, slice strokes, and the highlighted slice at 1.05.
