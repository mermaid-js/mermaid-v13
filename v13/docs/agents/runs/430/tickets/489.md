**`WardleyModel`** (`src/model.ts`, plain frozen data, the T3 contract). Positions are percentages 0–100 as v12 stored them (`≤ 1` × 100, else as written; the text is `[visibility, evolution]`, the model `x` = evolution, `y` = visibility); a value over 100 is `WARDLEY_OUT_OF_RANGE` and kept as 100. `nodes` in v12's map order (anchors, components, pipeline children; a merged node stays at its first position): `{ id, label, x, y, className: 'anchor'|'component'|'pipeline-component', labelOffsetX?, labelOffsetY?, inertia, sourceStrategy?, inPipeline, isPipelineParent, astId }`, v12's field names, merge as `addNode` (later wins, offsets and class fall back; a pipeline child over a same-id component drops its inertia and strategy). `links` `{ source, target, dashed, label?, flow?, astId }`: ends resolved by id, then first label, else the name as written (kept, D425). `trends` `{ nodeId, targetX, targetY, astId }` (one per node, last wins, targetY = the node's y). `pipelines` `{ nodeId, componentIds, astId }` (a later block replaces the children; old children stay nodes with `inPipeline`). `notes`, `annotations` `{ number, x, y, text, astId }` (one point, not v12's `coordinates[]`), `annotationsBox?` (first), `accelerators`, `deaccelerators` `{ name, x, y, astId }`, `evolution?` `{ stages, boundaries, astId }` (last; v12's `axes`), `size?` (last), `title?` (last in-text if non-empty, else front matter, D218), `titleAstId?`, `accTitle`, `accDescr`, `warnings`.

**AST ids** (D427, `ast.ts` table): `wardley`, `node:<id>` (pipeline child `node:<parent>_<name>`), `link:<a>-><b>` (names as written), `evolve:<n>`, `pipeline:<n>` (children `PipelineComponent`), `note:<k>` (ordinal), `annotation:<number>`, `annotations`, `accelerator:<n>`, `deaccelerator:<n>`, `size`, `evolution`, `title`/`accTitle`/`accDescr`, `@2` for repeats; `%>@#` percent-encoded. A model node's `astId` is always its first mention, `node:<id>`. **Symbols:** `node` def at the first anchor/component/pipeline component of a name, refs for repeats, link ends, `evolve`, pipeline parents, (de)accelerators; refs to a name nothing defines are dropped (as radar's D358). **Statements:** one span per statement, `pipeline` with its `component` children.

**Diagnostics.** Each v12 throw is an error with v12's text, all of them in source order (GAPS "Errors"). Syntax: `UNEXPECTED` (`Expected …, got …` with hints: D423 "`notebook` starts with the keyword `note` … quote it, as `"notebook"`", integer coordinates, suffix order, `A B` without arrow, chains, one-coordinate pipeline children, `{` on the next line, `}` on a component line), `UNEXPECTED_CHARACTER`, `UNCLOSED_STRING`, `UNCLOSED_ACC_DESCR`, `UNCLOSED_PIPELINE`. Recovery: to the line end (the next line too after an error at a line end, unless it starts a statement); a pipeline is a block (a failed header, its name included, still opens it when its `{` is on the line or starts the next one; an error inside skips its line, a `}` on it closes the block; a line starting another statement ends an unclosed block); after an unclosed `accDescr {`, to the next keyword line. A pipeline component's range error counts also when its pipeline's name failed or names no node (no node is added).
