# Ticket 490: wardley T3, custom layout (`WardleyLayout`)

**Exports** (runtime entry `@mermaid-js/diagram-wardley`): `layoutWardley(model, ctx) → WardleyLayout`, `WardleyLayoutContext` = `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `warn`; codes `WARDLEY_CONFIG_INVALID`, `WARDLEY_STAGE_CLAMPED`; every layout type (`layout/types.ts`). `./testing` adds `wardleyLayoutViolations(model, layout): string[]` and `wardleyLabelOverlaps(layout): string[]`. Reads `config['wardley-beta']` (`src/config.ts`), the model's `size`, `theme.value('fontFamily')`. px only.

**`WardleyLayout`** (absolute SVG coordinates as v12 wrote them, no group transform): `width`, `height`, `padding`, `nodeRadius`, `chart` (never empty, D424); `title?`; `axes {x, y, xLabel, yLabel}`; `stages[] {start, end, label, divider?}`; `grid[]` (per quarter mark its vertical then horizontal line; empty without `showGrid`); `pipelines[] {ast, nodeId, box, joins}`; `links[] {ast, source, target, from, to, dashed, flow?, heads {start?, end?}, label?}`; `trends[] {ast, nodeId, from, to, head}`; `nodes[]` in model order `{id, ast, className, point, glyph: circle|square|none, radius, overlay?, market? {dots, radius}, inertia? {line, width}, label}`; `annotations[] {ast, number, point, radius, label}`; `annotationsBox? {ast, box, lines}`; `notes[]`; `accelerators[]`/`deaccelerators[]` `{ast, name, outline (7 corners), label}`; `fonts`; `bounds` (canvas grown over all drawn, strokes included, D224).
- `PlacedText` = box (`Rect`, before rotation, one line high) + `text: string` (what is drawn), `font`, `ascent` (box top to baseline), `at` (v12's x/y), `anchor` (`start`|`middle`), `baseline` (`auto`|`middle`|`central`), `rotate` (degrees about `at`; the y label −90, link labels v12's angle, 180° becomes 360°). Text is v12's `.text()`: one literal line, the model string with XML white space collapsed as a text node draws it (`"a\nb"` → `a b`); `<br>`, `&lt;` and the model's `&amp;` are measured as written (v12 12.2.0 DB probed). T4 writes `text` with `SvgWriter.text()`.
- Arrowheads are triangles `[base, tip, base]` (v12's marker geometry: tip 0.1·size past the end, base 0.9·size before; links 5, trends 6). T4 draws them as paths (R-ARCH-6).
- `WARDLEY_METRICS` (`layout/metrics.ts`) holds every v12 constant with its line, incl. the strokes, dashes and opacity T4 draws with; `DEFAULT_STAGES`, `AXIS_LABELS`, weights 400/700.

**Behaviour.** v12's order: `pipelinesOf` returns the moved positions (x box centre, y box top − square/6), which links, trends and nodes then read; a later pipeline sees earlier moves. Links dropped: unknown end, self-link, child → own parent (no warning, T2's choice), coincident ends (D425 `WARDLEY_LINK_DROPPED`: the parser now lists links whose ends share a model position, moved parents aside, in its one warning; the layout raises one only when the parser raised none). Decreasing custom boundaries draw backwards, as v12. Trends shortened by r + 2 only when longer; a zero-length trend's head points right. Annotation box only with `annotations` and an annotation with text, lines sorted by number, clamped as v12 (`max(min, min(v, max))`).

**Config (D424)** `src/config.ts`: defaults written by hand (schema keys are `pending`; T5 generates `config-defaults.ts` and should swap them in). `WardleyLayoutConfig` = `Required<Pick<WardleyDiagramConfig, …>>`. A value below its schema minimum (`nodeRadius` must be above 0), non-finite or non-numeric falls back with one `WARDLEY_CONFIG_INVALID` per key (`path`); a numeric string reads as its number; a `size` dimension < 1 falls back to the config's with one warning (`astIds: ['size']`); a padding with 2·padding ≥ width or height falls back to 48, or to 0 where 48 leaves no chart either (one warning for the key in all). Stage boundaries clamped to [0, 1], one `WARDLEY_STAGE_CLAMPED` (`astIds: ['evolution']`). `showGrid` read for truth.

**Parser edit:** `normalise.ts` `drops()` adds coincident ends to `WARDLEY_LINK_DROPPED`.
