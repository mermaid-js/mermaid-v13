# Ticket 490: wardley T3, custom layout (`WardleyLayout`)

**Exports** (runtime entry `@mermaid-js/diagram-wardley`): `layoutWardley(model, ctx) → WardleyLayout`, `WardleyLayoutContext` = `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `warn`; codes `WARDLEY_CONFIG_INVALID`, `WARDLEY_STAGE_CLAMPED`; every layout type (`layout/types.ts`). `./testing` adds `wardleyLayoutViolations(model, layout): string[]` and `wardleyLabelOverlaps(layout): string[]`. Reads `config['wardley-beta']` (`src/config.ts`), the model's `size`, `theme.value('fontFamily')`. px only.

**`WardleyLayout`** (absolute SVG coordinates as v12 wrote them, no group transform): `width`, `height`, `padding`, `nodeRadius`, `chart` (may have a negative width/height when the padding is over half the canvas, as v12); `title?`; `axes {x, y, xLabel, yLabel}`; `stages[] {start, end, label, divider?}`; `grid[]` (per quarter mark its vertical then horizontal line; empty without `showGrid`); `pipelines[] {ast, nodeId, box, joins}`; `links[] {ast, source, target, from, to, dashed, flow?, heads {start?, end?}, label?}`; `trends[] {ast, nodeId, from, to, head}`; `nodes[]` in model order `{id, ast, className, point, glyph: circle|square|none, radius, overlay?, market? {dots, radius}, inertia? {line, width}, label}`; `annotations[] {ast, number, point, radius, label}`; `annotationsBox? {ast, box, lines}`; `notes[]`; `accelerators[]`/`deaccelerators[]` `{ast, name, outline (7 corners), label}`; `fonts`; `bounds` (canvas grown over all drawn, strokes included, D224).
- `PlacedText` = box (`Rect`, before rotation) + `text: MeasuredLabel`, `font`, `at` (v12's x/y), `anchor` (`start`|`middle`), `baseline` (`auto`|`middle`|`central`), `rotate` (degrees about `at`; the y label −90, link labels v12's angle, 180° becomes 360°). One line sits as v12's; extra lines grow up from `auto`, both ways otherwise.
- Arrowheads are triangles `[base, tip, base]` (v12's marker geometry: tip 0.1·size past the end, base 0.9·size before; links 5, trends 6). T4 draws them as paths (R-ARCH-6).
- `WARDLEY_METRICS` (`layout/metrics.ts`) holds every v12 constant with its line, incl. the strokes, dashes and opacity T4 draws with; `DEFAULT_STAGES`, `AXIS_LABELS`, weights 400/700.

**Behaviour.** v12's order: pipelines move parents (x box centre, y box top − square/6) before links, trends and nodes read positions; a later pipeline sees earlier moves. Links dropped: unknown end, self-link, child → own parent (no warning, T2's choice), coincident ends (no warning). Trends shortened by r + 2 only when longer; a zero-length trend's head points right. Annotation box only with `annotations` and an annotation with text, lines sorted by number, clamped as v12 (`max(min, min(v, max))`).

**Config (D424)** `src/config.ts`: defaults written by hand (schema keys are `pending`; T5 generates `config-defaults.ts` and should swap them in). A value below its schema minimum, non-finite or non-numeric falls back with one `WARDLEY_CONFIG_INVALID` per key (`path`); a numeric string reads as its number; a `size` dimension < 1 falls back to the config's with one warning (`astIds: ['size']`). Stage boundaries clamped to [0, 1], one `WARDLEY_STAGE_CLAMPED` (`astIds: ['evolution']`). `showGrid` read for truth.

**Shared edits:** core `vocabulary.ts` adds `wardley` to `fontFamily`'s `usedBy` (`gen:theme`: only `v13/docs/theme-variables.md` changed; core's generated table holds no `usedBy`); `theme-used-by.spec.ts` drops `wardley` from `NOT_DRAWN_YET` (now empty).

**Tests:** `layout/layout.spec.ts` (28, hand-worked v12 positions with a 10 px-per-character measurer, through `parseWardley`); `layout/invariants.spec.ts` (two inline maps, mutations the checker must catch, schema-limit configs); conformance `wardley/layout-corpus.spec.ts` (gate corpus × 5 configs incl. broken ones: no violations; the 10 `pr-check` maps: no label overlaps) and `wardley-layout-literals.spec.ts` (no length literal outside `metrics.ts`; allowed 0, 1, 2, 100, 180, 1e-6).

**Size** (esbuild, minified, core external): `layoutWardley` with config and geometry 12.1 KB / **5.0 KB gz**; runtime entry now 50.9 KB / 17.7 KB gz (12.9 before). Core 93,426 B gz before and after (budget 94,208).

**Deviations:** (1) links between coincident nodes are dropped silently (v12 wrote NaN; the parser cannot know positions, and a second `WARDLEY_LINK_DROPPED` would break one-per-kind). (2) `WARDLEY_CONFIG_INVALID` per key, as D366/radar. (3) Stage font clamped at 0. (4) Labels measured with core's label layout, plain (entities decoded, `\n` breaks a line) where v12 used `.text()`. (5) Invariant exceptions: "inside the chart" and "on the parent's line" skip parents a pipeline moved, children merged with another node (`P_c` collision) and children that are parents; label overlaps are asserted on the `pr-check` maps only (the hand-written cases stack nodes on purpose).
