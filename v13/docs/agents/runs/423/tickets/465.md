## Using them

- AST ids: `header`, `d:<name>` (`@2` for a later block), `i:<name>/<label>` (`@2`, … for the same domain and label again anywhere in the diagram, a later block of it included), `t:<from>><to>` (`#2` parallel), `title`/`accTitle`/`accDescr` (`@2`). Self-loops stay in the AST; the model drops them.
- `model.domains[k].ast` is the drawn (last) block's id, its items' ids that block's; `transitions[k].ast` the statement's.
- Symbols (D367): kind `domain`; the first block is `def`, later blocks and both transition ends are `ref`. Statements: `header`, `domain` (with `item` children), `transition`, `title`, `accTitle`, `accDescr`.
- Warnings, one per parse each: `CYNEFIN_DUPLICATE_DOMAIN` (range: first replaced block's name; the message lists every replaced block by line), `CYNEFIN_SELF_LOOP` (range: first self-loop; lists all). Also in `model.warnings`.
- Errors: `UNEXPECTED`, `UNEXPECTED_CHARACTER`, `UNCLOSED_STRING`, `UNCLOSED_ACC_DESCR`, plus core's preprocess codes. Recovery skips to the line end; items after a failed line join the block before it (or are skipped when none is open).

## Deviations

- Header AST id `header` (the spec names none). An empty transition label stays `""` in the AST node; the model has none.
- Recovery expectations live as extra `errors`/`keeps` fields on their `cynefin-cases.json` items (the brief puts failing inputs there).
- Fuzz fragments are our own (Pele's 51 are not here). Exempt, as core's directive reading: a `%%{` unclosed on its line or closed on a later one, and a one-line `%%{name: word…}%%` that v12's `directiveRegex` cuts short (it stops after the word; core removes the whole directive). For the maintainer.
- The grammar's lexer-input prose keeps "a lone CR reads as LF": the oracle accepts `cynefin-cases/lone-cr` (v12's preprocessing turns CR into LF); only Chevrotain fed directly rejects it.
- `detectCynefin` cuts directives inside the header word and takes `cynefin-beta%% c` + line break, as v12's `detectType` text did (the runtime detector is T5's).
- `convert.ts` repeats pie's value conversion (same `common.langium`; sharing it is a core change), as T1 did for the lexer.
- No language-service probe hooks in the parser yet (T6, #470).
