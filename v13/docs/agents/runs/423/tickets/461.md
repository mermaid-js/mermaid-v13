## Using them (T2)

- **One stream setup:** `lexCynefin(src)` in `src/parser/index.ts` returns `{ pre, view, stream }` (`preprocess` → `sourceView` → `lex`). The parser should start from it; `cynefinTokens`, `lexer.spec.ts` and the parity gate already do. Trivia is `CYNEFIN_TRIVIA` (comments, directives, blanks, `T.Yaml`).
- Token images are v12's: `TITLE`/`ACC_*` include the leading blanks (`complex title X` gives `" title X"`); `STRING` keeps its quotes; the last `Newline` is zero-width (v12's appended `\n`).
- `cynefin-beta:` is `T.HeaderColon`, `cynefin-beta` is `T.Header`; `T.DomainName` has no word boundary (`complexity` is `complex` then `Kind.Error`).

## Tests

- Gate 1, `packages/conformance/src/cynefin/lexer-parity.spec.ts`: name, image and hidden tokens on the text v12 lexed, cut at the first error (D220). 12 e2e, 26 harvested, 116 cases (`corpus/cynefin-cases.json`: quirks, rejections, U+2028/U+2029), each also CRLF and `commented()`: 462 sources, 441 compared, 83 with a lexer error, 0 diffs. The 21 that v12 never detects are listed by id in `NOT_DETECTED` with reasons (2 header-less doc fragments, `cynefin-betax`, `CYNEFIN-BETA`, each with its variants, and 9 `commented()` copies whose header the helper cuts). The dropped set must equal that list.
- Gate 2, same file: the 16 raw `cynefin.integration.spec.ts` strings (and their CRLF and commented copies) through the oracle's `lexText` against `cynefinVerbatimTokens`, with no preprocessing on either side, so `SINGLE_LINE_COMMENT` is gated.
- Exclusion: `cynefin-cases/unclosed-directive-*` (core ends an unclosed `%%{` at its line end, as for pie).
- Stress, `src/cynefin/stress.spec.ts`: 34 shapes, ratio 8n/n < 24, best of 5. Without the directive memo it fails (54x).
- Unit: `packages/diagram-cynefin/src/parser/lexer.spec.ts` (one token across removed spans, pitfall 4; rule order).
- Harvest: `src/cynefin/harvest.ts` (`harvestCynefin`), CLI `harvest:cynefin`, drift check `src/cynefin/harvest.spec.ts` (skips without v12 history, like the jison one).
