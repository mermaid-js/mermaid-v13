# #467 T3 handoff: cynefin custom layout and seeded boundaries

Branch `feature/467_cynefin-layout`. Code in `packages/diagram-cynefin/src/layout/`, theme stand-in in `src/theme/stand-in.ts`.

## Exports

- `.`: `layoutCynefin(model, ctx) → CynefinLayout`, types `CynefinLayout`, `CynefinLayoutContext` (`config`, `measurer`, `theme`, `idPrefix`, `warn`, optional `inline`).
- `./testing`: `cynefinLayoutViolations(model, layout) → string[]`; v12's generator as points (`foldCurve`, `horizonCurve` (adds the `+100` itself), `cliffCurve`, `confusionEllipse`), `curveData`, `ellipseData`, `seededRandom`, `hashString`, `resolveSeed`.
- In-package for T4 (`layout/index.ts`): `transitionData`, `arrowheadData`, `DOMAIN_META`, `domainTitle`, `CYNEFIN_DEFAULTS`, every layout type.

## Using it (T4)

- Geometry is in v12's content space: open `g` with `translate(offset)`, write `viewBox` from `layout.viewBox` (bounds already offset), width/height from it.
- Every text is a `PlacedLabel` (box + `MeasuredLabel`): draw with `w.label(p.text, p.x + p.width/2, p.y + p.height/2)`. Fonts in `layout.fonts` (`CynefinFont`: core's key plus `style`; subtitles are `italic`, measured so).
- Paths: `curveData(boundaries.fold|horizon|cliff)`, `ellipseData(confusion)`, `transitionData(t)`, `arrowheadData(t)` (no `<marker>`).
- `quadrants[i].ast` / `confusion.ast` / `items[i].ast` / `transitions[i].ast` give `data-ast`; absent for undeclared domains.
- Strokes the bounds assume: `layout.strokes` (boundary, cliff, arrow from the theme stand-in; item 1) and `confusion.strokeWidth` 1.5.
- `layoutCynefin` emits `CYNEFIN_CONFIG_INVALID` (path `cynefin.<key>`) through `ctx.warn`, once per bad key per render; a size whose canvas × 16 overflows counts as bad.

**Theme stand-in.** `cynefinThemeLengths(theme)` returns v12's five lengths (16, 12, 2, 4, 2). T4, which declares the theme table on the plugin (GAPS "Theme table in T4"), replaces its body with `theme.number('cynefin…')` and reads colours the same way.
