# T1 #300: quadrant lexer parity gate

Branch `feature/300_quadrant-lexer`. Lexer only; no grammar, no model.

## Exports (`@mermaid-js/diagram-quadrant`, `src/parser/index.ts`)

- `lexQuadrant(src, onRule?)` → `{ tokens, textStart, textEnd, v12 }`: tokens with source
  ranges; `textStart/End[i]` index `v12.text`, the exact text v12's lexer saw (comments cut, CR
  as LF, `trimStart`, entity placeholders, appended `\n`); -1 for trivia. The appended `\n`
  and the tail of each placeholder are zero-width in the source.
- `tokenValue(lex, i)`: text as v12's parser read it (entities `&name;`, appended `\n` clipped).
  `quadrantTokens(src)`: significant tokens `{kind, text, range}`. `QuadrantTokenKind`,
  `JISON_NAMES` (kind → jison terminal; dev/test only).
- Trivia: `Kind.Comment` (removed lines, and jison's skip rules 0, 1, 3; rule 1 takes the
  character before `%%`), `Kind.Directive`. Matches jison returns no token for (quotes, `:::`,
  `accDescr {`/`}`, the coordinate `,` and `]`) get kinds of their own, for T2 and editors.
- Where jison throws: one `Kind.Error` (zero-width before LF, else one code point), then the
  initial state with the stack cleared.

## For T2 (#301)
Text is runs of `ALPHA NUM SPACE …`: read it with `tokenValue`. `SPACE` is one `\s`; padded
keywords (`QUADRANT`, `X-AXIS`, `-->`, `quadrant-N`) carry their spaces; `point_x/y` are the raw
coordinate text (D226, `model.ts`). Rule numbers 0–52 follow `quadrant.jison` (`RULES`).

## Tests

- `packages/conformance/src/quadrant/lexer-parity.spec.ts`: 336 of 364 sources, all but the 28
  listed v12 does not detect (`NOT_DETECTED`, each with a reason; the `QuadRantChart` specs are
  re-run with a detected header). Lexed text and tokens equal the oracle; `rangeViolations`
  checks every token's source range; every rule fires but 41 (duplicate `=`).
- `src/parser/lexer.spec.ts`: ranges, CRLF, trivia, entities, recovery, 1 MB linear cases.
