## Exports (`@mermaid-js/diagram-quadrant`, `src/parser/index.ts`)

- `parseQuadrant(src, { preprocessed?, keepTokens? })` → `ParseResult<QuadrantModel, QuadrantDocument>`;
  never throws. `detectQuadrant(text)` (v12's case-sensitive `/^\s*quadrantChart/`, for T5).
- AST types (`src/parser/ast.ts`): `Header`, `Title`/`AccTitle`/`AccDescr` (`text`), `Quadrant`
  (`quadrant`, `label`), `Axis` (`axis`, `label`, `arrow`, child `AxisEnd`), `Point` (`name`,
  `label`, `className`, `x`, `y`, `styles`), `ClassDef` (`name`, `nameRange`, `styles`). Labels
  are `{ text (untrimmed, as jison built it), markdown, range }`.
- Ids: `pt:A`/`pt:A@2`; last `classDef c` `c:c`; last `quadrant-N` `q:N`; last axis `ax:x`; the
  drawn end label's `AxisEnd` `ax:x/end`; all else `st:<n>` in source order (`st:1` the header).
- Symbols: `class` def at `classDef`, ref at `:::` (T6). `tokenValue` moved to `src/parser/value.ts`; T kind `AxisDelimiter` renamed `AxisTextDelimiter`
  (gen:grammar matches kinds to grammar terminals by name). No probe yet: T6 adds it.

## Choices and divergences

- A bad style is one error diagnostic (`QUADRANT_STYLE_VALUE` / `_UNKNOWN`), the statement goes
  on; a style cut short by a syntax error is not checked (one error, one diagnostic).
- Listed divergence (2 cases): an unclosed `%%{` makes v12 drop the rest of the text and accept;
  core's preprocess keeps it and rejects (`UNCLOSED_DIRECTIVE`). GAPS #300 item closed this way.
- An overridden `classDef` also gets `st:<n>` (the ticket lists only `c:<class>`). Unmet: none.
