# T6 #321: quadrant language facet (branch `feature/321_quadrant-language`)
## Exports (`@mermaid-js/diagram-quadrant/language`, `src/language.ts`, helpers in `src/facet/`)

- `quadrantLanguage` (also as `language`): id `quadrantChart` (T5's manifest id), namespaces
  `[['class']]`, `isValidId(name)` (a class name must read back in both `classDef <name>` and
  `:::name`: ASCII letters and digits, not a keyword). Re-exports `parseQuadrant`,
  `detectQuadrant`, `quadrantTokens`, `quadrantCategories`, `quadrantDocs`, `QuadrantTokenKind`, AST types.
- Completion: `quadrantChart`; statement keywords (from the probe, also right after one typed
  in full); `-->` after an axis start label unless one follows; `:`/`{` after `accTitle `/`accDescr `;
  class names that read back after `:::` (`\w+`) and as a `classDef` name (no `_`); style keys
  after a point's `]` and a `classDef` name, none in a value. Hover: class (its last `classDef`,
  points using it), point label (coordinates, class, styles), keyword docs, `quadrant-N` corner.
- Probe (R-LANG-7): `parseQuadrant(text, { probe })` (ProbeCursor; the lexer records its start
  condition, jison names; `PROBE_FOLLOWS` in `parser.ts`). The statement loop records the
  statement-start kinds only where a statement may start (not before the `eol` ending one).
- Symbols (fixes branch `feature/321_language-fixes`): every `:::name` that lexes is a `ref`,
  failed statement or not, so rename and its clash check cover it; only the last `classDef` of
  a name is the `def` (earlier ones are refs). Goldens `rename/failed-statement`,
  `rename/clash-in-failed-statement`, `definition/last-class-def`.
