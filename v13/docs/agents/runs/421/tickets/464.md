# #464 T7 packet ASCII renderer: handoff

Branch `feature/464_packet-ascii`. D347's shape, drawn from `PacketModel` with `core/ascii`.

## Exports

- `@mermaid-js/diagram-packet/ascii` (`src/ascii.ts`, manifest key `ascii`, lazily loaded by the
  generated registry's `loadAscii`): `ascii(model, layout, ctx)` (the hook; `layout` unread),
  `PacketAsciiContext` (`config`, `warn`, optional `ast`, `inline`), and the
  `AsciiDroppedWarning` / `AsciiDroppedFeature` types.
- `src/ascii/draw.ts` (`drawPacket`), `src/ascii/warnings.ts` (`asciiWarnings`): internal.
- `packet.formats` and the manifest `formats` are `['svg', 'ascii']`.

## Use

`createMermaid().render(id, text, { format: 'ascii', config: { ascii: { charset } } })`.
32 bits a row give 65 columns; bit numbers on a line above each row (`showBits`), rows sharing
borders without them; labels cut with `…` (`~` in ascii); `descending` mirrored; the title
centred below. `rowHeight`, `bitWidth`, paddings ignored. `ASCII_TOO_WIDE` is the API's.

## Tests

- `diagram-packet/src/ascii.spec.ts`: goldens in both charsets via `src/ascii/packet.fixtures.ts`
  (`draw(src, { charset, maxWidth, packet })` → `{ text, warnings }`).
- `conformance/src/ascii/packet-corpus.spec.ts`: properties over the gate corpus (about 280
  sources × 2 charsets): renders what SVG renders, deterministic, rows/columns, no trailing
  spaces, closed boxes 2 columns a bit, labels inside, bit numbers, title last.
- `mermaid/src/packet.spec.ts`: public API, `ASCII_TOO_WIDE`; `bench/src/ascii-size.spec.ts`:
  packet's text path, and no ascii module on a packet SVG render.

## Size

Text path 7,821 B gz (core/ascii 6,304 shared + packet entry 1,517), under R-ASCII-9's 15 KB;
sequence's 10,142 stays the largest. Packet's SVG chunk is unchanged (the entry is separate).
