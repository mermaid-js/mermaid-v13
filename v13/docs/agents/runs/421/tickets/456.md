# Ticket 456: packet T3, custom layout (`PacketLayout`)

**Exports.** `@mermaid-js/diagram-packet` (`.`): `layoutPacket(model, ctx): PacketLayout`, types `PacketLayout`, `PacketLayoutContext`, `PacketRowLayout`, `PacketPieceLayout`, `PlacedLabel`, `BitNumber`. `./testing`: `packetLayoutViolations(model, layout): string[]`. Internal (`src/layout/index.ts`): `PACKET_METRICS`, `PACKET_THEME_DEFAULTS`.
- `PacketLayoutContext` = `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `inline`. Options come from T2's `packetConfig(ctx.config.packet).config` (no second warning), with `bitsPerRow` from `model.bitsPerRow`. Fonts: `theme.value('fontFamily')`, weight 400, sizes from `packetLabelFontSize`/`packetByteFontSize`/`packetTitleFontSize`, stroke from `packetBlockStrokeWidth`. Until T4 declares them, the fallbacks are 12/10/14/1 (GAPS #456).
- `PacketLayout`: `width`/`height` (v12's canvas), `options` (checked), `paddingY` (`pY`, with `showBits`' +10), `rows[]` (`y`, `pieces[]` in model order), `title?`, `strokeWidth`, `fonts {label, byte, title}`, `bounds` (v12's viewBox grown to cover everything drawn, half the stroke included, D344; may start below 0).
- `PacketPieceLayout`: `field` (index), `ast` and `first` (true on the field's first piece, which carries `data-ast`, D345; every piece's `data-id` is the field's `start-end`), `start`/`end`/`bits` (of the piece), `box` (`rect.packetBlock`), `label`, `bitNumbers[]`.
- `PlacedLabel` = `Rect & { text: MeasuredLabel; font: FontKey }`: draw it with `SvgWriter.label(text, x + width/2, y + height/2)` in `font.size`. A piece's label may be shrunk (D343), so read its own `font`. Title: same, with the first line centred on v12's point and further lines below it.
- `BitNumber`: `text`, `bit`, `role` (`start`/`end`, v12's `packetByte start|end` classes), `x`, `y` (baseline, `dominant-baseline: auto`), `anchor` (`start`/`middle`/`end`), `box` (for the bounds).

**Invariants** (`packetLayoutViolations`): no NaN/Infinity anywhere; canvas width and height as v12; rows and pieces equal the model's, in order; row `y`; each piece `max(0, bits * bitWidth - paddingX)` wide, at v12's column in both orders, inside `[1, width - 1]`, never overlapping in its row; a row holds at most `bitsPerRow` bits; each field's pieces cover its bits exactly (the one exception is the last field drawn in a `PACKET_TRUNCATED` model, cut by the row cap); `first` only on the first piece; labels centred on their piece; bit numbers per v12 (count, text, anchor, `y - 2`); title present only when the model has one, centred, its first line below the last row; everything inside `bounds`.

**Specs.** `src/layout/layout.spec.ts`: positions worked by hand from v12 `renderer.ts`/`renderer.spec.ts` with a half-em measurer (both orders, mirroring, flush-right part rows, `showBits`, canvas, title, entities and `<br>`, the D343 shrink, D344 bounds, D342 fallback and zero-width pieces, theme sizes through a stand-in `DiagramThemeTable`). `src/layout/invariants.spec.ts`: every hand-built fixture (`fixtures.ts`: `model(fields, extra)` splits rows like v12; `FIXTURES` has 17 cases: TCP ×2, register, hello, single bits, splits, long label, breaks, wide title, empty, title only, wide padding, tiny geometry, invalid config, truncated) × 3 option sets, plus one mutation per rule, which the rule has to catch. **Parser-produced:** `packages/conformance/src/packet/layout-corpus.spec.ts` parses the whole `packetGateCorpus()` (with CRLF and commented copies) with each source's `packetSection()` config and checks the invariants under 6 option overrides: 0 violations. Mutating the descending column fails it. Literal scan: `packages/conformance/src/packet-layout-literals.spec.ts` (allowed: 0, 1, 2, 1e-6).

**Size** (esbuild, minified, core external): layout + `packetConfig` 3.7 KB, **1.8 KB gz**. The `.` entry is now 19.9 KB, 7.8 KB gz (T2: 6.6 KB gz). `./testing` is 4.4 KB gz.

**Shared edits:** `fontFamily`'s `usedBy` lists `packet` (`core/src/theme/vocabulary.ts`, `gen:theme`; only `v13/docs/theme-variables.md` changed); packet's `NOT_DRAWN_YET` skip in `tools/gen-config/src/theme-used-by.spec.ts` is gone. T4 adds its own variables' reads.

**Deviations:** see GAPS #456 (multi-line title grows down, stroke in the bounds, proportional shrink with a floor of `min(label, byte)`, per-piece fitting, bit numbers measured directly). Before the merge, `src/config.ts` was a byte-identical copy of T2's file, so the merge was clean.
