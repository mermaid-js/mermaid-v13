# #274 T3: cheaper label wrapping (handoff)

Branch `feature/274_label-wrapping`, cut from `feature/265_render-speed` at `6c557ebfd`. That is the integration branch after its sync with `mermaid-v13` and D314, which raised the core budget to 93 KB. PR #393 into the integration branch.

## What changed (`packages/core/src/text/label.ts`)

1. **Fast path:** `*`, `_` and backticks send only a markdown label to the slow path (`RE_SLOW_MARKDOWN`). A plain label keeps the backslash in `RE_SLOW`, for `\n`.
2. **Blank labels:** a blank label returns before `inline.extract`. Its line height and baseline come from `metrics`, which the measurer caches (T2).
3. **One-piece lines:** a line of one piece whose final text is what `wrap` measured keeps that width (`Piece.measured`). `finish` measures every other run as before.
4. **No per-label cache:** `smallWidths` is gone. The measurer answers repeats, and single ASCII characters come from its table (T2).

Specs in `label.spec.ts`, written first: 1–3 each failed on the base. 4 has none, because it only removes a cache and is visible only as time. The ticket line numbers predate #215's rewrite of the file.
