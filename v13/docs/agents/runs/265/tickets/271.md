# #271 T0 — identity gate in the bench (handoff)

Branch `feature/271_identity-gate`, cut from `mermaid-v13` at `90f3c454d`. Draft PR into `mermaid-v13` (D209).

## What changed

- `pnpm --filter @mermaid-js/bench bench --identity [--base <ref>]` runs the identity gate (D200) instead of the bench. A flag of the existing CLI; no root script.
- Each selected fixture is rendered once by `v13` (working tree) and `v13-base` (`--base`, else `BENCH_BASE_REF`, else `origin/mermaid-v13`) in Chromium. Each renderer gets its own page and the two alternate fixture by fixture. Both get the same id (`identity<i>`) and the same source: stripped as the bench strips it, with no `%% run N` suffix. It runs in the browser on purpose: the canvas measurer that T1/T2 change exists only there.
- `src/identity.ts`: `compareIdentity` (exact string equality; a fixture that fails in both is identical only with the same error text; a timeout never is) and `identityReport` (the lines and the exit code). The page gains `renderSvg(source, id)`; the driver gains `driveIdentity`.
- Output: `Identity: 163 of 163 identical`. On failure: `Identity: 111 of 163 identical; 52 differ:`, then one line per fixture with the reason (`SVG differs at offset N`, `head failed: …`, `errors differ: …`, `base timed out …`). Exit 1 when any differ, and also when nothing was compared. Fixtures that fail in both are counted in the line, so a run where everything errors is visible.
- `--set`, `--tiers`, `--filter`, `--timeout`, `--strip` and `--lift-limits` apply as in the bench. A full run takes about 7 s here.
