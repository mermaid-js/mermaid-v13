# Ticket 447: radar T3, custom layout (`RadarLayout`)

**Exports** (`packages/diagram-radar/src/layout/index.ts`, internal; not re-exported from `src/index.ts`):
- `layoutRadar(model: RadarModel, ctx: RadarLayoutContext): RadarLayout`. `RadarLayoutContext` = `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `inline` and `warn`. Reads `config.radar` (through the stand-in), `theme.value('fontFamily')`, `theme.number('fontSize')`. px only.
- `RadarLayout` (`types.ts`): absolute diagram coordinates, no group transform (v12 translated to the centre). `center`, `radius`, `axisLength` (`radius·axisScaleFactor`), `labelRadius` (`radius·axisLabelFactor + 4`), `graticule`, `ticks` (clamped ≤ 32), `min`/`max` (the range used); `rings[]` (`radius`, `points` = polygon corners, empty for circles); `spokes[]` (`index`, `ast`, `angle`, `end`, `anchor`, `textAnchor`, `baseline` (v12's `dominant-baseline`), `label: PlacedLabel`); `curves[]` (drawn only: `index` = curve index, `ast`, `slot` = index mod 12 → `radarCurve-${slot}`, `points`, `segments` = cubic Béziers under `circle`, empty under `polygon`); `legend[]` (one per curve, skipped ones too, empty without `showLegend`: `index`, `ast`, `slot`, `swatch`, `label`); `title?`; `strokes {axis, curve, graticule}`; `fonts {axis, legend, title}`; `bounds` (v12's canvas grown to cover everything drawn, D354; may start at negative x/y).
- `PlacedLabel` = `Rect & { text: MeasuredLabel }`; first baseline at `y + text.baseline`. The box is v12's anchor/baseline placement of one line; extra lines grow away from the chart (down for `hanging`, up for `auto`, both ways for `central`). Title: middle-anchored on `center.x`, top at y = 0.
- `closedRoundCurve(points, tension): CubicSegment[]` and `relativeRadius(v, min, max, radius)`: v12's maths for T4's ported `closedRoundCurve`/`relativeRadius` specs (T4 formats the path string; `M p0` then `C c1 c2 to` per segment, `Z`). `relativeRadius` divides before multiplying (no overflow at 1e308) and returns 0 for `max = min`.
- Warnings through `ctx.warn`, one per kind per layout: `RADAR_CURVE_SKIPPED` (astIds of every skipped curve), `RADAR_EMPTY_RANGE` (astIds of the drawn curves; only when one is drawn). Codes exported as constants.
- `radarLayoutViolations(model, layout): string[]` — also `@mermaid-js/diagram-radar/testing` (new `./testing` export). Checks: no NaN/Infinity; spoke i at `2πi/n − π/2`, end/anchor on its ray, `textAnchor` by ±0.01; `⌈ticks⌉` rings at `radius·k/ticks`, polygon corners on the spokes; drawn curves = exactly those with n entries (n > 0), in order; slot = index mod 12; point i on spoke i, `0 ≤ r ≤ radius`; segment i ends at point i+1; legend rows per curve in order, 20 px apart (plus a label's extra lines); everything inside `bounds`.
- `RADAR_METRICS` (`metrics.ts`): label pad 4, threshold 0.01, row 20, text x 16, factor ¾; `MAX_TICKS` 32, `RADAR_SLOTS` 12.

**Stand-ins for T5** (`src/stand-ins.ts`, delete in T5): `radarThemeNumber(name)` returns v12's value for the nine numeric variables (`radarAxisColor` is documented as the rule `lineColor`; colours/opacities are there for T4). `radarLayoutConfig(section)` reads `config.radar`'s nine keys when a finite number in the schema range, else v12's default (600/600/50×4/1/1.05/0.17); no warning on a bad value (T5 decides). The swatch is `radarLegendBoxSize` (D359).

**Not in the layout (for T4/T5):** colours and opacities, `data-ast`/`data-id`, `DiagramPlugin.labels`, `fontFamily`/`fontSize` `usedBy: radar`.
