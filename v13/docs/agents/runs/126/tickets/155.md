## Exports (`@mermaid-js/diagram-class`)
- `layoutClass(model, ctx: ClassLayoutContext)` → `ClassLayout` (a `LayoutModel` plus `class: ClassPrepared`), as flowchart's `layoutFlowchart`. `ctx` = `{ config, measurer, theme, units?, layout? }`; `ctx.layout` defaults to `layered` (D106). `prepareClass` builds the graph alone. `classTitle(node)` = `Label<T>`.
- Layout ids (keys of `nodes`/`groups`/`edges`): class `c:<id>`, note `t:<noteN>`, interface `i:<interfaceN>`, namespace `s:<qualified id>`; edges use the relation's AST id (`#2`… if repeated), note edges `note>:<noteN>`. Prefixes stop a class, note and namespace with one name colliding. `views` maps layout id → view; `data-id` is the view's `id`.
- `boxes: ClassBoxView[]` (declaration order = v12 `colorIndex`): `width`, `height`, `annotation?` (first only, `«name»`, as v12), `name` (bold), `compartments` (`attributes`, `methods`: `top`, `height`, `rows`), `dividers` (y of each line, one per compartment). A `ClassRow` has `text`, `label: MeasuredLabel` (ready for `SvgWriter.label`), `x`/`y` from the box's top-left (`y` = label top; `x` = centre for `anchor: 'middle'`, left edge for `'start'`), `style` bits (Bold name, Italic `*`, Underline `$`), `member` and `ast` on member rows.
- Geometry (px, all through `fromPx`): `class.padding` (v12 effective 12) above/below the header and each compartment and left/right; rows 3 px apart; an empty compartment is one padding tall; `hideEmptyMembersBox` drops both compartments only when the class has no members (v12).
- `notes: NoteView[]` (markdown, unwrapped, text + `class.padding ?? 6`), `interfaces: InterfaceView[]` (name + `labelPatch`, borderless; placed in its class's namespace), `groups: NamespaceView[]` (outermost first, `depth`, title label).
- `edges: ClassEdgeView[]`: note edges first, then relations (v12 order). `kind` `relation | lollipop | note`, `line` `solid | dashed` (`..` and notes), `startMarker`/`endMarker` (`RelationType`, `none` on notes; the lollipop marker is at the interface end), `label` (markdown, `edgeWrap`), `startLabel`/`endLabel` (multiplicities, `"none"` dropped). Positions come from the model: `edges.get(id).{points,label,startLabel,endLabel}`.
- Routing `stepped` (v12 followed flowchart's default `rounded`). Spacing/padding: `class.nodeSpacing`, `class.rankSpacing`, `class.diagramPadding`, else builder defaults (50, 50, 8).
- Text is literal: `<` is escaped before `layoutLabel`, so `List<T>` is never read as a tag; entities are decoded (v12 `decodeEntities`). Notes and relation labels are markdown.

## For #156 (T4)
- End markers must stay within 12 px across (2 × `endLabelAcross`): the engine's across offset is what keeps multiplicities clear of them; no extra room is reserved. v12's are 12 px across (lengths 18/18/18/9/13); the conformance spec asserts the clearance with those sizes.
