## Exports (`@mermaid-js/diagram-class`, still `"private"`)
- `parseClass(src, { preprocessed?, probe?, keepTokens?, maxEdges?, maxNodes?, maxDepth?, claims? })` → `ParseResult<ClassModel, ClassDocument>`. Never throws. `detectClass(src)` → `'classDiagram' | undefined` (v12's `/^\s*classDiagram/`, `-v2` included).
- `ClassModel` (insertion-ordered arrays): `classes` (`id`, `ast`, `label`, `type` generic, `classes` CSS starting `default`, `styles`, `annotations`, `attributes`, `methods` (`MemberParts` + `ast`), `parent`, `link`, `linkTarget`, `tooltip`, `haveCallback`), `relations` (`start`/`end`: `{ id, type, multiplicity? }`, `line: 'solid'|'dotted'`, `label?`), `namespaces` (`id` qualified, `ast?`, `label`, `parent`, `explicit`, `classes`, `notes`, `children`), `notes`, `interfaces` (lollipop ends), `styleClasses` (classDef), `callbacks`, `direction`, `accTitle`, `accDescr`, `warnings`.
- T3: `namespaceGroups(model, hierarchical = true)` → `{ groups, parentOf }` is v12 `getData`'s `hierarchicalNamespaces` logic. Interfaces are their own nodes, with the `ast` of their mention. v12 draws `dotted` as dashed. Multiplicity: v12 drew a written `"none"` as nothing.
- T4: `memberDisplay(m)` → `{ displayText, cssStyle }` (v12 `getDisplayDetails`), `memberText`, `parseGenericTypes`.
- T6: `classCategories`, `classDocs` (generated), `ClassTokenKind`, `classTokens`. Symbols: kinds `class` (def where the class is made), `namespace`, `cssClass`. Statement spans: `header`, `class`, `relation`, `member`, `classRef`, `namespace` (block), `note`, `annotation`, `style`, `classDef`, `cssClass`, `click`, `direction`, `accTitle`, `accDescr`. Probe: `PROBE_FOLLOWS` = arrows, `:::`, braces, brackets, `<<`/`>>`, `,`, `.`, `:`; the lexer reports jison start-condition names (`class-body`, …).
- AST (`ast.ts`): `n:<id>` per class mention (`@k`), `m:<class>#<k>`, `e:<a>><b>#<k>`, `s:<qualified>@k`, `note:<k>`, `st:<k>` for the rest (header is `st:1`). Click nodes carry `callback` (`AstCallback`), `url`, `target`, `tooltip`. A model entry's `ast` is the mention that made it.
