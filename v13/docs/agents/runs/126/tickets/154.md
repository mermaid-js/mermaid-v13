## Exports (`@mermaid-js/diagram-class`, still `"private"`)
- `parseClass(src, { preprocessed?, probe?, keepTokens?, maxEdges?, maxNodes?, maxDepth?, claims? })` → `ParseResult<ClassModel, ClassDocument>`. Never throws. `detectClass(src)` → `'classDiagram' | undefined` (v12's `/^\s*classDiagram/`, `-v2` included).
- `ClassModel` (insertion-ordered arrays): `classes` (`id`, `ast` = `n:<id>`, `label`, `type` generic, `classes` CSS starting `default`, `styles`, `annotations`, `attributes`, `methods` (`MemberParts` + `ast`), `parent`, `link`, `linkTarget`, `tooltip`, `haveCallback`), `relations` (`start`/`end`: `{ id, type, multiplicity? }`, `line: 'solid'|'dotted'`, `label?`), `namespaces` (`id` qualified, `ast?`, `label`, `parent`, `explicit`, `classes`, `notes`, `children`), `notes`, `interfaces` (lollipop ends, `ast` `i:…`), `styleClasses`, `callbacks`, `direction`, `accTitle`, `accDescr`, `warnings`.
- `callbacks`: only for classes that exist (v12 dropped the rest), `args: string[]` as v12's `setClickFunc` built them (split at commas outside quotes, trimmed, unquoted; `[id]` when none). The AST's `AstCallback.args` keeps the raw text.
- T3: `namespaceGroups(model, hierarchical = true)` → `{ groups, parentOf }` is v12 `getData`'s `hierarchicalNamespaces` logic. Interfaces are their own nodes. v12 draws `dotted` as dashed; a written `"none"` multiplicity drew nothing.
- T4: `memberDisplay(m)` → `{ displayText, cssStyle }` (v12 `getDisplayDetails`), `memberText`, `parseGenericTypes`.
- T6: `classCategories`, `classDocs` (generated), `ClassTokenKind`, `classTokens`. Symbols: `class` (def where the class is made), `interface` (def, lollipop end), `namespace`, `cssClass`. Probe follows: arrows, `:::`, braces, brackets, `<<`/`>>`, `,`, `.`, `:`; modes are jison names (`class-body`, …).
- AST ids (`ast.ts`): `n:A` is the mention that made class A, wherever it is; every other mention of A is `n:A@k` in source order (flowchart's scheme, but keyed to the creating mention, not the first). Lollipop ends get their own prefix `i:A`, `i:A@k` (node type `InterfaceRef`). Also `m:<class>#<k>`, `e:<a>><b>#<k>`, `s:<qualified>@k`, `note:<k>`, `st:<k>` (header `st:1`). Click nodes carry `callback`, `url`, `target`, `tooltip`.
