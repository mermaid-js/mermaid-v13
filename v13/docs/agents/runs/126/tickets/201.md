# #201 class multiplicities clear of markers: handoff

Branch `fix/201_class-marker-clearance`, base `feature/126_class-diagram`. `pnpm check` and host `pnpm e2e` (883 passed) green under the locks.

## What changed
- Core contract (additive, `@mermaid-js/core/layout`): `LayoutEdge.startMarker` / `endMarker`, type `EndMarker { length, width }`: the room a marker drawn at that end takes, `length` out from the box along the route, `width` across, centred on the line. The layered engine's end-label placement (`endLabels`, D102) adds every edge's marker boxes to the obstacles it already steers labels around (middle labels, labels placed before). Nothing else reads them: no port spacing; routes and boxes do not move. Box helper in `core/src/layout/layered/end-markers.ts` (`index.ts` is at its 800-line lint limit).
- Flowchart sets no markers, so its output is unchanged by construction; every flowchart golden and snapshot passes as is.
- Class (`diagram-class/src/layout/prepare.ts`): `MARKER_ROOM` per relation type (diamonds 20, extension 19, dependency 13, lollipop 14; width 12), px only. A constant, as flowchart's head room (D154): the marker theme variables never move the layout. The values cover what the renderer draws in every built-in theme (redux's composition reaches 19.75).
- `render/markers.ts`: `markerReach(type, m)` (how far a drawn marker reaches from the outline, outline included). `./testing` also exports `markers`, `markerReach`, `MARKER_ACROSS`.

## Tests
- `conformance/src/class-layout.spec.ts`: `markerProblems` checks every placed multiplicity against every edge's marker as drawn (renderer geometry via `./testing`) in all `THEME_NAMES`, over the class corpus (nested and flat) and the 120 generated graphs. Failed before the fix (`themes/base.mmd`: `Dog>Leg`'s `1` on `Dog>Toy`'s diamond; several generated fans).
- `core/src/layout/layered/end-labels.spec.ts`: a two-edge fan out of one side, all four directions, the label clear of both markers; markers move the label, not the route. Both fail with the obstacles switched off.
