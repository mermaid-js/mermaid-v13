## Exports (`@mermaid-js/diagram-class`, `"private": true` until T5)
- `lexClass(src, onRule?)` returns `ClassLex` = `{ tokens: TokenStream (source offsets, trivia included), textStart, textEnd, v12 }`. `onRule` gets each matching jison rule number (dev use only).
- `tokenValue(lex, i)`: the token text v12's parser read (CRLF as LF, tag quotes as `'`, entities as `&name;` / `&#n;`), without the `\n` v12 appended.
- `classTokens(src)`: the significant tokens as `{ kind, text, range }`. `ClassTokenKind` (`T`); `JISON_NAMES` (`Kind.Newline` maps to NEWLINE, `Kind.Error` to INVALID).

## How it works (parser/)
- `source.ts` `v12Text()` replays v12's steps in order, each on the previous output, keeping per-character source ranges. The steps: cleanupText, cut core's directive ranges, remove comments from the directive-free text, trimStart, drop the style then classDef `;`, insert entity placeholders, append `\n`. Linear scans, no regex on user input.
- `rules.ts`: jison's 99 rules, index = rule number, plus each start condition's rule list. Tables are built at module scope; the only mutable state is the per-lex `Scan` memo.
- `lexer.ts`: the jison loop. Where jison throws, v13 writes one `Kind.Error`, resets to INITIAL and carries on.
- jison emits no token for `"`, backtick, `~`, `call `, `accDescr {` or `}`; T2 reads those from token positions.
- Trivia (for T2 and editors): comment and directive trivia go out before the next token. A removed comment *inside* a multi-line token (`accDescr {…}`, a string, a member) gives one token whose range covers the comment, and the trivia follows that token.

## Gate (packages/conformance/src/class/)
- `jison-lexer.ts` (oracle), `lexer-parity.spec.ts`, `lexer-stress.spec.ts`; `cli/harvest-class.ts` writes `corpus/class-v12-specs.json` (426 strings, now including those that open with front matter or a directive).
- Corpus: e2e + harvested specs + line-separator cases + 27 hand-written cases, each also with comment lines added. v12 lexes 1490 of the 1504 sources; the rest are not class diagrams to v12. Names and images match on 100%. Images are compared exactly, appended `\n` included, and v12's lexed text equals `lex.v12.text` on every source.
- Rule coverage: every reachable rule fires over the corpus. Unreachable, with reasons in the spec: 5, 86, 89, 94, 96, 97.
- Exclusions: trivia; both streams cut at the first INVALID; no comment line inserted right after a line ending in `%%{` (D67 gap below).

## Gaps
- Core preprocess vs v12 (D67): when a comment line directly follows `%%{`, v12's directive regex does not match, so v12 keeps the directive as text. Core reads it as a directive. Confirmed against the oracle, not fixed: it affects every diagram type.
- Speed is about 1 µs per char on token-dense lines. Linear, not optimised.
