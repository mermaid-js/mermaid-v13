## How it works (parser/)
- `source.ts`: flowchart's `sourceView` (comments, directives, dropped `;`, tag quotes), then `v12Text()` builds the exact text v12's lexer saw (+ appended `\n`), with per-character source start/end (identity fast path when nothing changes).
- `rules.ts`: jison's 99 rules, index = jison rule number, and each start condition's rule list (INITIAL is inclusive). Tables built once at module scope; the only mutable state is the per-lex `Scan` memo.
- `lexer.ts`: the jison loop (first match wins, skip rules, one more try at end of text, `less(0)`, `popState` keeps INITIAL). Where jison throws: one `Kind.Error` token, reset to INITIAL, carry on.
- Every token the jison lexer drops (`"`, `` ` ``, `~`, `call `, `accDescr {`, `}`) is also absent in v13: T2 reads positions from neighbouring tokens.
- `[*]` returns the name `EDGE_STATE`; `classDiagram` and `classDiagram-v2` are one kind (`ClassDiagram`, D101).

## Gaps / for later
- Core preprocess vs v12: a `%%{` followed by a comment line before the word is not a directive to v12 (its regex needs a word next), so v12 kept it as text. Core reads it as a directive. This is a preprocess/D67 question, not class-specific. It is excluded in the gate and not fixed.
- Speed: ~1 µs/char on token-dense lines (rule list tried in order, no first-char dispatch). Linear. Not optimised (handle at milestone close).
