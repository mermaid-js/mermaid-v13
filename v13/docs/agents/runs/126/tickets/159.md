## Parser fixes (diagram-class, from the goldens)
- `click`/`link`/`callback` statement spans were empty (recorded before the statement was read).
- A class symbol covers the id only (`A` of `A~T~`), so a generic class can be renamed.
- `cssClass "A, B"`: a part with blanks around it gets no symbol (v12 looked it up untrimmed: no class).
- An unclosed lexer mode has its own code: `UNCLOSED_GENERIC`, `UNCLOSED_CALLBACK`, `UNCLOSED_CALLBACK_ARGS`, `UNCLOSED_ACC_DESCR` (was `UNCLOSED`), so completion-validity treats `click A call` as an open block.
- `grammar/generated/class.*` (TextMate, Monarch, Lezer) committed with `git add -f`, as flowchart's are: `generated/` is gitignored, so a fresh checkout failed `check:grammar`.
