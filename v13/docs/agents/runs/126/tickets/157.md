## What changed
- `@mermaid-js/diagram-class` is published: `private` dropped, `13.0.0-alpha.0`, repository, README, `peerDependencies` `workspace:*`, changeset `.changeset/class-diagram.md`. Manifest `{ id: class, types: [classDiagram], formats: [svg], export: classDiagram, language }`: v12's one `classDiagram` detector takes both keywords (D101), in v12's order (`gen:registry`). `mermaid` and `language-server` depend on it; `language-service` has it as an optional peer.
- Config (`gen:config`, `SECTION_OWNERS.class`, `classConfigDefaults`): honoured `class`, `theme`, `layout`, `useMaxWidth`, `padding`, `nodeSpacing`, `rankSpacing`, `diagramPadding`, `hideEmptyMembersBox`, `hierarchicalNamespaces`; ignored with a reason `titleTopMargin`, `useWidth`, `dividerMargin`, `textHeight`. D125: documented `padding` 12, `diagramPadding` 8; the plugin's `configDefaults` leaves `padding` out so unset namespaces (16) and notes (6) draw as v12. D127: v12's class section had no `layout` default, so the top-level `layered` applies; asserted with an ELK loader registered.
- Shims gone: the #156 `vi.mock`s, `conformance/src/class/test-registry.ts`, the classDiagram row of `language-service/src/testing/unlisted-facets.ts` (file kept, empty). `classCategories`/`classDocs` are exported from `./language` only (they leaked into the mermaid bundle through the main entry).
- No theme variables: #156 added every family difference.
- Baselines: 26 fixtures in `e2e/diagrams/class-diagram/baseline/` (classes, relationships, namespaces, notes, styles, text, 9 themes); all accepted by v12 (parity suite).
- e2e: the snapshot runner decodes HTML entities (`asHostText`, `e2e/helpers/mmd-snapshots.ts`) as v12's e2e page did; 58 class corpus fixtures write `&lt;&lt;interface&gt;&gt;`, which v12 and v13 both reject as raw text.
- Spec `packages/mermaid/src/class.spec.ts`: both keywords, renderSync, SYNTAX, svg only, config section, D125 padding, D127 layout, slim.
