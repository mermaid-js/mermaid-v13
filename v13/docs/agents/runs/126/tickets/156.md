- `classDiagram`: the `DiagramPlugin<ClassModel, ClassLayout>`. Id `class` (= config section), aliases `classDiagram`, `classDiagram-v2`, `formats: ['svg']`, `layoutKind: 'graph'`, no `configDefaults` yet (#157). `parse` passes the core limits and `claims`.

Edge `data-id` is v12's `id_<a>_<b>_<n>` / `edgeNote<k>`. Full list in MIGRATION "Class diagram SVG structure".
- Markers (`render/markers.ts`): inline paths/circle, v12 classic shapes, ≤ 12 px across outline included; `MARKER_LENGTH`, `MARKER_ACROSS` exported from the module (not the package).
- Theme: palette slot per class by declaration order, `dropShadow` on boxes/notes/namespaces, colours `mainBkg`/`nodeBorder`/`nodeTextColor`/`lineColor`/`textColor`/`note*`/`cluster*`/`titleColor`, and new `classEdgeLabelBackground` (redux `edgeLabelBackground`, classic `mainBkg`; `REDUX_RULES` in `core/theme/specs/geometry.ts`).
