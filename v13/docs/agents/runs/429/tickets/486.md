# #486 T1 lexer parity gate: handoff

Branch `feature/486_venn-lexer`. New package `packages/diagram-venn` (`@mermaid-js/diagram-venn`, private 0.0.0, no `mermaid` manifest block yet: T5), lexer only, source mapping copied from kanban's T1. Core and the registry are untouched.

## Exports (`@mermaid-js/diagram-venn`)

- `VennTokenKind` (`src/parser/tokens.ts` `T`): one kind per `venn.jison` terminal, plus `IndentTextKeyword` (the `text` after `INDENT_TEXT`, no jison name), `QuotedLabel`/`Label` (both `BRACKET_LABEL`) and `Eof`. Shared kinds: `Kind.Newline` (`NEWLINE`), `Kind.Error`, `Kind.Comment` (mid-line `%%`, with the character a glued one eats).
- `JISON_NAMES`: kind → jison terminal (dev/test only).
- `vennTokens(src)` → `VennToken[] { kind, text, range }`: significant tokens; `text` as v12's parser read it (entities decoded, CRLF as LF, removed spans cut, `["…"]` its inside, `[…]` its inside trimmed).
- Internal for #488: `vennView(src)` (`src/parser/index.ts`) → `{ from, view }` (preprocess and source view), then `lex(src, from, view)` (`src/parser/lexer.ts`) → `Lexed { tokens, text(j) }` (trivia included, ends in `Kind.EOF`). Read text only through `text(j)`. Indent mode is the lexer's own (on at each `SET`/`UNION`, off at a line whose first non-blank is not `text`); the parser needs no feedback.

## Token facts the parser needs (oracle-checked)

- `TITLE`'s text is the whole `title …` (v12 strips `title ` with `substr(6)`); a bare `title` takes the next line; `title` at the end is an `IDENTIFIER`.
- Keywords win over ids at a token start (`set set-x` is `SET SET` then an error; `set title x` is `SET TITLE`); `rgb(…)` is `RGBCOLOR` wherever it starts.
- `STRING` keeps its quotes; a `[…]` label of blanks reads `''`.
- An `INDENT_TEXT` line never has a `TEXT`; the lexer cuts at the first error and lexes on (one code point per `Kind.Error`).

## Oracle (`packages/conformance/src/jison/`)

- `venn` descriptor in `JISON_TYPES` with `yy: vennYy`; the `yy` context gains `onToken(listener)`; the oracle gains `pulledTokens(source)` (tokens v12's parser pulled; `lexer.lex` is wrapped only during that call). Additive; other types run the old code path.
