- **Choice:** layering, lowest first: flowchart defaults < swimlane defaults < author `flowchart.*` < author `swimlane.*`, in each source; a later source (front matter, directive) still outranks `initialize()` whatever the section. Keys both sections have (`theme`, `layout`, `useMaxWidth`) resolve to one value written into both; `theme`/`layout` also consult the top-level key after the sections.
- **Choice:** an unscoped `%%{init: {config}}%%` key goes to `swimlane` when its schema (core's `KEY_TREE`, now exported from `@mermaid-js/core/config`) has it, else to `flowchart`. Any first-section key the second section's schema also has (`useMaxWidth`, `useWidth`) is mirrored into it.
- **Choice:** the default curve needs no code: flowchart's default is already `rounded`; an author's curve (`basis` included) wins.
