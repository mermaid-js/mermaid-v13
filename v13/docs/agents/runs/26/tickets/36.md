# #36 Monaco adapter and example editor (branch feature/36_monaco)

## Exports (`@mermaid-js/language-service-monaco`, packages/language-service-monaco, private)
- `registerMermaid(monaco, { service?, preload?, languageId = 'mermaid', diagnosticsDelay = 150 })`
  → `{ service, languageId, dispose() }`, once per monaco + id (ref-counted; another service refused).
  Awaits `service.preload()` (D155), then registers the id, Monarch, configuration, markers, every provider.
- Single features: `completionProvider(monaco, service)`, `hover|definition|reference|rename|foldingRange|
  semanticTokens` `Provider(service)`, `watchDiagnostics`, `toMarkers`, `snapshotOf` (keyed on text), `toRange`,
  `MonacoApi` (`monaco-editor` or `monaco-editor/editor/editor.api`).
- Preview sync: `trackAst(editor, service, ids => …, { languageId, delay })` (mermaid models only,
  re-parse debounced, closes what it opened), `astAtCursor`, `revealAst(editor, service, id)`.
- Peers: `monaco-editor`, `@mermaid-js/language-service`, `@mermaid-js/diagram-flowchart`; no runtime deps.

## Behaviour
Markers on open / language switch, debounced after edits, cleared (and `service.close`) on dispose.
Semantic tokens: LSP encoding, a token spanning lines split per line (Monaco has no multi-line
tokens), empty pieces dropped. Rename: `resolveRenameLocation` + edits, refusals as `rejectReason`.
Folding: 1-based line ranges, no kind. Hover markdown is untrusted (Monaco default).
Monarch (gen-grammar): `frontMatterStart` (fence on the first non-blank line, any indent) and
`includeLF` (Monaco runs no rule at a line end, so `$` pops never fired); test interpreter follows Monaco.
Service fix: completion word ranges stop at the first blank (an `end` ran on to the next id).

## Example (`packages/language-service/examples/monaco`, Vite 8, workspace package, private)
`pnpm --filter @mermaid-js/example-monaco dev|build|preview`. Sources via `mermaid-source`; setup in
`start()` (no top-level await). Cursor outlines the innermost `[data-ast]` (`#preview[data-active-ast]`),
click moves the cursor. `window.{monaco, editor, service}` for the spec.
