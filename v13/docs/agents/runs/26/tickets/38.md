# #38 LSP server `mermaid-language-server` (branch feature/38_lsp-server)

## Exports (`@mermaid-js/language-server`, packages/language-server, published)
- Bin `mermaid-language-server` (src/cli.ts): stdio only (`--stdio` accepted). Depends on
  `vscode-languageserver` ^11 (D88; `THIRD_PARTY_ALLOWED` in tools/check-deps), core, flowchart, service.
- `startServer(connection, { facets? })`: `initialize` builds the service and awaits `preload()` (D155).
  Third-party facets only with `initializationOptions: { mermaid: { plugins: true } }` (D157, `--help`):
  then each workspace folder's own `node_modules`. Serves `.mmd`/`.mermaid` or language id `mermaid`.
  Full sync advertised; ranged changes applied, older versions ignored. `console` → stderr (cli).
- Methods: push diagnostics (open/change; empty on close; `expected` appended to the message,
  `related` → relatedInformation), definition, references, prepareRename/rename (a refusal is a
  `RequestFailed` -32803 error carrying the reason), hover (client's markup format), foldingRange (by
  line; a closing `end`/`}`/`---` line stays visible), semanticTokens/full (legend = `SEMANTIC_TOKEN_LEGEND`), completion (textEdit per item).
- `encodeSemanticTokens(index, text, tokens, multiline)`: cuts a token per line (breaks and the
  continuation lines' indentation left out) unless the client sent `multilineTokenSupport`, then delta-encodes. UTF-16 positions via `LineIndex`.
- `discoverFacets(roots, { log, importTimeoutMs })`: diagram manifests with `id`, `detector` (export
  `detector` else default) and `language`. Never throws; skips (with a log line) bad JSON, missing
  fields, first-party ids or types, paths outside the package (realpath), detectors failing or over
  the time limit (5 s). A broken or slow `language` → `LANGUAGE_LOAD_FAILED`. A throwing facet
  parse → `LANGUAGE_FACET_FAILED` error and no snapshot until the next change.
