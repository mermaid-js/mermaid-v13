# #35 CodeMirror 6 adapter and example editor (branch feature/35_codemirror)

## Exports (`@mermaid-js/language-service-codemirror`, packages/language-service-codemirror, private)
- `await mermaid({ service?, uri?, preload?, delay?, onCursorAst? })` → `Extension`: awaits `service.preload(preload)`
  (D155), then Lezer language + `defaultHighlightStyle` fallback, lint (150 ms, D98), completion, hover, folding,
  semantic-token decorations, cursor → AstId. Peers only: `@codemirror/{state,view,language,lint,autocomplete}`,
  `@lezer/{common,lr,highlight}`, service, core. Exports point at `src/` (no build; not published).
- Single features: `await mermaidService(opts)` (needed by all below), `mermaidLanguage()`, `mermaidDiagnostics({delay})`,
  `mermaidCompletion()` (language data + `autocompletion()`), `mermaidHover()`, `mermaidFolding()` (+ `codeFolding()`),
  `mermaidSemanticTokens({delay})` (classes `cm-mermaid-<type>`/`-<modifier>`, debounced like lint), `mermaidCursorAst(fn)`,
  facet `cursorAstListener`, `selectAst(view, id)` (cursor to `rangeOf(id)`), `mermaidSnapshot(state)`.
- State-only mappings (unit-testable without a DOM): `lintDiagnostics`, `completionSource`, `hoverAt`, `foldAt`,
  `semanticTokenRanges`, `cursorAst`; `DIAGNOSTICS_DELAY` = 150; `renderMarkdown` (text nodes only).
- Snapshot: a StateField holds a lazy snapshot per text; nothing parses until a feature asks. Nothing asks
  per keystroke (review): folds come from the last debounced ranges mapped through edits, completion has
  `validFor: /^\w*$/`, semantic tokens rebuild after the debounce. The view's destroy closes the uri.
- Folds: first line's end to the end of the second-to-last line. `semanticTokenRanges(state, ranges)`: each token once.

## Lezer
`src/generated/` = lezer-generator over `diagram-flowchart/grammar/generated/flowchart.grammar` + tokens.js
(`pnpm --filter @mermaid-js/language-service-codemirror gen`; `src/generated.spec.ts` fails when stale).
Front matter (GAPS #28): the parser wrapper blanks `[0, preprocess().bodyStart)` (line breaks kept) and reuses
a fragment when each of its positions is blank in both parses or in neither (old end mapped by the fragment's
offset), so YAML and body keystrokes keep the tree. Done adapter-side; gen-grammar's outputs are untouched.
