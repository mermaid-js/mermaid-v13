# #31 language-service core (branch feature/31_service-core)

## Exports (`@mermaid-js/language-service`, packages/language-service, zero runtime deps)
- `createLanguageService({ facets?, schema? })` → `{ update(uri, text), get(uri), close(uri) }`.
- `DocumentSnapshot`: `uri`, `text`, `version`, `type` (v12 type), `facet`, `pending?`, `context`;
  `diagnostics()`, `definition(o)`, `references(o, includeDeclaration = true)`, `prepareRename(o)`
  (`{ range, placeholder } | { refused }`), `rename(o, name)` (`{ edits } | { refused }`),
  `foldingRanges()` (`{ range, kind }`), `semanticTokens()` (`{ range, type, modifiers }`),
  `astAt(o)` (ids innermost first, root left out), `rangeOf(id)`. All UTF-16 offsets.
- `firstPartyFacets` (generated: `pnpm gen:registry`, `generateFacets` in
  tools/gen-config/src/registry.ts): every v12 type in detector order, `{ type, id, detector, load? }`;
  `load` imports the manifest `language` subpath's fixed `language` export (shape-checked).
- `FacetEntry` (third-party rows may carry `facet` eagerly; a row with a first-party `type`
  replaces it), `SEMANTIC_TOKEN_LEGEND`, `DocumentContext`, re-exports `LanguageFacet`, `LineIndex`, …

## Use
`let doc = service.update(uri, text); doc = (await doc.pending) ?? doc;` (`pending` only while a
facet loads; an open question with the maintainer). Loads are cached per row; a throw, rejection or
non-facet result gives a `LANGUAGE_LOAD_FAILED` warning. Query results are frozen. Rename checks
`isValidId(name, kind)`, then clashes, then re-parses: the renamed occurrences must read back with
the same kinds and count. A `subgraph` def is its group's definition. Detectors: first-party rows
get the text from the diagram's first line, third-party rows the cleaned text and front-matter config.
No facet: preprocess diagnostics + info `NO_LANGUAGE_SUPPORT`; unknown type: `UNSUPPORTED_DIAGRAM`.

## Extending (#32, #33)
Add a feature module taking `DocumentContext` (text, pre, start, entry, facet, result, schema) and a
memoised method on `DocumentSnapshot` (`this.memo(key, fn)`). `completions` re-parses with `probe`.

## Golden format (#34 extends)
`packages/language-service/goldens/<diagram>/<feature>/<case>.mmd` → `<case>.out`, run by
`src/goldens.spec.ts`, rendered by `src/testing/goldens.ts` (`FEATURES`, one renderer per feature).
`|` = cursor (literal `\|`); `%% rename-to: X` sets the rename target; positions 1-based `l:c`.
Marker features print one block per marker. Update: `vitest run packages/language-service -u`, review.
Behaviour assertions: `src/service.spec.ts`, review cases in `src/review.spec.ts`.
Parser fixes here: click target range, `e1@{ }` is an edge symbol (separate commits).
