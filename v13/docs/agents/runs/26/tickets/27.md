# #27 parser-kit probe mode + flowchart wiring (branch feature/27_probe)

## Exports (`@mermaid-js/core/parser-kit`)
- `ParseOptions.probe?: number`, `ParseResult.probe?: ProbeResult` = `{ offset, expected: TokenKind[], mode, prefix: Range }`.
- `Probe(source, offset, follow?: KindSet)`: `targetIn`/`isAt(view, i, from?)`, `tested(kinds, tokenStart)`, `lexed(start, end, mode)`, `outside(mode)`, `trivia(stream)`, `freeze(always?)`, `reset()`, `result()`. `ParseState.result(..., options, probe?)` attaches it.
- `ProbeCursor(tokens, probe, trivia?)` extends `TokenCursor`: `at`/`eat`/`peekAt`/`tested` record at the probed token. `TokenCursor` gains `peekAt(kind)`, `tested(kinds)`, `recovering()` (no-ops; `syncTo` calls `recovering()`). `peek()` returns a kind and cannot record: use `peekAt`.
- Flowchart: `parseFlowchart(src, { probe })`, `flowchartLanguage.parse(text, { keepTokens: true, probe })`. The lexer reports the jison start condition (`INITIAL`, `text`, `edgeText`, `shapeData`, `dir`, `string`, …).

## The rule (for the D95 amendment)
1. Offset: truncated, clamped to `[0, length]`; NaN and -Infinity give 0, Infinity the end.
2. Outside code: an offset inside front matter (before the body), or inside a line comment or directive (start < offset ≤ end, not just after its own line break) gives `expected: []` and mode `frontMatter` / `comment` / `directive`.
3. Probed token: the first significant token ending at or after the offset; one ending exactly there is skipped when its kind is followed, not extended (#32: so is a followed token whose text, without the blanks it took after it, ends at or before the offset, or that the offset is past a line break of): `Kind.Newline`, `Kind.Space` and the diagram's `follow` set (flowchart `PROBE_FOLLOWS`: links, `:::`, `;`, blanks, `NoDir`, `|`, shape brackets, `}` of shape data). Zero-width tokens are never skipped.
4. Words: if that token is not a followed kind, step back over adjacent tokens (no gap, the later one not starting with a blank) that are not followed kinds. `café` (`caf`+`é`), `my-`, `日本x` are one word, probed at its first token.
5. `prefix` = probed token start (leading blanks dropped) → offset. `expected` = kinds tested there plus loop first sets (end of text, optional blanks before the header); `End` only inside a subgraph.
6. Recovery: once the token was tested, recovery freezes the record. A flowchart restart from before the offset resets it; a restart at or after it ends the probe.

## Notes for #32
- A probed token skipped by recovery (error lines) gives an empty `expected`.
- Shape-data and label prefixes cover the whole token so far: work out the replacement range yourself.
- `PS` also appears in quoted round labels; mode `string` tells them apart. `flowchart |` gives statement kinds (blank lexes as `NoDir`); `A --|` gives `EdgeText`/`Str`, mode `edgeText`.
