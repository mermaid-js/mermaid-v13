## What landed (tests and bench only; no runtime code, gz size delta 0)
- **Golden runner** (`packages/language-service/src/testing/goldens.ts`, run by `src/goldens.spec.ts`):
  `goldenCases(root)` discovers `goldens/<diagram>/<feature>/<case>.mmd`, so new diagram and feature
  folders (#32 completions, #33 front matter) run with no code change. A feature with no renderer
  in `FEATURES` runs through the `DocumentSnapshot` method of the same name (per `|` marker if the
  fixture has any; ranges print `l:c-l:c "text"`, objects `key value …`). `REQUIRED_FEATURES` +
  `missingFeatures(root, id)`: every first-party row with a `load` must have goldens for each
  (spec "the port checklist (R-LANG-3)"). #32/#33: add `completions`/`hover` to `REQUIRED_FEATURES`
  once flowchart has goldens for them; add a renderer only if the generic output reads badly.

- **Oracle through the service**: `packages/conformance/src/flowchart/service-symbols.spec.ts`
  (R-PARSE-5 expectations via definition/references/foldingRanges; 600+ corpus diagrams).
- **Property test**: `src/property.spec.ts`, all 2,244 `e2e/diagrams/**/*.mmd`, every query at
  every token/word boundary: no throw, each call ≤ max(25 ms, 5 × the doc's update), best of 3.
- **Rename round-trip**: `src/rename-round-trip.spec.ts`, every symbol of every facet doc renamed,
  re-parsed, model equal modulo the name (ranges dropped), renamed back to the original text.
- **Bench**: fixture `packages/bench/fixtures/language/flowchart-50k.mmd` (50,510 chars, 474 nodes,
  788 edges, 79 subgraphs); `src/language.ts` (`cycle`, `measureLanguage`, `typing`, `bestOf`);
  CLI `pnpm --filter @mermaid-js/bench language [--runs N] [--enforce]` (per-stage medians);
  PR CI ratios in `src/language-budget.spec.ts`: cycle ≤ 4 bare parses, 2× text ≤ 2.6× time.
