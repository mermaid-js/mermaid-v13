# #30 YAML reader tree mode (R-LANG-5, D96)

Branch `feature/30_yaml-ranges`. Code: `packages/core/src/preprocess/yaml.ts` (+ `yaml-nodes.ts` types, `yaml-text.ts` = pure helpers moved out of yaml.ts for max-lines).

## Exports (`@mermaid-js/core/preprocess`)
- `parseYaml(src, { start?, end?, indent?, tree: true }): YamlTreeResult` (overload; without `tree` it is the old call, same result type).
- `YamlTreeResult = { value, root: YamlNode | null, diagnostics }`. `value` = what was read around the errors.
- `YamlNode = YamlScalarNode | YamlSeqNode | YamlMapNode`, each with `range` (offsets into `src`).
  - map: `{ kind: 'map', flow, pairs: YamlPair[] }`, `YamlPair = { key, keyRange, value?: YamlNode }` (source order; `value` missing when it could not be read).
  - seq: `{ kind: 'seq', flow, items }`; scalar: `{ kind: 'scalar', value, style: 'plain'|'single'|'double'|'literal'|'folded' }`.
- Also `YamlTreeOptions`, `YamlScalarStyle`. Does not touch `isYamlMap` (PR #119 adds it at the end of yaml.ts; a merge is append-only).

## Ranges
- keyRange covers the key as written (quotes included). Quoted scalars include their quotes; block scalars run from `|`/`>` to the end of the last text line; plain from first to last non-blank char.
- Empty value (`key:`, `-`, `{e}`) = plain `null` scalar with an empty range where the value would start (after `key: ` / `- `): use it as the completion position.
- Block map/seq range = first key/`-` to the end of the last value.

## Recovery
- Each block-map entry and block-seq item catches its own error, reports it, then skips the rest of that entry (deeper lines, blanks, comments, lines starting `}`/`]`) and goes on. At most one error per line (later errors on a line already reported are dropped). NUL bytes are reported per line instead of stopping the read.
- A failed entry keeps its key in `pairs` (no value) and is left out of `value`. Duplicate key: the first value stays, the second pair has no value.
- Not recovered: errors inside a flow collection end that whole entry; trailing text after a less-indented root (`end of the stream …`) is reported once and not read; a root-level flow/scalar error gives `root: null`.
- Unclosed `{`/`"` that runs over lines reports where js-yaml fails (often the next line), not at the opener.
- Prototype keys are dropped from both `value` and `pairs`; depth cap unchanged.
