## Generator rules
Kinds match grammar terminals by name, ignoring case and `_`. Unnamed-rule kinds are listed in
`kinds.unnamed` (flowchart: `ShapeDataEnd`). Generation fails on a kind with no rule, an
unreadable kind entry, or a terminal with mixed scopes not in `kinds.mixed` (flowchart:
SHAPE_DATA). Idempotent; covered by `check:grammar`.

## Highlighter fixes (regenerated)
- Empty-matching rules (`\S*`, `[^(]*`, …) are emitted as `atom+` instead of dropped.
- TextMate: a pop+push rule (callback `(`) ends the scope by lookahead (no more Function to EOF).
- Grammar `@trivia`: COMMENT is line-anchored (`A --> B %% note` is node text, as in v12);
  COMMENT and DIRECTIVE take leading blanks so they win over label text. Lezer honours `^` and
  no token runs into a comment or directive.
