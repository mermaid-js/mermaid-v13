# #32 completion and hover for flowchart (branch feature/32_completion-hover)

## Exports
- Core `parser-kit/language.ts`: `LanguageFacet.completions(probe: ProbeResult, doc: DocumentView): CompletionItem[]`
  and `hover(at: HoverTarget, doc: DocumentView): Hover | undefined` (required; `isFacet` checks them).
  `DocumentView { text, result }` (the snapshot's parse, tokens kept); `HoverTarget { offset, token?, symbol? }`.
  `CompletionKind` adds `node`, `subgraph`, `class`, `constant`, `operator`, `shape`.
- Service: `doc.completions(offset)` re-parses with `probe: offset` (front matter first, #33); a text with no
  detected type gets each loaded facet's keywords on its first line (`DocumentContext.available`). `doc.hover`
  passes the non-blank token and the symbol occurrence under the offset (containing it, else ending at it).
- Flowchart: `src/facet/{completions,hover,tables}.ts`; `./language` also exports `flowchartDocs`.
- gen-grammar: `docs.ts` writes `src/generated/docs.ts`, a one-line doc per keyword/operator kind from the
  grammar file (rule docs, or the token rule's own doc; the syntax page prints both, D93). Generation fails
  for a keyword kind with no doc; `KindSource.documented` adds `Click`/`CallbackName` (`click`, `call`).

## Behaviour
Completion: keywords only where the parser tests their kind; ids by context (node/subgraph ids after a
link, `&`, a comma or at a statement start; classes after `:::`, `class A `, `classDef `); directions; arrows and
the rest of `--`/`==`/`-.`; bracket shapes after a known or linked id (not a keyword word); `@{ }` keys and accepted shape
names (lowercase, no `_`); `href`/`call`, link targets, `default`/`interpolate`. Prefix-filtered; the
word under the cursor is replaced whole; the word being typed is not offered as an id.
Hover: node (labels, shape, classes, in/out edges), subgraph (title, members), class (`classDef`, users),
edge id, arrow, keyword incl. `click`/`call` (grammar doc), `classDef default`, header direction, shape name.
Kit (tickets/27.md rules 3–4): blanks a token took and line-break runs are after it; words never cross them.
