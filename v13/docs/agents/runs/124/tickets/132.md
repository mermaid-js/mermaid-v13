## LayoutModel shape (what T4 and T7 draw from)
- Layout ids are AST ids: nodes `n:<name>`, groups `s:<name>[@k]`, edges `e:<a>><b>[#k]`. Look up in `layout.nodes/groups/edges`.
- `er.entities[]: EntityView` `{id, entity, label, style (CheckedStyle), classes ('default' + own), parent?, order (palette slot, v12 colorIndex), width, height, rule, header, columns, rows}`.
  - `rule`: rule thickness, 0 in px, 1 in cells. Bands are `{at, size}` offsets from the box's top/left, rules already counted: `header` (name band), `columns[4]` (type, name, keys, comment; size 0 = column not used, no divider), `rows[]` `{attribute, band, cells: [type, name, keys, comment] MeasuredLabel}`. Cell text is as drawn: generics as `<T>`, keys joined with `,`.
  - No attributes: `columns`/`rows` empty, the name centred in the box (v12 drawRect).
  - Cells match the mermaid-ascii goldens (attributes_basic 29×6, keys_and_comments 51×8, composite_key 39×6, long_entity_names 30×3). A name wider than the columns spreads the spare over the columns in use (v12); in cells the remainder goes to the last.
- `er.edges[]: EdgeView` `{id, relationship, source, target, label}`. Cardinality: `relationship.from.cardinality` at `source` (the route's first point), `to` at `target`. Identifying = solid. Label measured plain (not markdown) at `builder.edgeWrap`; draw it the same way.
- `er.groups[]: GroupView` `{id, subgraph, label, style, parent?, depth}`, outermost first.
