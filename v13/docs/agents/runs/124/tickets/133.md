## SVG (MIGRATION.md "ER SVG structure" lists every change from v12)
- Root `mermaid mermaid-er erDiagram`, `aria-roledescription="er"`; groups `clusters`, `edgePaths`, `edgeLabels`, `nodes`. Only ids: `${idPrefix}-title`/`-desc`.
- Entity `g.node.default.<classes>` (`data-id` = name, `data-ast` = `n:<name>`, `data-color-id` slot): `rect.outer-path`, one `g.row-rect-odd|even` per attribute (`data-ast` = `a:…`, fill rect + `text.attribute-type|name|keys|comment`, cells left-aligned), one `path.divider` (outline + all rules), `text.name`. No attributes: rect + name.
- Relationship `g.edge.relationshipLine.edge-pattern-solid|dashed` (`data-id` = v12 `id_<a>_<b>_<n>`, `data-ast` = `e:…`): line path (dash 8,8) and one `g.marker.<cardinality>` per end (inline path, circle for zero ends). `from` cardinality at the route start. `mdParent` draws nothing (as v12). Labels `g.edgeLabel` carry `data-id` only.
- Subgraphs `g.cluster` (`data-ast` = `s:…`) with `text.cluster-label`. Palette slots colour entities only (v12 ER `genColor`).
