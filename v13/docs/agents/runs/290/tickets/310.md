# #310 T1 journey lexer gate: handoff

Branch `feature/310_journey-lexer`. Lexer in `packages/diagram-journey/src/parser/`; gate in `packages/conformance/src/journey/`.

## Exports (`@mermaid-js/diagram-journey`)

- `journeyTokens(src): JourneyToken[]` (`{ kind, text, range }`): the significant tokens (comments and directives left out), `text` cooked as v12's parser read it (entities decoded, CRLF as LF, removed spans skipped), `range` in the source.
- `JourneyTokenKind` (`T` in `src/parser/tokens.ts`): `Journey`, `Title`, `AccTitle`, `AccTitleValue`, `AccDescr`, `AccDescrValue`, `AccDescrMultiline`, `AccDescrMultilineValue`, `AccDescrMultilineEnd`, `Section`, `TaskName`, `TaskData`, `Colon`, `Eof`, `Invalid`; plus core's `Kind.Newline`, `Kind.Comment`, `Kind.Directive`, `Kind.EOF`.
- `JISON_NAMES`: kind → jison terminal (`taskName`, `NEWLINE`, …); the `accDescr {` opener and `}` have none.

## For T2

- `lex(src, from, view, probe?)` in `src/parser/lexer.ts` returns a `TokenStream` with trivia, as sequence's: build `view` with core's `sourceView(src, pre.bodyStart, directives)`, then `significantTokens()`/`skipTo()`. With a `Probe` it records the jison start condition (`INITIAL`, `acc_title`, `acc_descr`, `acc_descr_multiline`) as the mode.
- `Title`/`Section` hold keyword plus text (v12 `substr(6)`/`substr(8)`, a line break may be the separator); `TaskName` is untrimmed; `TaskData` starts at its `:`. `Colon` and `Invalid` (`;`) are tokens no grammar rule takes.
- Every stream ends in `Eof` then core's `EOF`, also after an accessibility value at the end of the text, where v12 had none and threw (GAPS "#310").

## Gate and tests

- `packages/conformance/src/journey/lexer-parity.spec.ts`: names and images one for one over the 18 e2e fixtures, the 8 harvested v12 strings (`corpus/journey-v12-specs.json`, from #285), line-separator and edge cases, each also commented and with CRLF, plus every UTF-16 code unit in five positions: 287 sources, 0 diffs. Exclusions listed in the spec's header.
- `lexer-quirks.spec.ts`: one spec per T1 quirk of #290 (and the ones the gate found), each asserted against the oracle and v13. `gate.ts` holds both sides (`v13Tokens`, `v12Tokens`, `excludeAccEof`); `corpus.ts` the gate corpus.
- `stress.spec.ts`: linear in input size, 14 shapes. `packages/diagram-journey/src/parser/lexer.spec.ts`: ranges across removed spans (pitfall 4), trivia, CRLF, the zero-width `EOF`, probe modes.
- Descriptor: unchanged; #285's `defaultYy` already passes the plain-object DB (GAPS).
