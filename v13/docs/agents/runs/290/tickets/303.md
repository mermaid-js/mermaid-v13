# #303 T3 journey layout: handoff

Branch `feature/303_journey-layout`. Package `packages/diagram-journey` (skeleton: `package.json` without the `mermaid` manifest, which T5 adds; tsconfigs; `src/index.ts`).

## Exports (`@mermaid-js/diagram-journey`)

- Types from `src/model.ts`: `JourneyModel`, `JourneySection { ast, name }`, `JourneyTask { ast, name, score, people, section, sectionIndex? }`. T2 produces them (GAPS.md "Shared contracts").
- `layoutJourney(model, ctx: JourneyLayoutContext): JourneyLayout`, with `ctx` = `Pick<RenderContext, 'config' | 'measurer' | 'theme' | 'warn' | 'inline'>`. Raises `JOURNEY_SCORE` once per render and `STYLE_VALUE_DROPPED` for a refused `taskFontFamily`/`titleFontFamily`.
- `journeyLayoutViolations(model, layout): string[]`: no NaN/Infinity (path data too), every task laid out in order, tasks in their band, bands and tasks apart, faces on their line, legend rows clear of each other and of bands/tasks, nothing for `''`, bounds holding all drawn.
- `journeyMetrics(journeyConfig)`: the px table (v12 defaults and constants).
- Layout types (`src/layout/types.ts`): `JourneyLayout { units, legend, bands, tasks, activity, title?, left, bounds }`, `LegendEntry`, `BandLayout`, `TaskLayout`, `FaceLayout`, `ActorDot`, `ActivityLine`, `PlacedLabel`, `Rect`, `Circle`, `Mouth`.

## For T4

- Colours are slots: `BandLayout.slot` / `TaskLayout.slot` (0–7, `fillType<slot>`, `section-type-<slot>`), `ActorDot.slot` (`actor-<slot>`, `actorColours[slot % n]` or the author's `actor<slot>`, D249).
- Labels are `MeasuredLabel`s placed in their box (`PlacedLabel`), for `SvgWriter.label()`. Fonts: `fontsOf(ctx)` in `src/layout/env.ts` (task, legend, title) is the one place; export it from the package if the renderer needs it.
- `face.mouthPath` is absolute `PathData` (arc band or the flat line); `face.eyes`; `task.line` (dashed `4 2`); `activity.head` is the inlined arrowhead (fill with the line's colour, D245); `bounds` is the viewBox.
- `TaskLayout.band` indexes `bands`; `BandLayout.ast` is the AST id of the section line that opened the run. Empty sections and repeats folded into one run (consecutive same name) have no band: T4 must still give their AST nodes one `data-ast` element (pitfall 12).
