- Config (`config.schema.yaml`, `gen:config`): every journey key leaves `pending` per spec #290 (honoured / ignored, D225 `textPlacement`, D241 `sectionFills`, `sectionColours` honoured only when set), `useMaxWidth`/`useWidth` re-declared. Font families, `taskFontSize` and `sectionColours` carry no default ("default changes" rows). `journey` in `SECTION_OWNERS`: `src/generated/config-defaults.ts`, `journey.configDefaults`.
- Theme (`gen:theme`): `fillType0`–`7`, `faceColor`, `actor0`–`5` in the vocabulary (`usedBy: journey`). Fills are v12 12.2.0's values per theme via `fillTypes()` (`core/src/theme/specs/palettes.ts`); `base` derives 0/1 from primary/secondary in the shared rules; `faceColor` `#fff8dc` in the shared rules; `actor<n>` unset (D249). `paint.ts` reads them through the theme (the `known()` fallback is gone).
- Task dots carry the `data-ast` of their actor mention (`JourneyTask.mentions`, from T2's `Actor` nodes).
- MIGRATION.md: "User journey" (Layout: D242 sizing and legend margin, D241, D244, legend order, entity actor sort, D225 wrapping; Config; Themes) and the generated config table rows.
