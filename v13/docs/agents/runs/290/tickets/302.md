## Exports (`@mermaid-js/diagram-journey`, `src/parser/index.ts`)

- `parseJourney(src, { preprocessed?, keepTokens? })` → `JourneyParseResult` (`ParseResult<JourneyModel, JourneyDocument>`); never throws. Without `preprocessed` the preprocess diagnostics are included. Wired in `plugin.ts`: `parse: (text, ctx) => parseJourney(text, { preprocessed: ctx.preprocessed })` (the only change there).
- `detectJourney(src, pre?)`: v12's `/^\s*journey/` after front matter, directives and comments.
- AST types (`src/parser/ast.ts`): `Header`, `Title`/`AccTitle`/`AccDescr` (`text`), `Section` (`name`), `Task` (`name`, `score`, `data`, `people`, children `Actor` (`name`)). Ids: `st:<n>` (header, titles, acc), `s:<name>`/`s:<name>@2`, `t:<n>`, `a:<name>`/`a:<name>@2` over the whole text; no node for the `''` actor. Ranges trimmed, in the source.
- Symbols: `actor` def at the first mention, ref after. Statement spans: `header`, `title`, `accTitle`, `accDescr`, `section`, `task`.
- Model: v12's conversions (`Number()` score, people split/trimmed with `''`, untrimmed names, `substr(6)`/`substr(8)`, acc values trimmed, `\n\s+` → `\n` for descriptions); last `title`/`accTitle`/`accDescr` wins; front-matter title when no `title` (D218); `sectionIndex` set after the first section line. Errors: `UNEXPECTED` (with a hint), `MISSING_ACC_TITLE`, `MISSING_ACC_DESCR`, `UNCLOSED_DESCRIPTION`; recovery to the next line break.
