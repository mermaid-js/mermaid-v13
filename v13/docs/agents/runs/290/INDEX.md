## Key facts for tickets
1. **T1** Lexer is 14 rules in one jison file, first-match-in-order, case-insensitive, three `%x` states (`journey.jison:7-34`). `accDescr {` and its `}` return no token (L26-27); `[^\}]\%\%` eats the char before `%%` (L15); `\s+` before `\n` hides NEWLINE (L17). #285 is still open: copy sequence's `jison-lexer.ts` shape, but journey's DB is a plain object, so pass `probe.db` and `clear()` it instead of `new db.constructor()`.
2. **T1** Keyword-vs-task traps: `journey` has no word boundary (L20); `title\s` / `section\s` accept a newline as the `\s` (L21, L29); `title` text may contain `:`, `section` text may not; `taskData` needs at least one char after `:` (L31).
3. **T2** Values are untrimmed: title `substr(6)`, section `substr(8)`, task name as lexed (`journey.jison:61,65,66`). Acc values `.trim()`, then commonDb strips (`commonDb.ts:16-24`; description `\n\s+`→`\n`).
4. **T2** `addTask` (`journeyDb.js:61-84`): `Number(first piece)`, people only from the second `:` piece, split on `,`, trimmed; `''` kept, pieces 3+ dropped. `getTasks()` appends `rawTasks` on every call (L44) and `getActors()` reads `tasks` (L49-58): the oracle adapter calls `getTasks()` exactly once, then `getActors()`.
5. **T2** Sections in the model = every `section` line (empty and repeated); v12's **bands** come from section changes between consecutive tasks (`journeyRenderer.ts:297`), so A,B,A → 3 bands, empty sections → none, tasks before the first section → no band (fill `#CCC`). Decide and test the AST ids `s:<name>@2` against this.
6. **T3** Default geometry (`journeyRenderer.ts`, `svgDraw.js`): band y 50 and height `height`; tasks at y `2*height + diagramMarginY` = 110, x `L + i*(width + taskMargin)` (L = leftMargin + legend widening); face `cy = 300 + (5 - score)*30`, r 15, eyes ±5 / r 1.5; task line to y 450 dashed `4 2`; activity line y `4*height` = 200, stroke 4; legend dot (20, 60 + 20·row) r 7, text x 50, y +7; task dots from `x+14` every 10, r 7; title (L, 25).
7. **T3** Mouth: smile arc π/2→3π/2 at `cy+2`, sad 3π/2→5π/2 at `cy+7`, radii 7.5 / 6.82 (`svgDraw.js:42-69`), flat line ±5 at `cy+7` for 3 and NaN (L72-92). Write it as a `w.path()` arc.
8. **T3** Sizing bugs to drop (D242): width counts `leftMargin` twice (`journeyRenderer.ts:179`), task bounds use `diagramMarginX` as width (L340, L349), band gap uses `diagramMarginX` (`svgDraw.js:171`), widening threshold `lineWidth > leftMargin - lineWidth` (L109), activity line end `width - leftMargin - 4` (L188), viewBox `-25` top and `+70` for a title (L194-197).
