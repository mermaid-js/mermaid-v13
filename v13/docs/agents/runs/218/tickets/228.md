## Exports
- `@mermaid-js/bundler-plugin/{vite,webpack,rollup,esbuild}`: default (and named `mermaid`) = `mermaid(options?)`, so `plugins: [mermaid()]`. `.`: `unplugin` (the `createUnplugin` instance) and `discoveredModule(projectRoot) → { code, warnings, root }`. Options: `root?` (overrides the bundler root). Deps: `unplugin` 3.4.0 (exact; 3.5+ are < 2 weeks old), peer `mermaid`.
- `mermaid/discovered` (new export): `export default []` + `export const warnings = []`. `index.ts` imports it via `bundled.ts`; when non-empty, `createMermaid()` (and the default instance) get `discoverOnFirstUse(api, source)`, awaited before the first render, so extensions are active on it. The source honours `initialize({ discovery: false })` (my reading of D165 for bundles; escalate if wrong). `node.ts` skips Node discovery when the bundled list is non-empty (an SSR bundle built with the plugin has its scan already). `mermaid/slim` is untouched.
- `mermaid/node-scan` additionally exports `FIRST_PARTY_IDS` (node.ts now uses it too).

## How it works
- Root: Vite `config.root`, webpack `compiler.context`, esbuild `absWorkingDir`, else `process.cwd()` (Rollup); then `findAppRoot` + `scanPlugins(root, { firstPartyIds: FIRST_PARTY_IDS })` (T4 rules, confinement). Rescanned at every `buildStart`.
- `load` hook (filter `/mermaid/(dist/discovered.js|src/discovered.ts)$`, then `../package.json` name must be `mermaid`) returns the generated module: `import * as detectorN from "<abs>"` per diagram, entries `{ kind: 'plugin', package, plugin: { manifest: raw, detector: pick(detectorN), load: () => import(entry), loadAscii? } }`, extensions `{ …, plugin: { manifest, load: () => import(entry) } }`. Scan warnings: one bundler warning each (`[mermaid] …`) and in `warnings` for the first render. Order/collisions left to the registry (D166).
- Vite: `config()` adds `optimizeDeps.exclude: ['mermaid']` so dev mode goes through the plugin (not tested: the apps only `vite build`).
- Layout manifests (#238): the scan skips them (readManifest rejects). Additive later: one more case in `generate.ts` `entryOf` → `{ kind: 'layout', package, names, loader: () => import(entry).then((m) => m[export ?? 'default']) }`, plus a static import of an eager `config` module when present.
