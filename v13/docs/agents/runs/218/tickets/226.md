# T4 #226 — Node/SSR auto-discovery (D165, D169)

Branch `feature/226_node-discovery`. Code: `packages/mermaid/src/{node.ts,node-scan.ts}`; spec `node-discovery.spec.ts`; e2e `e2e/platform/ssr.spec.ts` + app `e2e/platform/ssr/`.

## Entry points
- `mermaid` `.` export: `node` condition → `dist/node.js` (after `mermaid-source`, before `default`; `types` stays `index.d.ts`). Same API as `index.ts`; the default instance and every `createMermaid()` from it scan on first `prepare`/`render`/`parse`/`preload` via `discoverOnFirstUse`. Browser bundlers (Vite, webpack, Rollup `browser: true`, esbuild `platform: 'browser'`) never take `node`. The `mermaid` bin still imports `index.ts` (no discovery).
- `nodeDiscovery({ cwd?, importTimeoutMs? }) → FirstUseSource` (exported from `node.ts`, not in the public types): honours `config.discovery === false`, finds the app root, scans, imports each detector with a 5 s limit, cached per (root, limit) for the process. Tests: `discoverOnFirstUse(createMermaid(), nodeDiscovery({ cwd }))`.
- **For T5 / #215: `mermaid/node-scan`** (`node` + `types` conditions only, no `default`, so a browser build fails to resolve it). Pure `node:fs`, sync, runs no package code:
  - `findAppRoot(from) → string | undefined`: nearest dir at or above `from` with a package.json.
  - `scanPlugins(root, { ignore? }) → { packages: ScannedPackage[], warnings: ScanWarning[] }`. Only `root/node_modules/*` and `@scope/*`. Sorted by package name (code-unit). `ScannedPackage = { package, dir (real), raw (the manifest as written), manifest (readManifest), files: { entry, detector?, ascii? } }` — absolute real paths, confined. `ScanWarning = { code: 'PLUGIN_SKIPPED', message, package }`.
  - T5 passes the bundler root and `ignore` = mermaid's own deps (node.ts reads them from `mermaid/package.json`; npm hoists `@mermaid-js/diagram-*`, whose manifests have no detector).
- Shared files: `tools/eslint-plugin` lets `src/node.ts`/`src/node-scan.ts` import `node:` (as the bin); `knip.json` gets a `packages/mermaid` workspace with `src/node.ts` as entry.
- Seam change (additive): `FirstUseSource = (config, warn) => list`; `warn(w)` queues a warning for the first render. Exported type from `discovery.ts`.

## Rules
- Skipped with a `PLUGIN_SKIPPED` warning, never thrown: package.json not JSON, `readManifest` rejection, no `entry`, diagram without `detector`, a path that is missing or resolves (lexically or through symlinks) outside the package, a detector import that throws, times out or exports no function (`detector` or default). Packages without a `mermaid` key or package.json: silent. Ancestor `node_modules`: never listed (so no warning; just not found).
- Diagrams: detector now, `entry` (and `ascii`) on first use, all through `import()` with the same limit. Extensions: entry on discovery (via `addDiscovered`), so `plugin-interactions` activates (D169). Registry rules (first-party skip, explicit wins) are T1's.
- `discovery`: schema key (boolean, no default, so ids/hashes unchanged), on `INTEGRATOR_ONLY_KEYS`; front matter/directives get `CONFIG_SECURE_KEY`. Generated files via `gen:config`.
- Layouts: TODO(#238) in `node-scan.ts` (`scanOne`): `plugin: "layout"` is skipped with readManifest's message until #238; then emit the seam's `layout` arm in `node.ts` `toDiscovered` (`loader: () => importWithin(entry).then((m) => m[export ?? 'default'])`).
