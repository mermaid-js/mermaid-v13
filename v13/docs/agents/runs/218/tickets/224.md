# T3 #224 — R-PLUG-4 bundle test on four bundlers

Spec `e2e/platform/bundle.spec.ts` (project `chromium`, so `pnpm e2e` runs it): 4 apps × 2 pages = 8 tests, ~20 s warm.

## Apps (`e2e/platform/bundle-<bundler>/`, installed with pnpm through `installApp`)

- `bundle-vite` (vite 8.3.4, `vite.config.js`), `bundle-webpack` (webpack 5.112.0 + webpack-cli 7.2.3, `webpack.config.js`), `bundle-rollup` (rollup 4.64.10 + `@rollup/plugin-node-resolve`, `rollup.config.js`), `bundle-esbuild` (esbuild 0.28.2, `build.mjs`). Each depends on `mermaid` only; versions pinned, all ≥ 2 weeks old.
- Each config has a `plugins: []` array: T5 adds `mermaid()` there (esbuild: the `plugins` const in `build.mjs`). Source maps are on in every config: the test needs them.
- The pages are shared: `e2e/platform/bundle-pages/` (`flowchart.html`/`src/flowchart.js`, `all.html`/`src/all.js`). The spec installs the app without building, copies `bundle-pages` into the copy, then runs `pnpm run build`. Output: `dist/{flowchart,all}.html`, entries at `dist/src/*.js` (Vite: `dist/assets`).
- `all.js` exposes `window.renderType(id)` (`flowchart`, `class`, `er`, `sequence`, `state`) and `window.diagramIds`; status `ready` before any render.

## Shared helper (`e2e/platform/harness/chunks.ts`, exported from `harness/index.ts`)

- `recordScripts(page, origin) → { all, next() }`: every script request path to `origin`; `next()` = since the last call.
- `assertLoadedOnly(dist, paths, { diagrams, required? })`: maps each served file to parts through its source map and throws unless only `app`, `core` and `diagram:<id>` for the allowed ids loaded, with each `required` id present. The message lists every script and its parts.
- `chunkParts(dist, path)`, `partOf(source)`: parts are `app` (app + bundler runtime), `core` (`mermaid`, `@mermaid-js/core`), `diagram:<id>`, `ascii` (any `ascii` entry), `language` (language entries and `@mermaid-js/language-*`), `testing`, `package:<name>`. Last `node_modules/` segment wins, so npm, pnpm and `webpack://` paths all work. A map-less chunk that only re-exports (Rolldown facade) has no parts; any other map-less chunk throws.
- `partOf` is unit-tested in `e2e/helpers/platform-harness.spec.ts`.

## Assertions

- One-flowchart page: after render + network idle, all scripts ⊆ {app, core, flowchart} and flowchart loaded.
- Every-type page: nothing of any diagram before the first render; after each render, its new scripts hold its own chunk and nothing of a type not yet rendered. No `ascii`/`language` anywhere.
- Red check done by hand: adding a class render and an ascii render to the flowchart page fails all four apps with `Loaded parts that should not load: ascii, diagram:class`.

## Findings, sizes, unmet

- No `sideEffects`/`exports` fix needed: all four bundlers already split per type. Rollup puts some core modules into the ER chunk and webpack mixes core into per-type chunks; both load only with their type, so they pass.
- No package code changed; gz sizes unchanged.
- Unmet: not run in the Playwright Docker image (as T2). Apps install third-party bundlers from the registry (pnpm `--prefer-offline`), so a cold run needs the network.
