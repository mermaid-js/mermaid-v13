# T2 #222 — pack-and-install e2e harness

Helper: `e2e/platform/harness/index.ts` (Node only, Playwright side). Specs go in `e2e/platform/*.spec.ts` (`testMatch` in playwright.config.ts, project `chromium`, so `pnpm e2e` runs them). Apps go in `e2e/platform/<app>/` with their own package.json.

## API

- `installApp(app, opts?) → InstalledApp` (sync). Packs, installs into a fresh copy of `e2e/platform/<app>/`, runs the build. Options: `packages` (default: the app's deps/devDeps that are packable; their packable deps come along), `manager: 'npm' | 'pnpm'` (default npm), `build` (a script name, or a command array), `env`, `edit`. Returns `{ dir, packed, run(cmd, args?, {env}?) → stdout, close() }`. Throws with the tool's output when pack, install or build fails.
- `serveDir(dir, { headers?, port? }) → Promise<StaticServer>`: static server on a free 127.0.0.1 port. `{ origin, url(path), requests ('GET /x 200'), close() }`. Two servers = two origins (T6).
- `packPackages(names, { edit? }) → PackedPackage[]` (`{ name, version, tarball, hash }`, deps first): builds the workspace packages in the closure (`pnpm --filter … run build`, skipped when their sources are unchanged), then `pnpm pack` each. Fails if a `workspace:` range survives.
- `packClosure(names)`, `packageSources()`: packable = published `packages/*` + `e2e/platform/fixtures/*`. Follows dependencies, peer and optional deps, never devDependencies.
- `edit: { [pkg]: (manifest) => manifest }`: rewrites a packed package.json and re-packs with `npm pack`, so a narrower `files` drops files. For "this mistake breaks the app" tests.
- `assertInstalledFromTarballs(dir, packed)`: runs after every install; every installed copy of a packed package must hash equal to its tarball (`packageHash`). Catches a registry copy of the same version (the published 13.0.0-alpha.0 exists on npm; pnpm does not apply overrides to the peers it installs itself).
- Constants: `REPO_ROOT`, `PLATFORM_DIR`, `FIXTURES_DIR`, `FIXTURE_DIAGRAM`, `FIXTURE_EXTENSION`; `cacheRoot()`.

## How installs work

App package.json deps on packed packages become `file:./tarballs/<x>.tgz` (tarballs copied into the app: short, relative paths). Packages the app does not list go through overrides (npm: `overrides`, direct ones as `$name`; pnpm: `pnpm-workspace.yaml` `overrides`, since pnpm 10 ignores `pnpm.overrides`). Install flags: `--prefer-offline`; first-party packages never need the registry. Commands run without the outer `npm_*`/`pnpm_*` env, with the monorepo's `node_modules/.bin` last on PATH (the smoke app bundles with the repo's esbuild; T3 apps install their own bundlers).

## Cache

`MERMAID_PLATFORM_CACHE` or `<os tmpdir>/mermaid-v13-platform` (outside the repo, so nothing resolves from the monorepo's node_modules). Tarballs by content hash (pnpm pack reorders deps, so package.json is hashed key-sorted); installs keyed by manager + harness source + app files + tarball hashes; cross-process mkdir locks. Cold run ~7 s per app, cached ~0.3–0.7 s (copy + build). Nothing prunes it; delete the folder freely.

## Fixtures (`e2e/platform/fixtures/`, plain JS, no deps, `private: true`)

- `mermaid-fixture-diagram`: manifest `{ plugin: 'diagram', id: 'fixturebox', detector: './detector.js', entry: './index.js', export: 'fixturebox' }`; exports `.`, `./detector`, `./package.json`. `fixturebox <label>` draws one `svg.fixturebox` box with the label.
- `mermaid-fixture-extension`: `{ plugin: 'extension', id: 'fixture-mark', entry: './index.js', export: 'fixtureMark' }`; `postRender` adds class `fixture-mark` to the root svg.
- Both pass `readManifest` (`e2e/helpers/platform-harness.spec.ts`, in `pnpm test`).
