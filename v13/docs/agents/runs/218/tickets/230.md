# T6 #230 — CDN build (ESM + classic loader, cdnBase, plugin queue)

Branch `feature/230_cdn-build`. R-PLUG-7, D162, D163, D167.

## Files

- `packages/mermaid/scripts/cdn-build.ts` (`buildCdn(outdir?) → { files, esmClosureGzip, loaderGzip }`, `closureGzip`, `ESM_FILE`, `LOADER_FILE`): run by `mermaid`'s `build` after `tsc` (`tsx scripts/cdn-build.ts [outdir]`; prints both gz sizes). Two esbuild passes from the `mermaid-source` sources: pass 1 finds every lazy `import()` target; pass 2 makes each one an entry with a stable name (`chunks/diagram-<id>.mjs`, `-ascii`, `-language`, `core-theme-specs-<theme>.mjs`, `mermaid-ascii.mjs`; shared code in `chunks/chunk-<hash>.mjs`) and rewrites each lazy `import('…')` in the sources to `import(globalThis[Symbol.for("mermaid.cdnBase")] + "chunks/<name>.mjs")`. A lazy import it cannot name, or a relative one left in the output, fails the build. Linked source maps with sources embedded; map sources read `node_modules/<package>/<path>`, so T3's `assertLoadedOnly` attributes CDN chunks too.
- `src/cdn.ts` (ESM entry → `dist/mermaid.esm.min.mjs`): `index.ts` + `initialize` that also sets `cdnBase` (each call replaces it; default `new URL('./', import.meta.url)`), sets `globalThis.mermaid`, connects the queue. Not in `tsc` output.
- `src/cdn-loader.ts` (→ `dist/mermaid.min.js`, IIFE, no imports): sets a stand-in `globalThis.mermaid` at once, `import()`s the ESM file beside `document.currentScript.src`. Async methods wait; `initialize`/`register*`/`setParseErrorHandler`/`contentLoaded` are replayed in order; `renderSync`/`detectType`/`supportsFormat`/`mount` throw until loaded. Calls `contentLoaded()` itself when the page `load` already fired.
- `src/plugin-queue.ts` `connectPluginQueue(api, scope = globalThis)`: drains `scope.mermaidPlugins` into `addDiscovered` and replaces `push`. Entries: anything `registerExternalDiagrams` takes, with an optional `package` (fallback: manifest id, then plugin id), or a seam entry `{ kind: 'plugin' | 'layout', package, … }` (layouts register lazily). Bad entries → `PLUGIN_SKIPPED`.
- `api.ts` (T1 seam): draws (`prepare`/`render`/`parse`/`preload`) now also wait for `addDiscovered` calls still in flight, not only the first-use source. T5's module benefits too.
- Config: `cdnBase` in `INTEGRATOR_ONLY_KEYS` (core) and `IntegratorOptions`/`INTEGRATOR_KEYS` (snapshot; left out of `optionsKey`, so ids do not change), reference text via `gen:config`.
- `package.json`: `unpkg`/`jsdelivr` → `./dist/mermaid.esm.min.mjs`; both CDN files in `sideEffects`; devDeps `esbuild`, `tsx`. `files` unchanged (`dist`). No `exports` change. `knip.json`: a `packages/mermaid` block (CDN entries, `scripts/`).
