## Exports

- `@mermaid-js/layout-elk/sync` (`packages/layout-elk/src/sync.ts`), private package, no published wiring:
  - `layoutSync(graph: ElkNode, options?: { layoutOptions?: LayoutOptions }): ElkNode` — same contract as `await new ELK().layout(graph, { layoutOptions })` with elkjs's in-process worker: mutates and returns `graph`; elkjs errors are thrown (GWT `__java$exception` flattened to `cause`).
  - `LayoutSyncOptions` type.
- Dependency: `elkjs` **0.12.0** exact (v12 develop's lock).

## How to use (E2)

```ts
import { layoutSync } from '@mermaid-js/layout-elk/sync';
const laidOut = layoutSync(elkGraph); // no await, no timers
```

Build the ELK graph as v12's `buildElkGraphFromLayoutData` does, call `layoutSync`, read x/y/sections. Never read `$H` (GWT hash counter, differs run to run).
