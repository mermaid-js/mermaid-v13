# M3 #246 — math in every diagram type

Branch `feature/246_math-integration`. Consumers: S1 #247 (size), #218 T4 (activates on install), M4 icons (labels walk).

## What changed

- Class, state, ER and sequence pass `inline: ctx.inline` at every `layoutLabel` call (class: labels, terminals, `measureBox`; sequence: `env.measure`). Flowchart already did, edges and subgraph titles included. Each type's layout context gains `inline?: InlineSpans`. Class's single-run row form skips box runs.
- Text output: `inlineSpans(providers, warn, 'ascii')` boxes nothing and warns one `ASCII_DROPPED` (`feature: 'math'`, no `astIds`) per render; `mermaid` passes it for `format: 'ascii'` (D179).
- Sequence: no parse diagnostic any more. `SEQUENCE_MATH` (deprecated alias, exported const in `layout/env.ts`) is raised once per layout when a label shows a `$$…$$` pair as written, next to `MATH_NOT_RENDERED` / `MATH_ERROR` / `ASCII_DROPPED`. Remove it in the next alpha.
- `legacyMathML`, `forceLegacyMathML`: `ignored` with a reason (`gen:config`).
- Core, additive: `DiagramPlugin.labels?(model)` (every text the layout lays out, as written) and `ResourceRequest.labels?()`, which `mermaid` fills from the diagram plugin. Each first-party type has `src/labels.ts`. plugin-math's `needsMath` scans `request.labels()` when given, else the old whole-parse walk, so `$$` in a click tooltip or URL loads nothing.
- `packages/dev/src/adapter.ts` registers plugin-math (as installed), so the e2e page and gallery render math. dev gains a devDependency on `@mermaid-js/plugin-math`.
- MIGRATION.md: `### Math` under Labels (glyphs, size 1.13 vs 1.21 em, colour, mapped KaTeX names, static class members ending in `$`, unsupported `\def`/`\newcommand`/`\renewcommand`/`\href`/`\style`/`\class`/`\unicode`/`\htmlClass`, `\tag`), sequence entry rewritten.

## Tests and helpers

- `mermaid/src/inline-boxes.spec.ts` "math in every diagram type": `EVERY_TYPE` (one source per type, a span in every label kind, distinct TeX lengths) with the fixture provider: boxes drawn, no `$$`, no placeholder; without a provider one `MATH_NOT_RENDERED` (+ `SEQUENCE_MATH`); ascii for flowchart/ER/sequence, provider or not.
- `plugin-math/src/index.spec.ts`: `ONE_LABEL` (24 cases, one label kind holds the only math, fresh plugin each): `prepare` + `renderSync` draws it, so every type's `labels()` covers that kind. Tooltip/URL no longer load. The allow-list/determinism/tree-identity check now also covers the new math fixtures.
- Fixtures: `e2e/diagrams/{class-diagram,state-diagram-v2,er-diagram,sequence}/pr-check/math-should-render-tex-in-every-*-label.mmd`.
