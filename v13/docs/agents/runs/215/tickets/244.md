# #244 M1 — MathJax TeX → SVG paths (spike)

Result: works, no stop rule tripped; the engine is 677 KB gz (maintainer's call). Full write-up: `../244-mathjax.md`.

## Exports

- `@mermaid-js/plugin-math/engine` (`packages/plugin-math/src/engine.ts`), private package, no plugin wiring:
  - `typeset(tex, { ex, em? }): MathBox`, synchronous. Display mode, as v12. px, top-left origin. Throws `MathError` for bad TeX and for output outside the allow-list.
  - `MathBox` `{ width, height, baseline, node }` and `MathFragment` `{ tag, attrs?, children? }`, which are T0's `InlineBox`/`SvgFragment` shapes, declared locally until #237 lands. M2 switches to core's types.
  - `MathError`, `TypesetOptions`.
- Core: `@mermaid-js/core/svg` exports `pathBuilder` (additive).
- Dependencies: `@mathjax/src` 4.1.3, `@mathjax/mathjax-tex-font` 4.1.3 (Apache-2.0).

## How to use (M2)

```ts
const provider: InlineProvider = { open: '$$', close: '$$',
  box: (tex, req) => typeset(tex, { ex: req.ex, em: req.font.size }) }; // catch MathError → undefined or warn
```

Checked against `feature/237_inline-box-runs` on a throwaway merge: the four katex fixtures render through `render()`, inert and deterministic. `ex = 0.5 × font.size` is good enough (math em 1.13× the label font; v12 KaTeX was 1.21×). There is no need for an x-height metric. For v12's size, pass `ex = 0.535 × font.size`.

## Sizes

Engine minified ESM: 2,809,932 B / **1,034,233 B gz** as resolved today. With MathJax's `#default-font/*` aliased to the TeX font it is 1,834,162 B / **677,592 B gz**. M2's build must alias it.
