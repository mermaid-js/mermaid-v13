# #608 T1 handoff: railroad lexer parity gates (IR, EBNF, ABNF, PEG)

Branch `feature/608_railroad-lexers`. Package `@mermaid-js/diagram-railroad` (private, `0.0.0`, no `mermaid` manifest block: T5).

## Layout (choice: one shared token-kind module, one lexer per notation)
- `src/parser/tokens.ts`: `T` (one kind set for all four notations; shared kinds `Header`, `Title`, `AccTitle`, `AccDescr`, `Id`, `String`, `=`, `;`, `(`, `)` …), `RailroadNotation` (`'railroad' | 'railroadEbnf' | 'railroadAbnf' | 'railroadPeg'`, the v12 type ids), `RAILROAD_TRIVIA` (no newline token: line breaks are whitespace in all four grammars).
- `src/parser/lexer.ts`: abstract `RailroadLexer` (source view, Chevrotain loop and error skip, offsets, trivia, the rules every grammar repeats: header, TITLE/ACC_*, IR-style strings, whitespace, YAML, directive, `%%`, `/* */` and `(* *)`, with linear memos). Each notation subclasses it with `scan(p, c)` in 2.0.1's token order: `src/parser/{ir,ebnf,abnf,peg}/lexer.ts` (`lexIr`, `lexEbnf`, `lexAbnf`, `lexPeg`).
- `src/parser/langium-names.ts`: `LANGIUM_NAMES[notation][kind]` and `LANGIUM_HIDDEN[notation]` (Chevrotain names; testing only).
- `src/parser/index.ts`: `LEXERS[notation](src, from, view)`, `railroadView(src)`, `railroadTokens(notation, src)`.
- `src/index.ts` exports nothing yet; `./testing` exports the above.

## Use
`railroadTokens('railroadAbnf', src)` gives `{kind, text, range}` per token v12 saw. T2 parsers take `LEXERS[n](src, bodyStart, view)` and `RAILROAD_TRIVIA`. LONGER_ALTs copied: IR keywords → `RR_ID`, EBNF `(`→ISO comment, `?`→special, `-`→YAML, ABNF `;`→`ABNF_COMMENT` (any text after `;` on its line, a blank too). Entities read as v12's placeholders (`#x;` is an error in PEG, not a comment).
