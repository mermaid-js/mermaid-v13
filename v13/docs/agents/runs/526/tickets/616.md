## Features
Completion: the four headers (only them) at the header; `title`/`accTitle`/`accDescr` at a line start; IR call keywords; each notation's operators; defined rule names at an element (IR: `nonterminal("x")`, and inside `nonterminal("…")`). Hover: a rule name shows its first rule's first line (cut at the rule's end) (duplicates, undefined); an ABNF repeat its min/max and what is drawn; keywords their notation's grammar doc (IR keywords now documented one rule each in `grammar/railroad.ebnf`). Folding: multi-line rules, `accDescr {}`, `/* */`, `(* *)`, EBNF specials. Symbols `rule`, `declaredOnly`; rename refuses invalid/`title`-prefixed names (isValidId), notation-only refusals (ABNF `_`, IR keywords) via read-back, clashes.
