## Model shape (for T3, `src/model.ts`, frozen, source order)
`{ notation, rules: [{ name, astId, definition, range }], title?, accTitle, accDescr, warnings }`. Nodes: `terminal{value}`, `nonterminal{name}`, `special{text}`, `sequence{elements}`, `choice{alternatives}`, `optional{element}`, `repetition{element, min, max}` (`max` `Infinity` when unbounded; only `min === 0` changes the drawing). Every node has `astId` (`rule:a/0`, `rule:a/0/1`, …); a rule `rule:a` (`rule:a@2` for a duplicate). One-element sequences/choices collapse; EBNF `A - B` is `sequence[A, terminal '-', B]`; PEG `&X`/`!X` a `special`. A rule with a syntax error is left out.

## AST, symbols, diagnostics
- `Document > Header | Title | AccTitle | AccDescr | Rule > expression nodes` (one per model node, same id and kind; ranges as written, postfixes cover their operand). `rule` symbols: def at rule names, ref at nonterminals (IR: the text inside the quotes; PEG predicates' operands too). Statements `header`, `title`, …, `rule`.
- Errors: `UNEXPECTED` (human expected-names), `UNCLOSED_STRING`, `UNCLOSED_COMMENT`, `UNEXPECTED_CHARACTER` with notation hints, `DEPTH_LIMIT`. Recovery resumes after the next `;` or at `name =` (missing `;` is reported right after the rule's last token). Warning `RAILROAD_DUPLICATE_RULE`.
