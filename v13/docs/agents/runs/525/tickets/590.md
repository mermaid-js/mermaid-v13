Branch `feature/590_compass` (worktree `arch-t590`), merged with `origin/mermaid-v13` @ ade398e6b (and alpha.2, 9041e926e), head a55fdf0f9 after the /code-review fixes (10 findings, each with a spec that failed before). Own core PR into `mermaid-v13`. `pnpm check` green (899 files, 18,697 tests).

## Exports

- `@mermaid-js/core/layout/compass`: `compass: LayoutEngine` (`packages/core/src/layout/compass/index.ts`). Never re-exported from `@mermaid-js/core/layout`.
- `@mermaid-js/core/layout` types gain D501's optional fields: `LayoutEdge.sides?: { source?: Side; target?: Side }`, `LayoutEdge.border?: { source?: boolean; target?: boolean }`, `LayoutGraph.align?: readonly { axis: 'row' | 'column'; members: readonly string[] }[]`, `LayoutNode.anchorY?`. Other engines ignore them.
- `validateLayout`: a `border` end on a node must lie on its group's border; an end on a group is checked against that group.
- `mermaid`: `LAZY_LAYOUTS` row `compass`; `ANY_GRAPH_LAYOUTS` set in `registry.ts` (D502 exemption, one row per engine; swimlane adds `'swimlane', // D535`). `tree` keeps D285.

## Using it (T3)

- Architecture's plugin: `layoutEngine: { default: 'compass' }`; any graph type may also set `layout: compass`. `prepare()` loads it; `renderSync` before that throws `NotLoadedError` `{ kind: 'layout', name: 'compass' }`.
- Build: services `width = max(iconSize, label width)`, `height = iconSize + label height`, `anchorY = iconSize / 2`; junctions `iconSize` square with `anchorY = iconSize / 2`; groups `padding` 40 on all sides, `title` measured; edges `sides` (both), `border` for `{group}`, `label`; `align` from the hints. Groups may come in any order (reordered parents first).
- Output: plain `LayoutModel`. `L`/`R` ends sit on the box side at the anchor line, `T`/`B` at the middle of top/bottom; `ports` are the sides. Routes are orthogonal: 2 points straight, 3 one bend, more for detours. T4 runs `L`/`R` lines on to the icon when a label is wider, and junction ends to the centre (GAPS T0).
- Lengths: `METRICS` in `compass/metrics.ts` (gap 60, stub 12, …). Fixed at v12's defaults (GAPS T0).
