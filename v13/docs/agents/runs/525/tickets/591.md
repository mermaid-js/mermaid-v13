## Behaviour (for T3/T4 with `layout: layered`)

- Ranks, node order, boxes and labels are layered's. An edge is drawn again only if a named side moves one of its ends; `ports` report the named sides.
- Where each end goes: onto its named side.
  - If layered took another side, it goes to the side's middle.
  - On any named `left`/`right` side it goes to `anchorY`, moved or not.
  - Otherwise it stays where layered put it.
- Stub lengths: the source stub is `corner` plus the start marker; the target stub is `corner` plus `headRoom` plus the end marker.
- Routing: right angles from stub to label to stub. A small cost (boxes crossed, turns, doubling back) picks among lines through the ends, midway, and `corner` past each end box. RoutePoints carry their axes from the start.
- The drawing grows, and everything shifts, where a stub reaches into the margin.
- A loop with two different sides is routed the same way, through its label. A loop with both ends on one side keeps layered's loop. Not applied on the grid.
