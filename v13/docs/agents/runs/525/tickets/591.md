## Behaviour (for T3/T4 with `layout: layered`)

- Ranks, node order, boxes and labels are layered's. An edge is redrawn only where a named side moves an end.
- Ends: on the side's middle if layered took another side; at `anchorY` on any named `left`/`right` side, so architecture L/R edges are always redrawn on the icon line; otherwise where layered put them.
- Stubs: source `corner` + start marker; target `corner` + `headRoom` + end marker.
- Links run stub → label → stub, chosen by cost (nodes crossed, doubling back, turns). Lanes go past the end boxes, then past any node still crossed. Straight-through points are dropped; axes are set on the way.
- The drawing grows, and shifts, where a stub or lane enters the margin.
- Kept as layered drew them: edges between a node and its own group, same-side self-loops, and the grid.
