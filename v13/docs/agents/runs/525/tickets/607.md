- `layoutArchitecture(model, ctx)` → `ArchitectureLayout` (`LayoutModel` + `architecture: ArchitecturePrepared`): builds the graph and calls `ctx.layout` only (no engine bundled). `ctx`: `ArchitectureLayoutContext` = `RenderContext`'s `config`, `measurer`, `theme`, `layout`, `warn`, optional `inline`.

Services first, then junctions, each in model order.
- `ARCHITECTURE_METRICS`, `architectureSizes(iconSize, padding)` → `ArchitectureSizes` (a render's are `prepared.sizes`; read them there, not again): `iconSize`, `padding`, `anchorY` (`iconSize/2`), `arrow` (`iconSize/6`), `labelWidth` (`×1.5`), `labelAt` (`iconSize/2`, `iconSize`), `groupEdge` `{ side: padding+4, bottom: +18 }`, `junctionEnd` (`iconSize/2`), `groupIcon` (`padding×0.75`), `groupLabelGap` 4, `groupDash` 8.

## Using it (T4, T5)

- Plugin `layout(model, ctx)` = `layoutArchitecture`. Layout ids: node and group ids as written, edges by `astId`. Group title band = icon, then 4 px and the label (4 px from the corner without an icon) (model `title` centre from `LayoutModelGroup.title`).
