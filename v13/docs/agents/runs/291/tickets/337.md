# #337 T3 layout (LR and TD): handoff

Branch `feature/337_timeline-layout`. New private package `@mermaid-js/diagram-timeline` (0.0.0, no manifest, no registry or config change), wired like diagram-state at its T1: `package.json`, `tsconfig.json`, `tsconfig.build.json`; lint, knip and vitest pick it up by glob.

## Exports (`@mermaid-js/diagram-timeline`)

- `src/model.ts`: `TimelineModel { direction, title?, accTitle, accDescr, sections, periods, warnings }`, `TimelineSection { ast, text }`, `TimelinePeriod { ast, text, section?, events }`, `TimelineEvent { ast, text }`, `TimelineDirection`. Text is raw (v12's DB); `section` is an index into `sections`, undefined before the first one. AST ids 1-based: `sec:<n>`, `per:<n>`, `ev:<p>.<k>`, `st:<n>`. **#336 adopts this type** (additive changes only).
- `layoutTimeline(model, ctx)` → `TimelineLayout`; `ctx` is `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `inline`. Reads `timeline.leftMargin` (150), `timeline.padding` (50), `timeline.disableMulticolor`, theme `fontSize`, `fontFamily`, `fontWeight`.
- `TimelineLayout { direction, sections, periods, connectors, axis, title?, bounds }`: boxes are `TimelineBox { x, y, width, height, ast, slot, label: MeasuredLabel, padding }`; sections add `section` and `band`; periods add `period`, `section?`, `events`. Lines (`axis`, `connectors`) carry `width` and an inline `arrow { tip, left, right }` triangle (D253) sized from v12's marker. `title` is a `PlacedLabel` left-aligned at `x` (D254). `bounds` is the viewBox (v12's, grown for strokes and arrowheads, D224).
- `timelineLayoutViolations(model, layout)` → `string[]`: the spec's invariants for both directions (no NaN; counts and AST ids; no overlaps among boxes, title and section bands; events in column/row; connectors joining; axis spanning; sections containing; bounds).
- `TIMELINE_METRICS`: the only lengths (pitfall 13), enforced by `packages/conformance/src/timeline-layout-literals.spec.ts`.

## For the renderer (#311)

- Label offset inside a box is the renderer's: `padding / 2` classic, `padding` redux (events `padding / 2 + 3`). Boxes are measured at theme `fontWeight`, so draw labels at it.
- `slot` is unbounded; wrap it to the palette (v12 class `section-<slot − 1>`, GAPS #311).
- Connectors are dashed (`5,5`); axis 4 px, connectors 2 px, as v12's attributes. Redux draws them at `strokeWidth`: if #311 changes the width, pass it into the layout so the arrowheads and bounds follow.
- MIGRATION.md rows: TD section spacing, D251 grouping, D252, D253, D254 (GAPS #337).
