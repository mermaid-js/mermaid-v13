## Exports (`@mermaid-js/diagram-timeline`)

- `TimelineTokenKind` (`src/parser/tokens.ts` `T`): one kind per `timeline.jison` terminal (`Timeline`, `TimelineLR`, `TimelineTD`, `Title`, `AccTitle`, `AccTitleValue`, `AccDescr`, `AccDescrValue`, `AccDescrMultilineValue`, `Section`, `Event`, `Period`, `Invalid`, `Eof`), plus `AccDescrMultiline` and `AccDescrMultilineEnd` (jison returns no token). Line breaks are core `Kind.Newline`; skipped `#…`, `%…`, `x%%…` are `Kind.Comment` trivia.
- `JISON_NAMES`: kind → jison terminal (dev/test only, never shown to users).
- `timelineTokens(src)` → `TimelineToken[] { kind, text, range }`: significant tokens, `text` as v12's parser read it (entities decoded, CRLF as LF, removed spans cut).
- Internal for #336: `lex(src, bodyStart, view)` in `src/parser/lexer.ts` returns the full `TokenStream` (trivia included, ends in `Kind.EOF`); build `view` with `sourceView(src, pre.bodyStart, directives)` as `parser/index.ts` does.

## Token facts the parser needs (all v12's)

- Images are raw: `title` is `title<\s>…` (`substr(6)`), `section` is `section<\s>…` (`substr(8)`), `event` is `:<\s>…` (`substr(2)`), periods keep trailing blanks. `\s` may be a line break, so a bare `title`/`section` takes the next line.
- `NEWLINE` is unreliable (`\s+` eats breaks after blanks); the grammar needs no separator. Every stream ends with `Eof` (or an empty acc value when lexing ends inside an acc state).
- `timeline` keywords are word-bounded: `timeline RL` is `Timeline` + `Period "RL"`. A `:` that starts no event is `Invalid`. jison never throws on timeline text, so there is no `Kind.Error`.
