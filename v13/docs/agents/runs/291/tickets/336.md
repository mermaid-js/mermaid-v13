# #336 T2 grammar, parser, model and AST: handoff

Branch `feature/336_timeline-parser`. `TimelineModel` (`src/model.ts`) adopted; one additive field, `titleAst?` (the in-text title's `st:<n>`, undefined for a front-matter title).

## Exports (`@mermaid-js/diagram-timeline`)

- `parseTimeline(src, { preprocessed?, keepTokens? })` → `ParseResult<TimelineModel, TimelineDocument>`; never throws. `detectTimeline(src)` (v12's case-sensitive `/^\s*timeline/` after front matter and directives, for T5).
- AST (`src/parser/ast.ts`), flat in source order: `Header` (`direction`), `Title`/`AccTitle`/`AccDescr` (`text`), `Section`, `Period`, `Event` (`text`, `period` index). Ids `sec:<n>`, `per:<n>`, `ev:<p>.<k>`, `st:<n>` for the rest (`st:1` the header). Statement spans `header`, `title`, `accTitle`, `accDescr`, `section`, `period`, `event`. No symbols; no probe yet (T6 #318).
- Model text as v12's DB kept it: period raw, section `substr(8)`, event `substr(2)`, title `substr(6)` (last wins, else front matter, D218); acc values trimmed (`accDescr` with v12's `\n\s+` fold).
- `accDescr {}` is an `AccDescr` node (`st:<n>`) that sets nothing; the grammar names `accDescr {` and `}` (jison returns no token for them). Recovery skips to the next line, or stops after a token that runs over a line break.
- Errors: `UNEXPECTED` (no header, a second header, a `:` that starts no event, an empty `accTitle:`/`accDescr:` at the very end), `UNCLOSED_DESCRIPTION`, `TIMELINE_EVENT_BEFORE_PERIOD` (semantic; the statement stands).
