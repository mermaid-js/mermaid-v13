# #311 T4 SVG renderer: handoff

Branch `feature/311_timeline-renderer`. Draws `TimelineLayout` through `SvgWriter` for both directions (D250); no plugin export yet (the parser, #336, is not merged).

## Exports (`@mermaid-js/diagram-timeline`)

- `renderTimeline(model, layout, ctx, w)`; `ctx: TimelineRenderContext` = `Pick<RenderContext, 'config' | 'theme' | 'idPrefix' | 'version'>`. T5's plugin: `render: (m, l, ctx, w) => renderTimeline(m, l, ctx, w)`, `layout: (m, ctx) => layoutTimeline(m, ctx)`.
- Reads `timeline.useMaxWidth` (default true) and the theme only. Root `class="mermaid mermaid-timeline"`, `aria-roledescription="timeline"`, `<title>`/`<desc>` from `accTitle`/`accDescr`.
- Structure: section `g.timeline-node.section-<slot mod 12 − 1>[data-id][data-ast=sec:n]`; period `g.taskWrapper[data-ast=per:n] > g.timeline-node`; event `g.eventWrapper[data-ast=ev:p.k] > g.timeline-node`; each node holds `path.node-bkg`, `line.node-line-<n>` (classic) and its `text[data-id]`. Lines: `g.lineWrapper[data-id] > line + path.arrowhead` (inline, D253). Title `text.timeline-title`.

## Theme variables (core, new)

`timelineRadius` (5 / 0), `timelineLabelOffset` (`0.5 * padding` / `padding`), `timelineEventLabelShift` (0 / 3), flag `timelineScaleColors` (true / false): classic and neo / redux (D227). `usedBy` gains `timeline` on `mainBkg`, `nodeBorder`, `textColor`, `strokeWidth`, `dropShadow`. Schema, `gen:config`, `gen:theme`, MIGRATION "Theme geometry" rows done. `layout/env.ts` `scaleColors(theme)`: the layout draws the axis and connectors at `strokeWidth` when it is false.
