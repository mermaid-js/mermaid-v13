## Parser changes (T2's output)

- **Probe** (R-LANG-7): `ProbeCursor` with a probe; the lexer records its jison start condition as the mode (`INITIAL`, `acc_title`, `acc_descr`, `acc_descr_multiline`; an `acc…` keyword's blanks are already the value's mode, a one-line value holds the offset at its end). Expected kinds: the header kinds at the start, `TimelineLR`/`TimelineTD` after a bare `timeline` while the offset is on its line, the seven statement kinds at every statement start. Follows `}` and `INVALID`.
- **Section spans** (D259 folding): each `section` statement span is a block holding every statement after it, ending at the last non-blank character before the next `section` (or the end): comment lines stay in, blank lines do not. The AST stays flat.
- `accTitle:`/`accDescr:` with nothing after it at the very end: the error range is now zero-width after the keyword and its blanks on that line (was the keyword), so a just-completed `accTitle: ` is the statement still to be written (completion-validity spec).

## Behaviour

- Completion: `timeline`, `timeline LR`, `timeline TD` in an empty text; `LR`, `TD` after a bare `timeline`; `title `, `section `, `accTitle: `, `accDescr: ` at a line start. Prefix matched without regard to case (the lexer's). Nothing in a period, event, title or section text, an acc value or outside code.
- Hover: keyword docs from `generated/docs.ts`; for `title …`/`section …` only the keyword. No hover on periods, events, values.
- Definition/references empty, rename refused by the service ("There is no id or class name here to rename.").
