Branch `feature/315_timeline-integration`. `timeline`, `timeline LR` and `timeline TD` render through `createMermaid()`, `mermaid/slim` + `timeline`, the CLI and the dev gallery; the language service loads the facet from the registry.

## What changed
- Manifest `{plugin: diagram, id: timeline, types: [timeline], formats: [svg], export: timeline, language}`, version `13.0.0-alpha.0`, README, `repository`. `src/plugin.ts` (`timeline`, `layoutKind: 'custom'`, no `configDefaults`), `src/labels.ts` (`DiagramPlugin.labels`: title, sections, periods, events), `TimelinePlugin` type. `gen:registry`: row after `flowchart-v2`, before `gitGraph`; format matrix svg yes, ascii no (`UnsupportedFormatError`, D216). `mermaid`, `language-server` depend on it; optional peer of `language-service`.
- Config (`gen:config`, GAPS #315): section and `leftMargin`, `padding`, `useMaxWidth`, `disableMulticolor` honoured, unset = v12's merged-default values (150, 50, true, false); top-level `fontSize` honoured as v12 read it (box height `0.55 × fontSize`, TD axis ends; layout `env.ts` now reads it, text keeps the theme size); the 19 sequence-copied keys and `useWidth` ignored. `timeline.theme`/`layout` stay pending (as pie, journey, sequence). MIGRATION.md: "Timeline config" section, LR axis-end and `useMaxWidth` rows.
- Theme: `usedBy` already complete (`theme-used-by.spec.ts` checks both ways; palettes and the gradient are read through `theme.palette()` / `theme.gradient()`). New `Theme.paletteRgba(name)`; `render/paint.ts` no longer imports `@mermaid-js/core/theme` by value (`PALETTE_SLOTS` = 12 there).
- Language (#318 list): unlisted-facet row and the conformance eager row removed; `LEZER_HIGHLIGHTERS` / `MONARCH_HIGHLIGHTERS` rows and generated files; `adapters-agree`, highlighter specs, keyword completion, both first-paint e2e specs cover timeline.
- Baselines: 27 fixtures in `e2e/diagrams/timeline/baseline/` (11 themes LR; TD in default, redux, redux-color, neo, neo-dark; no sections LR/TD; D251 leading periods and repeated names; 13 sections; line breaks; tall period; front-matter title + acc (listed divergence); config options LR/TD; palette overrides; redux + gradient). All 57 timeline e2e files now run in `mmd-snapshots`. Gate-corpus counts 30 → 57, YAML digest updated.
- Release: changesets (`diagram-timeline` first release, `mermaid` + `core`), RELEASING.md, publish and pack-closure lists.
