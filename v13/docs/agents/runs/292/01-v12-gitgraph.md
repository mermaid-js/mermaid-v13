## 1. Grammar — `$L/gitGraph/gitGraph.langium`, `reference.langium`, `common/*`

- `gitGraph.langium` L5–13 entry: `NEWLINE*` header (`'gitGraph'` | `'gitGraph' ':'` | `'gitGraph:'` | `'gitGraph' Direction ':'`) then `(NEWLINE | TitleAndAccessibilities | statements+=Statement)*`. - L23–24 `Direction: dir=('LR'|'TB'|'BT')`. `gitGraph TB` (no colon) and `gitGraph:TB` are rejected (probed); `gitGraph LR :` is accepted.
- L26–33 `Commit`: `'commit' ('id:' id=STRING | 'msg:'? message=STRING | 'tag:' tags+=STRING | 'type:' type=(NORMAL|REVERSE|HIGHLIGHT))* EOL`. Bare STRING is the message. Repeats: last `id`/`msg`/`type` wins, tags accumulate in order (probed).
- L34–37 `Branch: 'branch' name=(REFERENCE|STRING) ('order:' order=INT)? EOL`. L39–45 `Merge` (`id:`/`tag:`/`type:`). L47–48 `Checkout: ('checkout'|'switch') branch=…`. L50–56 `CherryPicking` (`id:`/`tag:`/`parent:`); no option is required by the grammar.

## 11. Surprises

1. The header needs no line break: `gitGraph commit`, `gitGraph:commit`, `gitGraph TB: commit` are accepted (probed). The spec's grammar reads "Then newlines, … statements".
2. Duplicate ids are not always a self-parent: `A`, `B`, `A` gives `B → A(later)` and `A → B`, a two-commit cycle, and the first A is gone (probed). D264 describes only the consecutive case; the layout's closest-parent and the arrow code both meet a parent drawn after its child.
3. D267 says v12 "ignores a user's `tagLabelBorder`": it does not; every theme re-applies overrides after deriving (probed). The decision (honour it, `tagBorder` an alias) still matches v12.
4. Corpus: 9 `%%{init}` files but only 3 have `themeVariables` (6 set `gitGraph` options); one fixture has a front-matter `title` (nightly 66), which v12 draws.
5. INT outranks REFERENCE: `branch 123` is rejected, `branch 10abc` lexes `INT REFERENCE` (rejected); `branch 1.5` is a name (probed). The spec only covers `order: 1.5`.
6. Colour moduli: commits/arrows always use 8 slots, branch labels 12 only on redux geometry; but redux/redux-dark draw every slot `nodeBorder` and redux-color draws `borderColorArray[i % 12]`, so the visible split is redux-color/redux-dark-color only. Redux themes never read `git*`, and neo uses `git*` from slot 1 (slot 0 `nodeBorder`).
7. `useGradient` (neo, neo-dark) adds `<linearGradient>` whatever `look` is; drop shadow needs `look: neo` and a redux theme. The measuring pass leaves two empty `<g>` groups, and `drawCommitTags` reverses the DB's tag array in place.
8. `rotateCommitLabel` defaults to true, yet only 1 corpus file sets it true and 19 set it false; `mainBranchOrder` only ever appears as 2.
9. `NUMBERED_PALETTES` and `paletteSlots` are fixed to 12 slots; D267's 8-entry `git`/`gitInv`/`gitBranchLabel` palettes need a length per palette (`git0`–`git7`), and git's hue steps (−30, −60, −90, +60, +120) are not `HUE_STEPS`.
