**Lexer facts for T2:** a word keyword yields to `REFERENCE` only when `REFERENCE` is longer (`commit:` is `commit` + `:`, `commit.` is `commit` + error). `gitGraph:` is one token, `gitGraph :` is two. `TITLE` never yields (`titled` → `TITLE` + `REFERENCE d`). `INT` beats `REFERENCE`: `branch 123` gives `INT`, `branch 10abc` `INT REFERENCE`, `branch 10.5` `INT 1`, `INT 0`, error; `0` never looks ahead (`007` is three INTs). A name ends at its last `[-\w]` (`a.` → `a` + error at `.`). Error tokens span what Chevrotain skipped. Title/accessibility images keep v12's leading blanks, stop before `%%`, untrimmed; value conversion is T2's.
