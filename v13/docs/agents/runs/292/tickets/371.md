**Deviations** (also GAPS.md #371):
- Where v12 drew branch labels over each other (TB: a long name after a short one, since v12 spaces by the previous name only; LR: names of 4+ lines), the lane moves out until the boxes are 10 apart (`labelGap`). v12 positions are kept wherever they did not overlap (as D224).
- Cycles (D264): only parents with a smaller `seq` (never the commit itself) count for `parallelCommits`; a commit with none is placed as a root. v12 threw in BT parallel and drew pass-dependent positions elsewhere.
- Arrows in seq order; v12 used DB map insertion order, which differs only for duplicate ids (lane picks for reroutes there).
- Branch label text: v12's first baseline (group top + 1em), with the group centred in its box minus 2; TB redux is 1 px lower than v12's `-2·padY + 7`.
