# #369 T4a: `git`, `gitInv`, `gitBranchLabel` palettes and label variables (branch `feature/369_gitgraph-palettes`)

## Exports (`@mermaid-js/core/theme`)

| Name | Kind | Slots | Overrides |
| --- | --- | --- | --- |
| `git` | palette (literal colours) | 8 | `git: [...]` or `'a, b'`; `git0`–`git7` |
| `gitInv` | palette | 8 | `gitInv: [...]`; `gitInv0`–`gitInv7` |

- Read: `theme.palette('git' | 'gitInv' | 'gitBranchLabel')` → 8 `SafeColor`s in every built-in theme; slot for branch `i` is `i % 8` (the renderer decides, D267). `theme.color('tagLabelBorder')` etc.; sizes with `theme.number('commitLabelFontSize')`.
- Precedence per slot: numbered > author list > theme rule (as `cScale*`). `git8`+ is an unknown name (ignored). Unsafe colours drop with `THEME_VARIABLE_DROPPED`.
- `usedBy` is `[]` for the label variables: T4 adds `'gitGraph'` when the renderer reads them (`theme-used-by.spec.ts` checks both ways). Palettes have no `usedBy`.
- Also exported: `PALETTE_LIMITS` (per numbered palette), `GIT_PALETTE_LIMIT` (8), type `NumberedPalette`. `PALETTE_LIMIT` stays 12 (cScale).

## Core additions

- `vocabulary.ts`: three palettes, eight variables, two tokens. `theme.ts`: `RE_SLOT` takes `git`, `gitInv`, `gitBranchLabel`; numbered limit 8 for them.
- Builders: `gitSources`, `gitPalettes`, `gitLabelRules`, `BASE_SECONDARY` (`specs/palettes.ts`); `classicGitLabels`, `fixedGit` (`specs/scales.ts`, lazy). No new DSL function.
- Rules follow v12 per theme (see `01-v12-gitgraph.md` §5 and GAPS.md "#369"): `default` fixed (constructor double pass), `dark`/`neutral` from `pie<n>` without `git<n>`, `neo`/`redux`/`redux-color` from fixed constants, `neo-dark` always lightened.
