## Behaviour

- Completion: `gitGraph`, `gitGraph LR:`/`TB:`/`BT:` in an empty text; `LR:`, `TB:`, `BT:` after `gitGraph` on its line, `:` after a direction; the nine statements at a line start (separator added unless the text has one; before `{` only `accDescr`); options per statement; `NORMAL`/`REVERSE`/`HIGHLIGHT` after `type:`; branches made before the cursor (main first, under its configured name; not the checked-out one after `merge`) after `checkout`/`switch`/`merge`, quoted when not a bare name; after a cherry-pick's `id:` the written ids not on the current branch (merges only with a `parent:`), after `parent:` the merge's written parents, quoted. Nothing in strings, text values or outside code. Keywords matched without regard to case.
- Hover: keyword docs (`generated/docs.ts`; only the keyword of `title`/`accTitle`/`accDescr`); a branch name: commits and `order:` (main: "set in config"); a commit id: branch, message, type, tags, for a merge what it merges and its parents; "a later commit takes this id" on a replaced one (D264). Nothing on messages, tags, numbers.
- Rename: branches and commit ids apart, quotes kept (D191); main refused at prepare (no occurrence; GAPS **Choice**). Folding: statement spans (`accDescr { … }`).
- Parser: probe mode `string` after an unclosed quote; `GIT_CHERRY_PICK_UNKNOWN_COMMIT` without `id:` ranged after the statement.
