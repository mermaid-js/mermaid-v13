## For H2

- Edge paint comes partly from the parent `<g class="edgePaths">` (flowchart, class, state: `stroke`, `stroke-width`, `fill: none`). Keep an edge as one `<path>` so it still inherits. An edge often has no `stroke` attr, and H1's `sketch` then draws no outline set, so give `sketch` a placeholder stroke for `edge` and leave it off the written path.
- Flowchart's `docs` shape draws inside `<g transform>`. The drawer's output sits inside it, so the geometry holds.
- Invisible shapes arrive with `fill: none` and `stroke: none`: flowchart's `text` and brace boxes (`node`) and state's region frame (`group`). Draw nothing visible for them.
- D308(a): no ER edge or marker is under an entity, so the underlay is dropped (GAPS.md, T1).
