Branch `feature/343_hand-drawn-integration`. No new exports. Activation: `registerExternalDiagrams([handDrawn])`, or install it: Node discovery (R-PLUG-5, #218) finds it.

## What landed

- Baselines: `e2e/diagrams/{flowchart,class-diagram,state-diagram-v2,er-diagram}/baseline/handdrawn/{default,redux,neo,neo-dark}.mmd` (D307), one representative diagram per type with `look: handDrawn`. Under `baseline/`, not `<type>/handdrawn/`: the level below a type is the tier (GAPS.md, H3). The mmd snapshot run, the gallery and `adapter.spec.ts` pick them up.
- The page adapter (`packages/dev/src/adapter.ts`) registers the plugin, as it does math, so the e2e page, gallery and dev server sketch. `adapter.spec.ts` checks the look and the 4 × 4 baseline set.
- `packages/plugin-hand-drawn/src/unsketched.spec.ts`: the seven types v12 never sketched, over each folder's whole corpus, give the same SVG bytes and no added warning with the plugin registered and `handDrawn: true`. Sequence runs (222 files); gantt, pie, timeline, journey, quadrant and gitGraph are skipped until ported (`supportsFormat`).
- Activates on install: the SSR app (`e2e/platform/ssr`) depends on the packed plugin; with no registration code `look: handDrawn` is sketched (npm, pnpm, bundled server), and with `discovery: false` it is plain with `LOOK_REMOVED`.
- R-PLUG-8 (#247, `tools/check-deps/optional-size.spec.ts`): already generic over manifests; the plugin is now named in its assertion. Core's bytes are identical with and without it.
- MIGRATION.md: "Hand-drawn look" and "Hand-drawn SVG structure" (install, keys, section `look`, seed 0 fixed, bounds not from the sketch, paints and families, roles and roughness, unsketched types, text output, no `rough-node`/`data-look`, groups, edges, ER underlay dropped, alt composites solid), plus the Packages, Themes and At-a-glance rows.
- Config reference: `pnpm gen:config` gives no diff; the plugin's `handDrawn` and `handDrawnSeed` sections were already there (H2).
- `packages/bench/src/normalize.ts` unchanged; it still strips `look: handDrawn` (its spec covers it).
- Fix in H1's `sketch.ts`: tsx (the dev server) handed roughjs's bundle over as `{ default: rough }`; the import now unwraps it.
