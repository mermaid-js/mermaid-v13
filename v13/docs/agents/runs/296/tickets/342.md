# H2 (#342): the plugin package, its drawer and config fragment

Branch `feature/342_hand-drawn-plugin`. `@mermaid-js/plugin-hand-drawn` is now an extension (manifest `plugin: extension`, `id: hand-drawn`, `export: handDrawn`). No `postRender`, so the stream writer stays.

## Exports (`src/index.ts`)

- `handDrawn` (also default): `ExtensionPlugin` with `config` (the fragment), `outline` (`active`, `draw`, in `drawer.ts`) and `postLayout` (text output's warning). Register: `await mermaid.registerExternalDiagrams([handDrawn])`.
- `NODE`, `GROUP`, `COMPOSITE`, `MARK`, `EDGE`, `optionsFor(role, attrs)` (`roles.ts`): the role table. A `part` with class `outer` or `inner` (state composite) is `COMPOSITE`; other parts and dividers are `NODE`.
- H1's `sketch`, `roughSeed`, `strokeLineDash` and types, unchanged.

## Behaviour

- `active(ctx)`: `ctx.config.handDrawn === true`; it also stores `handDrawnSeed` for that render's `draw` calls (module state; one SVG render draws at a time).
- Non-edge roles: `<g …leaf attrs but geometry and paint>` holding roughjs's paths (fill, then outline). Stroke extras (`stroke-opacity`, `-linecap`, `-linejoin`, `-dashoffset`, `-miterlimit`) go on the outline path, `fill-opacity` on the fill path (as `stroke-opacity` for hachure). Nothing to sketch (no fill and no stroke, so hit boxes and state region frames; geometry `sketch` refuses) → `false`, the plain leaf.
- `edge`: one `<path>`, the leaf's attrs with roughjs's `d`. The sketch gets `currentColor` when the leaf has no `stroke`; the written path never gets one, so it keeps inheriting from `edgePaths`. `stroke: none` → plain.
- Text output: `postLayout` with `units === 'cell'` warns `ASCII_DROPPED` (`feature: 'handDrawn'`) once per render when `handDrawn` is true, any type.

## Config (`schema/config.fragment.yaml` → `src/generated/config-fragment.ts`, `pnpm gen:config`)

- `handDrawn` (boolean, false), `handDrawnSeed` (number, 0). `handDrawnSeed` left core's schema (core defaults, key tree, types, language-service schema regenerated).
- Aliases `look: handDrawn` and `<section>.look: handDrawn` → `handDrawn: true`, for all 31 core sections with a `look` (`index.spec.ts` checks the list against core's key tree).
- `LOOK_REMOVED` names `@mermaid-js/plugin-hand-drawn`: added in `mermaid`'s `toWarning` (`api.ts`), not core, since check-deps forbids core naming an optional package (as D173).
