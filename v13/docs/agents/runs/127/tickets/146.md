# #146 — T4 SVG renderer

Branch `feature/146_state-render` (merged `feature/127_state-diagram`).

## Exports (`@mermaid-js/diagram-state`)
- `state`: the `DiagramPlugin` object (`id: 'state'`, aliases `stateDiagram`, `stateDiagram-v2`,
  `formats: ['svg']`, `layoutKind: 'graph'`; `parse` → `parseState`, `layout` → `layoutState`,
  `render` → `renderState`). Not registered: T5 adds the manifest, `configDefaults`, registry.
- `renderState(model, layout, ctx, w)`: the whole `<svg>` through `SvgWriter` (`src/render/`:
  `render.ts` sections, `shapes.ts` node shapes, `edges.ts` curved/rounded routes and the point
  arrowhead, copied from flowchart since packages cannot import each other).
- `StateRenderContext` gains the optional `idPrefix`, `version`, `securityLevel`, `linkSchemes`.
- `@mermaid-js/diagram-state/testing`: `renderForTest(src, { config, idPrefix, stream })` →
  `{ svg, tree, warnings, parse, layout, config }`, through the plugin's own entries.

## Drawing
- Groups `clusters`, `edgePaths`, `edgeLabels`, `nodes`; v12 class names; `data-id` + `data-ast`
  on every state, composite, region, transition and note (note connectors: `data-id` only).
- Region dividers: dashed lines from `StateLayout.dividers`, in the composite's group. Note
  connectors dashed, no arrowhead. Palette slots per composite (v12 `colorSlotFor`).
- Colours and sizes from theme variables only (D152), guarded by `state/render-theme-names.spec.ts`.
- MIGRATION.md "State diagram SVG structure": every change from both v12 renderers.

## Tests
- `diagram-state/src/render/render.spec.ts` (root, shapes, notes, composites, regions, palette,
  geometry, links).
- `conformance/src/state/render.spec.ts`: both corpora (144 files): well-formed, `assertInert`,
  deterministic, stream = tree, no NaN, viewBox, AST round trip, one divider line per divider,
  script-like sources inert, no colliding ids.

Size (esbuild minify, gzip -9, the `state` plugin): 19.7 KB alone (core external), 62.7 KB with core.
