# #148 — T5 integration

Branch `feature/148_state-integration` (merged `feature/127_state-diagram` at `2243c86ba`).

## What changed
- `@mermaid-js/diagram-state` is published: `private` dropped, `13.0.0-alpha.0`, README,
  `THIRD_PARTY_NOTICES` (Pele, for `render/edges.ts`), changeset `.changeset/state-diagram.md`.
- Manifest `{ id: state, types: [stateDiagram], formats: [svg], export: state, language }`. v12's
  one `stateDiagram` detector takes both keywords (D101); `gen:registry` keeps the v12 order.
  `supportsFormat('state'|'stateDiagram', 'ascii')` is false; `format: 'ascii'` throws
  `UnsupportedFormatError` (D100). Format matrix: svg yes, ascii no.
- Config: `SECTION_OWNERS.state` → `stateConfigDefaults`, `state.configDefaults`. Honoured: the
  section, `theme`, `layout` (v12's `elk` default, drawn with `layered` until an ELK plugin, D106),
  `useMaxWidth` (state override of the base key), `wrappingWidth`, `minNodeWidth`, `nodeSpacing`,
  `rankSpacing`. Ignored with a reason: `titleTopMargin` (D122), `useWidth`, and the 15 sizes only
  v12's old dagre renderer read (12.2.0 sends both keywords to the unified renderer). No theme
  variables: the only redux/classic difference is #192 (D120).
- `mermaid`, `language-server` depend on it; `language-service` has it as an optional peer (the
  generated `facets.gen.ts` imports `./language`); `pending-facets.ts` deleted.
- `UNCLOSED` → `UNCLOSED_COMPOSITE`; `state x |` offers `{`. Bench `language-bundle.spec.ts`
  covers state. Fixture discovery gains `FIXTURE_TYPE_EXCEPTIONS` (the one `info` fixture), so
  `state-diagram-v2` runs in e2e; all 144 corpus + 25 baseline files snapshot.
- Baselines: 25 fixtures in `e2e/diagrams/state-diagram-v2/baseline/` (states, composites,
  notes, transitions, text, 9 themes); all agree with v12 in the conformance specs.
- MIGRATION.md: state "Config" section; D121/D122 cited in "State diagram SVG structure".
- Spec `mermaid/src/state.spec.ts`: both keywords via `createMermaid().render()`, renderSync, SYNTAX, svg-only, config, slim.
