# #144 — T3 graph builder and layout

Branch `feature/144_state-layout` (merged `feature/127_state-diagram`).

## Exports (`@mermaid-js/diagram-state`, `src/layout/`)
- `layoutState(model, ctx)` → `StateLayout`: builds the graph, calls `ctx.layout` (default core
  `layered`, D106), then stretches region frames along the flow to the composite's inner extent
  and returns `dividers` (`{ composite, x1, y1, x2, y2 }`, midway in each gap). `state` holds the
  views; the engine's own `groups` map is copied, not mutated. This is what T5's plugin `layout` calls.
- `prepareState(model, ctx)` → `StatePrepared`: `graph`, `nodes` (`StateNodeView`: `shape`
  `state|described|start|end|choice|fork|join|note`, measured `label`, `rows` for a described
  state, `w`, `h`, `flow`, `style`), `groups` (`StateGroupView`, outermost first, `region` flag),
  `edges` (`StateEdgeView`, `note` flag), `views`, `regions` (composite → region ids in order).
- `StateRenderContext` (structural subset of the pipeline's), `stateMetrics(units)` (state's px/cell
  shape table, D108), `STATE_LAYOUT_DEFAULTS` (`wrappingWidth`/`minNodeWidth` 120 px, for T5's
  `configDefaults`).

## Model → graph
- Composite: titled group, padding from `units.builder`; `direction` = its own, else TB (v12
  `getDir`). Split by `--`: its side padding is 0 and each region (title-less group, D111) carries
  `groupPad`, so regions tile it. Transitions to a composite end at its group id; sibling-region
  edges go in unchanged (D113). Notes: node `note:<k>` in the target's scope, edge `<from>-<to>`
  (`left of`: note → state). Labels are markdown (v12 `labelType`); spacing from `state.nodeSpacing`/`rankSpacing`.
