# #138 — T1 lexer parity gate (stateDiagram.jison)

Branch `feature/138_state-lexer`. New package `packages/diagram-state` (`private: true`, no
`mermaid` manifest, no registry entry: T5 adds those and drops `private`).

## Exports (`@mermaid-js/diagram-state`)

- `stateTokens(src)`: significant tokens `{ kind, text, range }`. `text` is the image v12's lexer
  gave (CRLF as LF, comment lines and dropped `;` cut, jison's trims applied; entities stay
  `#name;`). `range` is a source range.
- `StateTokenKind` (the `T` object), `JISON_NAMES` (kind → jison terminal, dev/test only).
- Internal for T2: `parser/lexer.ts` `lex(src, view)` returns `{ tokens: TokenStream, viewStart,
  viewEnd }` (trivia: comments, directives, in source order); `parser/source.ts` `sourceView()`
  builds v12's text plus the source offset of each character. Read values from `view.text`.

## How it lexes

- Rule order per start condition copied from the compiled v12 lexer (`conditions` table in
  `mermaid-v12/dist/chunks/mermaid.core/stateDiagram-v2-*.mjs`), case-insensitive.
- jison quirks kept: `.*direction…` anywhere on a line, `[\s]+` swallowing a line break, `processId`
  (`%%` in an id), the empty-image tokens at a value or text end, `NL` at `<<EOF>>`.
- Kinds with no terminal (`State`, `Quote`, `Marker`, `EndNote`, `AccDescrOpen/Close`,
  `ScaleWidth`) keep text jison consumes silently. `MultiWordState` is where v12 threw.
- After an error: a value state is left (a zero-width `Error`); elsewhere one char is skipped.

## Gate

- `packages/conformance/src/state/lexer-parity.spec.ts`, oracle `src/state/jison-lexer.ts`.
  593 of 600 sources compared and all match: 145 e2e (one `info` file is skipped), 120 harvested
  (`corpus/state-v12-specs.json`, `pnpm --filter @mermaid-js/conformance harvest:state`), 35
  edge cases, each one also with comment lines added. The exclusions are listed in the spec header.
- Unit tests: `packages/diagram-state/src/parser/lexer.spec.ts` (ranges, trivia, linear time).
- Size: 5.7 KB gz on its own (core external), 12.3 KB with the core parts it uses.
