## Behaviour

- Completion: by the probe's expected kinds (keywords, ids, `[*]`, `-->`, `:::`, `--`, `}`), plus line
  contexts where v12's lexer leaves nothing to test (`note |`, `note left of |`, `direction |`,
  `state x |` markers, `class|style |`, `classDef |`, `:::|`). Nothing inside text or comments.
- Hover: state (kind, labels, composite/region, classes, transition and note counts, "not drawn"),
  class (`classDef`, users), `[*]` (which start/end), `-->` (its transition), keywords from `stateDocs`.
- Folding: composites (nested), multi-line notes, `accDescr { }`, from the statement spans.
- Rename: `isValidId` reads the name back in every context a state id appears in; names `class` and
  `style` cannot hold (`[\w,]+`: `café`, `a.b`, `a,b`) are refused with that reason.
- Diagnostics come back in source order (the parser adds `STATE_NOT_DRAWN` last).
