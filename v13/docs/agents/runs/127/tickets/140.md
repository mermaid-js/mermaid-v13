## Result

Verdict: **adopt the nested-group model with a named workaround; no state T0.** Full findings and
per-fixture table: `v13/docs/research/state-regions.md`.

- Region = `LayoutGroup` with `parent` = composite group, no title, no direction, no edges
  between regions. Passes `validateLayout` plus the region checks on 29/29 corpus files and
  15/17 synthetic cases (curved, stepped and `grid: 1`).
- Fails only for a transition between two sibling regions (S7, S17): the edge ranks the
  regions and stacks them. Workaround W4: leave such edges out of the engine's graph, draw them
  in the builder, warn (non-UML).
- Builder drawing pass: stretch region frames along the flow to the composite's inner extent;
  dividers go in the middle of each gap.
- A crossing edge drops a composite's `direction` (v12 parity, core `inheritCrossedDirections`).
