# #142 — T2 grammar, parser, StateModel and AST

Branch `feature/142_state-parser` (merged `feature/127_state-diagram` with #181).

## Exports (`@mermaid-js/diagram-state`)

- `parseState(src, { preprocessed?, maxDepth?, keepTokens?, probe? })` → `ParseResult<StateModel, StateDocument>`;
  never throws. `detectState(src)` (v12's one detector, both keywords, D101).
- `StateModel`: `direction`, `states` (`id`, `ast`, `kind`, `descriptions`, `parent`, `classes`, `styles`, `dir`),
  `regions` (`<composite>:region<k>`), `transitions` (`edge<n>`, `from`, `to`, `label`), `notes`
  (`target`, `side`, `text`), `classes`, `links`, `accTitle`, `accDescr`, `warnings`. Insertion order;
  ids as v12 (`root_start`, `X_end`, `X:region1_start`). Built by `model.ts`, a step-by-step port of
  v12's `docTranslator` → `extract` → `dataFetcher`, so it is what v12 drew (one node per id, last parent).
- AST (`ast.ts`): `n:A`/`n:A@2`, `n:[*]start`, `n:X/[*]end`, `e:A>B#2`, `s:X`, `r:X#1`, `note:1`, `st:k`.
  The model's `ast` fields point at these.
- Warnings where v12 silently draws nothing: `STATE_NOT_DRAWN`, `FLOATING_NOTE`, `EMPTY_REGION`.
