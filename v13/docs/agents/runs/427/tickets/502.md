## Renderer

- v12's order: `g.nodes > g.node[data-id data-ast transform] > rect[width height fill]`, `g.node-labels[font-size=14 fill=textColor] > text[data-id x y dy text-anchor]` (outlined: every `text.sankey-label-bg[stroke=mainBkg stroke-width=4 stroke-linejoin=round]`, then every `text.sankey-label-fg`), `g.links[fill=none stroke-opacity=0.5] > g.link[data-id data-ast style=mix-blend-mode:multiply] > path[d stroke stroke-width]`. Constants from `layout/metrics.ts`.
- Colours are the layout's (`fill`, `sourceFill`, `targetFill`, now `SafeColor`): T3's slot rule changed so a `nodeColors` entry counts only when it is a string passing `checkColor`; any other counts as absent and the node takes its Tableau10 slot (the spec's "dropped, and the default used"; v12 drew it black). `linkColor`: modes matched before `checkColor`; else one checked colour, else the default gradient (`w.linearGradient({ x1: path.from.x, x2: path.to.x, from, to })`, shared when equal). Nothing is ever left unpainted; #503 adds `SANKEY_COLOR_INVALID`.
- Root: `class="mermaid mermaid-sankey"`, `role="img"`, `aria-roledescription="sankey"`, viewBox = `layout.bounds` (ceil), `width="100%"` + `max-width` unless `useMaxWidth: false` (v12 12.2.0's resolved default is `true`, GAPS #502), `font-family` the theme's, the `auto` sheet. Front-matter `title` → `<title id="<prefix>-title">` + `aria-labelledby` (D396). No other id.
- Checked against v12 12.2.0 in Chromium (bench's `mermaid-v12-frozen`, Playwright): node/link numbers, label anchors and `dy`, and computed styles in `default`, `dark` (outlined) and `neo` + `look: neo` (labels fill `textColor`, halo `mainBkg` 4 px round, links blend `multiply`, `stroke-opacity` 0.5, no neo branch).
