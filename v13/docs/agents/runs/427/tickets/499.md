## Exports

## What T4 draws from it

- `nodes` in model order: `x0 x1 y0 y1` (d3's box: `g.node` `translate(x0,y0)`, rect `x1-x0` × `y1-y0`), `colour` (`nodeColors` entry or Tableau10), `slot`, `ast` (`data-ast`), `label { text, x, y, dy, anchor, box }`: `y` is the centre, `dy` 0 or 4.9 (v12's `0.35em`, GAPS #502), `text` one line (D395).
- `links` in model order: `path { from, c1, c2, to }` (`M from C c1 c2 to`), `strokeWidth` (`max(1, width)`), `sourceColour`/`targetColour` (gradient `x1 = from.x`, `x2 = to.x`), `ast`.
- `bounds`: nodes and label boxes, no padding (D224; may start below 0 or run past the extent with outlined labels); `font` (14 px, `fontFamily`, 400), `labelStyle`, `width`/`height` (extent), `padding` (d3's `py`).

## Tests

- `packages/conformance/src/sankey/layout-d3.spec.ts`: the real d3-sankey 0.12.3 (resolved through `mermaid-v12`'s own dependencies, `sankey/d3.ts`; no package dependency) against `layoutSankey` on the gate corpus (1,100+ sources, cycles skipped) and on 66 generated DAGs of 2–200 nodes (`sankey/generated.ts`), 4 aligns × 6 configs: node boxes and layers, link width and centre lines, and d3-shape's path, within 1e-9 px (measured: 0 difference over 60,592 coordinates, bit-identical). `D3_NAN` lists the 4 cases where d3 writes NaN (every flow 0). Sensitive: a non-power-of-two flow scale, a changed tie-break or collision threshold fails it.
- `packages/conformance/src/sankey/layout-corpus.spec.ts`: invariants (no NaN, inside the extent, padding apart, heights/widths proportional, link ends on edges, widths sum to heights, colours, labels, inside the bounds) over the gate corpus and the DAGs, 4 aligns × 6 configs (height 0 included). `sankey-layout-literals.spec.ts`: no length literal outside `layout/metrics.ts`.
- Package: `layout/layout.spec.ts` (18, worked by hand from `sankeyRenderer.ts` with a 10 px/char measurer), `layout/invariants.spec.ts` (planted faults).

## Decisions (also in GAPS.md #499)

- Where d3 writes NaN, v13 does not (D394): every flow 0 gives `ky` 0 (nodes 0 high, spread as d3 spreads them); flows are scaled by a power of two first (bit-identical elsewhere, no overflow); a 0-high extent with one node per column pads by `nodePadding`. A cyclic model throws `circular link`, as d3 (the parser rejects it first).
- `nodeColors` counts own string entries only (v12's `nodeColors[id]` found `Object.prototype` members for `constructor`).
- `THIRD_PARTY_NOTICES`: d3-sankey 0.12.3, d3-array 2.12.1 (`sum`/`min`/`max`), d3-shape 1.3.7 (`linkHorizontal`), all BSD 3-Clause (read from the installed `LICENSE`s), in `files`.
