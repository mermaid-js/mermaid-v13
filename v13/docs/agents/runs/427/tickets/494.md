## Token facts the parser needs (oracle-checked)

- The lexer runs on v12's text: comments/directives cut, CR as LF, tag quotes as `'`, a style line's last `;` dropped (covered by the token before it), then `prepareTextForParsing` (trim `\s` off both ends; a run of line breaks is one `Newline` whose range covers the run, also inside quotes). A line of blanks is not collapsed: `Text "   "`.
- `Sankey` only in INITIAL (before the header), case-insensitive, `\b`: `sankey-betax` is `Sankey` + `Text -betax`; in the body `sankey` is text. Blanks after the header are a `Text` (v12 rejects).
- `Kind.Error` = one run of characters outside printable ASCII other than LF (tab, control, `é`, U+2028, NBSP, BOM, an entity `#…;`), in any state; lexing goes on in the same state. v12 stalls there and always rejects.
- Text ending inside quotes: a zero-width `EscapedText` at the end, no `Eof`. `""` is `OpenQuote CloseQuote` (v12 rejects: no `ESCAPED_TEXT`). `Eof` sits just past the last character v12 kept.

## Tests

- `packages/conformance/src/sankey/lexer-parity.spec.ts`: 1,070 sources (18 e2e, 14 harvested, 124 cases of which 9 are `line-separator-*`, each in six variants that change it: commented, CR-cut by a comment and by a directive, CRLF, blank lines doubled, a directive through every line); 1,062 lexed by v12, all equal; 171 stall (exclusion in the spec header; each asserted to run to the oracle's cap and to be rejected). Exactly 8 skipped: commented copies of one-line bodies where `%% cut` splits the header (asserted). `lexedText` is pinned to the text after `prepareTextForParsing`. Builders in `src/sankey/corpus.ts` (`sankeyCorpus`, `sankeyCases`, `sankeyGateCorpus`, `VARIANTS`; front-matter helpers shared with `kanban/corpus.ts`) for #496's model parity.
- `packages/diagram-sankey/src/parser/lexer.spec.ts`: one test per spec quirk (expected streams from the oracle), one token across removed spans (pitfall 4), CRLF/CR ranges, trivia order, empty input.
- `packages/conformance/src/sankey/stress.spec.ts`: 29 linear shapes (pie's ratio pattern): long fields, blank runs, unterminated quotes, stalls, entities, removed spans. An injected per-token scan fails 12 of them.
- Corpus: `corpus/sankey-v12-specs.json` (6 `sankey.spec.ts` sources, `energy.csv` with its comments, and 8 docs); `corpus/sankey-cases.json` (124: header, fields, characters, lines, values, comments, directives, front matter, title/acc, nodes/links, line separators as `\u2028`/`\u2029` escapes). `sankey` in `smoke.spec.ts`.
