# #56 handoff: packages/dev replaces packages/visual; `pnpm dev`

Branch `feature/56_dev`. `packages/visual` is gone; everything moved to the private `@mermaid-js/dev` (`packages/dev`). Playwright's webServer, `ci.yml`, `gallery.yml` and the e2e helpers point at it.

## Exports (packages/dev/src)

- `server.ts`: `startServer(port, { routes?, entries?, host? }) → DevServer { url, port, address, urls, close() }`. Listens on all interfaces unless `host` is set. `urls` is one URL per interface address, read from `os.networkInterfaces()` at startup. `close()` also ends open connections (SSE-safe), then disposes esbuild. It also exports `matches(route, method, pathname)` and re-exports `Route`.
- `routes.ts`: `Route { path, prefix?, method?, handle(req, res, url) }`, `builtInRoutes` (`GET /`, `POST /node-render`, `GET /smoke.mjs`, `GET /fonts/*`), and the helpers `readBody(req)` and `sendFile(res, file, type, missing?)`.
- `listen.ts`: `resolveDevPort(env, root)` (the v12 rule; an invalid override is ignored) and `listenUrls(boundAddress, interfaces)`. The second gives both families for `::`, IPv4 only for `0.0.0.0`, and drops duplicates.
- CLIs: `src/cli/dev.ts` (root `pnpm dev` → `pnpm --filter @mermaid-js/dev dev`) loads `<root>/.env` with dotenv, takes its port from `resolveDevPort(process.env, REPO_ROOT)`, and prints `server.urls`. `src/cli/serve.ts` (the Playwright webServer) is the same server on `MERMAID_PORT`.
- The port root is `REPO_ROOT`, derived from the file location rather than `process.cwd()`, because `pnpm --filter` changes cwd. It hashes the same as `playwright.config.ts`, which runs from the root.

## How to extend (SSE, file API, explorer)

- **New route:** add a `Route` to `builtInRoutes`, or pass it in `startServer(port, { routes })`. Routes are tried in order, first match wins. Exact `path`, or `prefix: true` for a subtree (e.g. `{ path: '/dev/api/', prefix: true }`). If `method` is set, other methods fall through. Anything unmatched goes to esbuild (the `www/` static files plus bundles).
- **Async handlers:** a throw or rejection becomes a 500 carrying the message (or a destroyed socket if headers were already sent).
- **SSE (`/events`):** a route that calls `res.writeHead(200, {'content-type':'text/event-stream'})` and keeps `res` in a client set. `close()` ends those connections. The watcher will need the esbuild ctx to rebuild; it is not exposed yet, so add a hook to `ServerOptions` when the watch ticket needs one.
- **Explorer:** put its HTML under `www/dev/` (served statically) and pass its page script as `entries: { explorer: '<abs path>.ts' }`, which serves it at `/build/explorer.js`. Its API goes in routes under `/dev/api/`.

## Viewer

`?graph=` accepts `code: string | string[]`. An array renders each entry in order into `#block0`, `#block1`, … with `idPrefix` `block<i>`. A string still renders into `#block`. The theme is detected from the first block.
