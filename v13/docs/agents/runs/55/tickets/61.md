# #61 handoff: Compare tab

Branch `feature/61_dev`. New dev dep in packages/dev: `pixelmatch@^7.2.0` (v12's). viewer.ts, context.ts and styles.css are untouched; `explorer.ts` gained two lines (the versions route and the `compare-pane` entry in `explorerServerOptions`).

## Server

- `src/versions.ts`: `versionsRoute({ registry?, now?, timeoutMs? })` → `GET /dev/api/versions` → `VersionsResponse { mermaid: { versions (newest first, prereleases included), distTags }, fetchedAt, stale }`. Reads npm's abbreviated document (`application/vnd.npm.install-v1+json`, small). Cache TTL `VERSIONS_TTL_MS` (1 h), concurrent requests share one fetch. Registry down: the last answer with `stale: true`; nothing cached: 502 `{ error }`.
- `explorerServerOptions` adds it after the explorer routes and the entry `compare-pane` (`/build/compare-pane.js`).

## Browser

- `www/dev/compare-pane.html` + `src/browser/compare-pane.ts`: one iframe per side, one mermaid each. The protocol (`ready → load {bundle: {kind: 'dev'|'npm', url, label}} → loaded`, `render {text, config, background, requestId} → rendered {svg, width, height} | error`, `overlay {dataUrl|null}`) is typed there (`ParentMessage`, `PaneMessage`). Dev uses `createMermaid()` from `/mermaid.esm.mjs?build=<n>` with the interactions plugin and `devLayoutLoaders`; npm uses the CDN bundle's default export (ESM, mermaid ≥ 10).
- `browser/explorer/compare-model.ts` (pure, also used by the server): semver sort, `resolveVersion(choice, versions)` (`12` = newest stable 12.x, the default; `latest`; exact), `cdnBundleUrl`, `parseCompareUrlState`/`serializeCompareUrlState` (URL `version`, left out for the default, and `diff=1`), `npmRenderConfig(settings, prefersDark)`.
- `browser/explorer/compare-diff.ts`: `diffRenders(left, right, background)` (v12's, unchanged in behaviour).
- `tabs/compare.ts` (`dev-tab-compare`): iframes only while `active`. A new `ctx.build` recreates the left iframe; a new version the right one. Re-renders on any change of `ctx.text`/`ctx.settings` (unsaved edits included). D (document listener, ignored in inputs, `sl-*` and `.cm-editor`) or the Diff button toggles the overlay. An error shows in its own pane header (`.error[role=alert]`) and inside its iframe.
- Spec hooks: `.pane[data-side][data-status]` with `.title`, `iframe[data-side]`, `sl-select[data-role="version"]`, `sl-button[data-action="diff"]`, `[data-testid="compare-diff-status"][data-changed-pixels]`, the pane's `#svg-host svg` and `#overlay`.

## How to extend

- More choices (e.g. a v11 line): add the alias in `compare-model.ts` (`isVersionChoice`, `resolveVersion`) and an `sl-option` in `#renderSelect`.
- Another npm-side setting: map it in `npmRenderConfig`; the left side uses `renderConfig` from settings.ts.

## Tests

- `packages/dev/src/versions.spec.ts` (ports 9621, 9622; a local fake registry on port 0): order and dist-tags, cache within the TTL, refetch after it, stale answer with the registry stopped, 502 with no cache.
- `browser/explorer/compare-model.spec.ts`: alias resolution and URL round-trip.
- `e2e/dev/compare-tab.spec.ts` (own `startExplorerServer`): left pane renders dev with unsaved edits and shows its error (no network). Network specs pin `mermaid@12.0.0` → `12.1.0` and skip with "Offline, skipping the CDN side…" when the CDN or registry is unreachable: both panes render the same text and an npm-side error; the default resolves to `mermaid@12.x`; switching re-renders and sets `version`; D and the button toggle the overlay and `diff`; the URL restores both.

## Deviations / unmet

None unmet. `pnpm check` and `e2e/dev` (chromium, 28) pass after merging `feature/55_dev-server`. Deviations from v12: the left side is fixed to v13 dev (spec #55); no prerelease toggle and no pre-10 IIFE bundles; `layered` maps to v12's `dagre` and `auto` to `dark`/`default` by the colour scheme on the npm side. agent-browser blocks non-localhost fetches, so the CDN side can only be checked with Playwright. If #62's COOP/COEP is ever added, the CDN import needs `cross-origin-resource-policy` (jsDelivr) or `credentialless`.
