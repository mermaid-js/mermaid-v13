## Component (packages/dev/src/browser/explorer/tabs/code.ts)

`dev-tab-code` (`CodeTab extends ViewerTabElement`) replaces only the placeholder; viewer.ts, context.ts and styles.css are untouched.
- CodeMirror 6 mounted in the tab's shadow root (`root: this.renderRoot`), v12's extensions and highlight palette, plus a dark `EditorView.theme` on Shoelace variables. Fills the panel height.
- Edits call `ctx.setText`, so the shell re-renders unsaved text. Shell text changes (disk reload, revert) are pushed into the editor without echoing back; the cursor is kept (clamped).
- Save: the `sl-button[data-action="save"]`, Mod-s inside the editor (a `Prec.highest` keymap), and Mod-s anywhere while `active` (a `document` keydown listener). All call `ctx.save()`.
- Status: `[data-status]` is `saved | dirty | saving | conflict` (exported type `CodeStatus`). `conflict` = `ctx.diskChanged`; it also shows `.conflict[role="alert"]` with a Revert button (`ctx.revert()`). The shell's own notice banner still shows too.
- Open-at-line: when `ctx.reveal.seq` changes, the tab moves the cursor to `{line, column}` (1-based; line clamped to the doc, column clamped to the line end, missing column = 1), scrolls it to centre and focuses the editor. A reveal that arrives while hidden waits until `active`, then applies on the next animation frame.
- `position` getter: the cursor as `{ line, column }` (1-based), `undefined` before mount. Use it in specs.

## How #60 / #61 use it

Call `ctx.goto('code', { line, column })` from your tab (e.g. a diagnostic's `mermaidError.line/column`). Nothing else is needed; the shell switches the tab and the Code tab reveals. Calling it again with the same position re-reveals (seq bumps).

## Tests

- `e2e/dev/code-tab.spec.ts` (each test gets its own `startExplorerServer` root): highlighting present; edit re-renders the Diagram tab with the file unchanged on disk; Mod-s and the Save button write the file and return to `saved`; an on-disk write while dirty shows `conflict` + the alert and keeps the edits, then Mod-s overwrites and clears it; an on-disk write with no edits updates the editor; `ctx.goto` from `dev-tab-diagram` switches to Code (URL `tab=code`), cursor at 3:5, active-line gutter 3, focused, typing lands there; a second goto while showing, column clamping and the default column.
- Driving goto from a spec: `document.querySelector('dev-tab-diagram').ctx.goto('code', {line, column})` (the shell renders in light DOM, so tabs are reachable by `querySelector`); read the cursor with `document.querySelector('dev-tab-code').position`.
