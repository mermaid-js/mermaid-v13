# X7 (#862): flowchart addVertex, drawNode, drawShape

Branch `feature/862_flowchart-functions`. Flowchart package only; core untouched.

## What moved

- `parser/model.ts`: `addVertex` keeps the subgraph and edge-id dispatch and calls
  `edgeTarget` (edge id), `vertexOf` (create or find, node limit, unknown-style note),
  `applyParts` (+ `noteShaped`), `vertexShape` (metadata `shape`, same `UNKNOWN_SHAPE`
  diagnostics in the same order), and the module functions `applyVertexDoc`,
  `applyDocLabel`, `applyAssetSize` (label, icon, img, form, pos, constraint, w/h).
- `render/render.ts`: `drawNode` calls `nodeHref`, `nodeAttrs` (`shapeAttrsOf`,
  `lineAttrsOf`), `blockFrame`, `drawFoldedNode`, `drawNodeBody`. The folded block still
  returns before the label, as before.
- `render/shapes.ts`: `drawShape(d: ShapeDraw)` takes a record (kind, w, width, height,
  attrs, lines, pads). One call site in `render.ts`.
- #822 is closed but did not move the shapes code (`drawShape` is still in
  `diagram-flowchart/src/render/shapes.ts`), so `drawShape` was done here.
