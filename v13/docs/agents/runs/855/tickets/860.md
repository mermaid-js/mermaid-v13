## What moved where (all in `core/src/svg/`, no new file in `src/`)

- `inert.ts`: `inertProblem` is now a loop over `textProblem` and `markupProblem`; `markupProblem` calls `styleProblem` (`<style>` sheet), `closingProblem` (end tags) or `openingProblem` (start tags: `gradientPlace`, `attributesProblem` -> `attributeProblem`, whole-tag rules). State is one `Scan` record per call. `attrProblem` is a Map from attribute name to an `AttrRule` (`sizeRule`, `hrefRule`, `transformRule`, `styleRule`, ...; `matching(re)` and `among(set)` build the plain ones).
- `style.ts`: `checkValue` is `VALUE_CHECKS[kind](v, lower)`, a table from kind to check.
- Not touched: the gradient rules, `hrefProblem`, `decodeAttr`, `badAmp`.
