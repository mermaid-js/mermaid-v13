## Exports (`@mermaid-js/diagram-xychart`)

- `XyChartTokenKind` (`src/parser/tokens.ts` `T`): one kind per terminal of the lexer 12.2.0 generated, plus no-token kinds `AccDescrMultiline`, `AccDescrMultilineEnd`, `StringStart`, `StringEnd`, `DeadMdRule`, `Blanks` (jison's skipped `\s+`). `XyChart` covers both headers; `SquareBracesStart`/`End` cover all three `[` and both `]` rules.
- `JISON_NAMES`: kind → jison terminal (dev/test only).
- `lexXyChart(src, onRule?)` → `XyChartLex { tokens, textStart, textEnd, v12 }`: the full `TokenStream` (trivia included, ends in `Kind.EOF`) over v12's text (`v12-text.ts`, a copy of quadrant's plus `v12Directives`, which cuts directives as v12's regex reads them: an unclosed `%%{` runs to the end of the text, or ends after a word argument; core's preprocess ends it at its line end). `tokenValue(l, j)` gives a token's text as v12's parser read it. `xyChartTokens(src)`: significant tokens `{ kind, text, range }`. No probe argument yet (T6 adds it, as quadrant's did).

## Token facts the parser needs (oracle-checked)

- `\b` on `title`, `xychart(-beta)`, `x-axis`, `y-axis`, `line`, `bar`; none on `vertical|horizontal` (`verticalx` is `CHART_ORIENTATION ALPHA`). `title` text is ordinary tokens (ALPHA, NUM, STR, punctuation), joined by the grammar.
- `axis_data` (after `x-axis`/`y-axis`, popped by a line break): a digit run is `NUMBER_WITH_DECIMAL`, so `x-axis Year2024 [a]` has one; `[` enters `axis_band_data`. `data` (after `line`/`bar`): digits are `NUM` before `[`; `[` enters `data_inner`, where numbers are `NUMBER_WITH_DECIMAL` (`1e3` is `1 e 3`, `1.` is `1 .`, `+-1` is `PLUS -1`).
- `x%%…` (x not `}`) is one skipped comment that takes x: `bar [1]%% c` has no `]`, a line break before `%%` is eaten too. Blanks before a line break swallow it (`bar [1] \nline [2]` has no NEWLINE and does not leave `data`).
- `accTitle:`/`accDescr:` values are `[^\n]*` (`;`, `#` kept); `\s*` after the colon crosses line breaks (`accTitle:\nbar [1]` is a title `bar [1]`). An unclosed string or `accDescr {` ends in an extra empty `STR` / value. A backtick, non-ASCII letter and `(){}<>@^~|!?'/\$%` outside strings are lexical errors; `#name;` outside a string is one too (placeholder).
