- `XyChartModel` (`src/model.ts`): `orientation?` (only `horizontal` as written turns it; absent = config), `title?`/`titleAst?` (last in-text, else front matter), `accTitle`, `accDescr`, `xAxis` (`band` with `categories`, or `linear` `min`/`max`; `ast?`), `yAxis` (`linear`, `explicit`, `ast?`), `plots` (`ast`, `kind`, `name`, `index` = palette slot before mod, `values` as written, `data: {x, y?}[]` = v12's `[x, y]` against the axis the plot saw, `pointLabels?` lines only), `warnings`.

- AST (`src/parser/ast.ts`): `Header`, `Title`/`AccTitle`/`AccDescr` (`text`), `Axis` (`axis`, `title?`, `categories?`, `data?`), `Plot` (`kind`, `name?`, `points`). - Diagnostics: `XYCHART_NO_PLOT` (error, v12's text, only when no other error explains it: a failed statement or text an unclosed `%%{` cut), `XYCHART_PLOT_BEFORE_AXIS` (one warning at the last `x-axis` with data, `related` = each plot read against other x data; the same categories or range again do not warn, D386), `XYCHART_UNCLOSED_DESCRIPTION` (warning), `UNEXPECTED`, `UNEXPECTED_CHARACTER`, `UNCLOSED_STRING`.

## Decisions and deviations

- **Choice:** unclosed `%%{` keeps the quadrant/radar precedent: core's `UNCLOSED_DIRECTIVE` rejects; six base cases listed in `divergences.json`, their generated variants left out of the parity corpus.
- **Choice (for the maintainer):** an unclosed `accDescr {` is accepted as v12 does (it reads an empty description last) with a new `XYCHART_UNCLOSED_DESCRIPTION` warning (D383 lists three kinds).
- **Choice (for the maintainer):** v12 acceptance in the oracle includes having a plot (`xychart/oracle-env.ts`), as v13 reports it at parse.
- **Deviation (for the maintainer):** the spec says the title is "in-text if non-empty, else front matter"; v12 set the front-matter title before parsing, so an in-text `title "  "` wins with `''`. Followed v12 (P2), as quadrant.
- **Deviation (for the maintainer):** inferred x range from the **first** plot (oracle-checked), not the longest as the spec says. Unmet: none.
