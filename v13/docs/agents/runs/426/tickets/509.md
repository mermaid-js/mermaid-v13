# #509 T3 layout: handoff

Branch `feature/509_xychart-layout`. Adds the XY chart custom layout (`src/layout/`), the `xyChart` option reader (`src/config.ts`) and the `./testing` entry. One core edit: `fontFamily`'s `usedBy` in `core/src/theme/vocabulary.ts` lists `xychart` (its layout reads it), and `theme-used-by.spec.ts`'s `NOT_DRAWN_YET` is empty (`pnpm gen:theme` regenerated `v13/docs/theme-variables.md`). The registry is untouched (no plugin or manifest yet).

## Exports (`@mermaid-js/diagram-xychart`)

- `layoutXyChart(model, ctx)` → `XyChartLayout`; `ctx` is `Pick<RenderContext, 'config' | 'measurer' | 'theme'>` plus optional `inline`, `warn`, so T4's plugin passes its `RenderContext` as it is. Reads `ctx.config.xyChart` and `theme.value('fontFamily')` only (no theme table yet).
- `XyChartLayout` (`src/layout/types.ts`), plain data in canvas px: `orientation`, `width`/`height` (v12's canvas and viewBox), `plot`, `xAxis`/`yAxis` (`position`, `box`, `range`, `outerPadding`, `domain` or `categories`, `ticks[]` with `at`, `line?`, `label?`, `tickWidth`, `line?`, `lineWidth`, `title?`, `ast?`), `plots[]` in model order (`bar`: `bars[]` with `datum`/`value`, `dataLabels[]`; `line`: `points[]`, `path` = d3 `line()` string, `strokeWidth`, `pointLabels[]`), `legend?` (`box`, `rows[]` with `swatch` or `stroke`, `label`), `title?`, `bounds` (D224).
- Every text is an `XyText`: anchor `x`/`y`, `anchor` (`start|middle|end`), `baseline` (`top` = v12 `text-before-edge`/`hanging`, `middle`, `alphabetic` = v12 `auto`), `rotation` (degrees about the anchor), `font`, `box` (before the rotation), `text` as written, and `label` (core `MeasuredLabel`) for author text (D385). T4 draws `label` with core's label writer, plain `text` otherwise.
- Warning codes `XYCHART_MISSING_VALUE`, `XYCHART_EMPTY_RANGE`, `XYCHART_LABEL_TOO_SMALL` (one per kind per layout, `astIds` = plots or axes).
- `xyChartOptions(section)` → `XyChartOptions` (every key set; v12 defaults until T5 generates `config-defaults.ts`; any finite number taken, as v12), for the renderer's `useMaxWidth`, `showDataLabel*`. A legend line row carries `stroke` and `strokeWidth`.
