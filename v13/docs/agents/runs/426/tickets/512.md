## Behaviour

- Completion: `xychart` where the header goes; `vertical`/`horizontal` right after it; `title`, `x-axis`, `y-axis`, `bar`, `line`, `accTitle: `, `accDescr: `, `accDescr {` at a line start or after `;` below a header; `-->` after a range minimum (not when already written); `[` after an axis or plot name. Nothing in values, strings, descriptions (also the blanks after `accDescr {`), comments, front matter.
- Hover: keyword docs from the grammar (`accDescr {` and its `}` as `accDescr`); a plot (name, values, brackets) its kind, number, "Colour n of the plot palette" (a slot number: no theme table yet, GAPS), value count, and on a value its x (or that it is not drawn); a category its place, repeats and whether a later `x-axis` replaces it. Folding: the statement spans (`accDescr { … }`).
