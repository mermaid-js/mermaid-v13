# Ticket 571: treeView T1, lexer parity gate, box-drawing pass and corpus

**`@mermaid-js/diagram-treeview`** (private, `0.0.0`, no manifest until T5). `.` (`src/index.ts`) is empty; `./testing` (`src/testing.ts`) exports:
- `treeViewLex(src)`: `{ tokens, box, before(i) }`. `tokens` are what v12's lexer saw, in order (`{ kind, text, range }`, wardley's shape: significant tokens, `Kind.Newline`, in-text `%%` as `Kind.Comment`, `Kind.Error` over skipped characters; removed spans, `│` lines the box pass dropped and `EOF` left out; the last `Newline` zero-width at the end). `box` is the box pass, a union on `kind`: `none`, `rewrite` (`{ text, first, last }`) or `error` (`{ message, line, start, end }`). `before(i)` is v12's text before token `i` (the gate's error offset). `treeViewTokens(src)` gives `tokens` only. `treeViewView(src)`: `{ bodyStart, view }`, the one `preprocess → sourceView` shape.
- `TreeViewTokenKind` (`T`): `TreeViewBeta, AccDescr, AccTitle, Title, ClassAnnotation, IconAnnotation, DescAnnotation, Indentation, QuotedName, BareName`. `TREEVIEW_TRIVIA` (Comment, Directive; not Newline; the lexer writes no Space). `LANGIUM_NAMES` (test use). `ampEntities(text)`: `#name;` as `&name;`, the one entity scan (`entityAt`, `src/parser/text.ts`) shared by the box pass, the lexer and the gate.
- Internal for T2: `lex(src, from, view)` (`src/parser/lexer.ts`) returns `{ tokens: TokenStream, box, text(j), before(j) }`. **Read token text with `text(j)`, not `cook`**: on a rewritten line it is the rewrite's text (tabs as four spaces), which is what v12 converted. `boxDrawing(text, from)` (`src/parser/box.ts`) is the pass on the view text.

**Rules T2 must know** (all gated): token order as the spec's table. The keyword gives way to a longer BARE_NAME (`treeView-beta   `, `treeView-beta %% c`, `treeView-betaX` are names; its `(?=%%)` arm is unobservable). Blank runs are INDENTATION anywhere; NL is skipped, so annotations reach across lines. Box pass: v12's rules, CR/CRLF/LF as breaks, columns as v12 counted them (tab 4, `#name;` +2, `#123;` +3). A rewritten line's INDENTATION token spans its whole box prefix in the source; tokens on it map back char by char (a tab's four spaces to the tab). On a box error the text is lexed unrewritten and `box.error` carries v12's message, v12's line (line 1 = header line, after front matter and comment lines) and the source line range, for D486's source-column diagnostics.
