# #47 — format 'ascii' in the API, ascii config, hooks

Branch `feature/47_m2-ascii-api`. D76, D77, D80, D82, D84, D86, R-ASCII-4, -5, -8.

## Exports (`mermaid`)
- `render(id, text, { format: 'ascii', config? })` and `renderSync(text, { format: 'ascii' })` →
  `TextRenderResult { format, text, columns, rows, diagramType, warnings }`; `columns` = widest
  line in cells (`cellWidth`). Overloads: `TextRenderOptions` → text, `SvgRenderOptions` / v12
  `Element` / none → `RenderResult`. No catch-all overload (it would break the v12 type test,
  which reads the last one): narrow a dynamic `format` first. Types exported, + `TextRenderContext`.
- `render`'s 3rd arg: options when a plain object without a numeric `nodeType`; its `id` loses
  to render's. `prepare(text, { format: 'ascii' })` loads the ascii entry + `src/ascii.ts`
  (lazy re-export of core/ascii `cellMeasurer`, `cellWidth`); `renderSync` before that throws
  `NotLoadedError` with `{ kind: 'diagram', name: 'flowchart/ascii' }`. Text needs no theme.
- `UnsupportedFormatError` from `prepare`/`renderSync`/`render` when `formats` lacks ascii, or
  no hook exists after loading. The DOM adapter is SVG-only (`DomHost` takes `SvgRenderOptions`).

## Core / registry
- `DiagramPlugin.ascii?(model, layout, ctx: TextRenderContext)`; `TextRenderContext` adds
  `title`, `ast`. `drawText(plugin, hook, model, ctx, hooks?)` beside `drawDiagram`;
  `AsciiHook` type. `LaidOut.units: 'px' | 'cell'` (required); postLayout may not change it.
- Manifest `ascii` key (diagram only, needs `ascii` in formats). `gen:registry` emits
  `loadAscii: () => import('<pkg>/ascii').then((m) => m.ascii)`, the subpath found through
  package `exports`. `ManifestPlugin.loadAscii()` for third parties; `Registry.loadAscii/ascii`.
- Config: `ascii.{charset, padding, maxWidth}` honoured. No schema defaults on purpose: a
  default would join `CORE_DEFAULTS` and change every default SVG id (`defaultIdPrefix`).
- `toWarning` keeps `feature`, `shapes`, `astIds`. `ASCII_TOO_WIDE` when columns > maxWidth.
- prepare.ts: in cells `diagramPadding` = profile's 0 (was 8 px → 1). The drawer trims the
  margin, so the 1 cell only made `maxWidth` = natural width tighten the drawing.
