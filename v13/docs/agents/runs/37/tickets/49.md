# #49 — mermaid CLI bin

Branch `feature/49_m2-cli`. D85, R-ASCII-4, R-PERF-2, R-ERR-2.

## What ships
- `packages/mermaid/package.json` `bin: { mermaid: ./dist/cli.js }`, built from `src/cli.ts` by
  the existing `tsc` build (shebang kept). No new package, no new root scripts.
- `mermaid render [file|-] --format ascii|svg [--charset ascii|unicode] [--width N|auto] [--warnings]`,
  plus `-h/--help`, `-v/--version`. No file or `-` reads stdin. Output to stdout, newline-ended.
- `--format` is required (D85 lists it without brackets). Anything but svg/ascii is passed to the
  API, which throws `UnsupportedFormatError` → exit 2. The CLI keeps no format list of its own.
- Config: `{ deterministic: true, ascii: { charset, maxWidth } }` as per-call config, so the
  table measurer is used and output is byte-identical. Diagram text (front matter, directives)
  still wins over the flags, as for any per-call config (#47 precedence).
- `--width auto`: `process.stdout.columns`, else `$COLUMNS`, else no limit. Width only affects
  text output (SVG ignores it).
- stderr: `<file|<stdin>>: <MermaidError.message>` (snippet + caret) on render errors;
  `mermaid: <msg>` + "Run 'mermaid --help' for usage." on usage errors; `mermaid: cannot read
  <file> (ENOENT)` on read errors; `<name>: warning <CODE>: <message>` with `--warnings`.
- Exit: 0 ok, 1 any error (syntax, unknown type, usage, read), 2 `UNSUPPORTED_FORMAT`.

## Zero-dependency proof (R-PERF-2)
- `tools/check-deps`: `readBinSources` maps each published `bin` (`./dist/x.js` → `src/x.ts`)
  and `findBinImportViolations` fails any import that is not `node:`, relative or a workspace
  package. Wired into `pnpm check:deps`. Shallow: the bin's own imports only; the rest of the
  package is held by `mermaid/import-boundaries`.
- `mermaid/import-boundaries`: `packages/mermaid/src/cli.ts`, and only that file, may import
  `node:` builtins (spec in `tools/eslint-plugin/rules.spec.ts`).
- `knip.json`: `src/cli.ts` added to the `packages/*` entries.

## Tests
`packages/mermaid/src/cli.spec.ts`: 19 process specs, each spawns
`node --import tsx --conditions=mermaid-source src/cli.ts` (cwd = repo root, so no build).
Covers file, stdin (bare and `-`), both formats, charset, width N/auto, warnings on/off,
every exit code and the exact stderr. `cli.ts` has `/// <reference types="node" />` because the
mermaid tsconfig has `types: []`.

Size: `cli.ts` min 3,284 B, 1,535 B gz; not in any browser bundle.
