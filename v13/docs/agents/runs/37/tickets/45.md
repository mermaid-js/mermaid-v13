# #45 — snapRoute and the repair router (core/ascii)

Branch `feature/45_m2-repair-router`. D78, D140, R-ASCII-1, R-ARCH-6, DESIGN §6.3 M2 item 7.

## Exports (`@mermaid-js/core/ascii`)
- `snapRoute(points, grid = 1): Point[]` — a model route as a cell polyline (corners only): quantise
  to 1e-4, round, square any diagonal with a knee (`axis` of the later point), drop duplicate and
  collinear points. Ends stay the engine's cells outside the source and target sides.
- `repairRoutes(graph, model, options?): RepairResult` — snaps every edge, then re-routes only the
  colliding stretches with an A* over cells (cost 1 per cell + `turnPenalty` 3 per bend, Manhattan
  heuristic), window grown 4/16/64 cells around the stretch, `maxSearch` 400k expansions.
  `RepairResult = { routes: Map<edgeId, Point[]>, repaired: string[], unresolved: Collision[] }`.
- `routeCollisions(graph, model, routes?)` — the same checks, for properties (default: snapped routes).
- Types `Collision { edge, kind, cell, with }`, `CollisionKind` (`box|label|frame|shared|corner`),
  `RepairOptions`, `RepairResult`.

## Rules (per cell; arms = directions the line leaves the cell in)
Node boxes, other edges' label patches and group titles are walls. A group frame may only be crossed
straight, by an edge with exactly one end inside the group. Another edge's cell may only be crossed
at right angles with both lines straight; sharing an arm is `shared`, touching where one turns is
`corner`. End cells are reserved. Edges in model order, each marked before the next. Self-loops keep
their shape. No route found: snapped stretch kept, collision in `unresolved`.

## Using it (#46)
Lay out with `grid: 1`, `routing: 'stepped'`; call `repairRoutes(graph, model)`; draw
`routes.get(id)` (cell indices). Turn `unresolved` into warnings (e.g. a sibling trunk). Draw group
titles at `round(x − w/2 + ½)` so they match the walls repair assumed.
