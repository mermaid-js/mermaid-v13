# #48 — ASCII goldens, structural check, divergences, corpus properties

Branch `feature/48_m2-ascii-goldens`. D83, D87, D140, R-ASCII-2, R-ASCII-9. All in `packages/conformance`.

## Files and helpers (`src/ascii/`)
- `render.ts`: `renderAscii(text, {charset, padding, maxWidth})` → `TextRenderResult` via the public
  API (`prepare` + `renderSync`, `format: 'ascii'`, `config.ascii`). `layoutCells(text, opts)` → the
  cell `FlowLayout` (+ `flow` views, `title`) by hand (`layoutAscii`), for model-level properties.
- `structure.ts`: `readStructure(text, charset, expected)` reads a drawing back (ours or mermaid-ascii's):
  boxes (title on the border allowed, ASCII `+` corners vs edge corners), node labels in boxes,
  edge labels (words; label cells join lines), line components with free ends, arrowheads.
- `expected.ts`: `expectedOf(layout, title)` — labels the builder measured (labelless shapes and
  collapsed members drop out, as in SVG), group titles, front-matter title.
- Specs: `structure.spec.ts` (table), `goldens.spec.ts`, `corpus.spec.ts` (~5 s for all three).
