# #46 — flowchart ascii entry

Branch `feature/46_m2-flowchart-ascii`. D76, D78, D82, D140, R-ASCII-1, R-ASCII-5.

## Exports (`@mermaid-js/diagram-flowchart/ascii`, `src/ascii.ts`)
- `ascii(model, layout, ctx: FlowAsciiContext): string` — the hook. Uses `layout` when it is in cells
  (`layout.flow.graph.grid` set); otherwise (px layout, or a postLayout model without `flow`) it
  lays out again with `layoutAscii`. Repairs routes, warns, draws; `\n`, no trailing spaces, the
  empty margin trimmed (output starts at row 0, column 0).
- `layoutAscii(model, ctx)` — `layoutFlowchart` with `cellMeasurer` + `cellProfile(ascii.padding)`.
- `FlowAsciiContext = FlowRenderContext & { title?: string; ast?: AstNode }`: front-matter title
  (line 1, centred) and the parse AST (adds statement ids `style:1`, `accTitle:1`… to warnings).
- Types `AsciiWarning`, `AsciiDroppedWarning`, `AsciiShapeWarning`, `AsciiDroppedFeature`.
- Charset from `config.ascii.charset` (read loosely; schema is #47's).
