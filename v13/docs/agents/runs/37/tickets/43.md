# #43 — flowchart graph builder takes every length from the unit profile

Branch `feature/43_m2-builder-units`. D77, R-ARCH-3, DESIGN §6.3.

## What changed

- `FlowRenderContext.units?: UnitProfile` (`render/context.ts`); absent means `pxProfile`.
- `render/prepare.ts` reads `units.builder` for label patch, group/title padding, edge wrap,
  head room, default wrap/spacing/padding, and converts px config (`nodeSpacing`, `rankSpacing`,
  `wrappingWidth`, `diagramPadding`) with `fromPx` and `builder.minSpacing`. Node spacing runs
  across the flow, rank spacing along it (LR/RL: rank on x, node on y); padding and wrap use x.
- `LayoutGraph.metrics = units.engine` always; `grid` only when the profile has one (cell: 1).
- `units.id === 'cell'` sizes every node as a text-form box:
  `w = label + 2·(nodePad.x + 1)`, `h = lines + 2·(nodePad.y + 1)`, `dy = 0`, and leaves `span`
  unset (the engine's `corner` metric applies once #42 reads metrics). This is the only branch.
- px keeps reading node pads from the theme tokens (`spacing3`, `spacing2 + spacing1`), so
  custom themes stay byte-identical; `builder.nodePad` is read only for cells.
- Image/icon asset geometry (80/48 px, label gaps) moved verbatim to `shapes.ts` `assetSize`.

## Using it (#46)
Call `flowchart.layout(model, { ...ctx, units: cellProfile(), measurer: cellMeasurer })`; the
returned `FlowLayout.flow.graph` / `nodes[].w,h` are in cells. `minNodeWidth` is ignored in cells.

## Tests

- `packages/conformance/src/flowchart-units.spec.ts`: cell graphs over the e2e flowchart corpus
  hold only whole, non-negative cells; metrics/grid handed over; text-form box sizes; LR axes;
  px graph carries `pxProfile.engine` and no grid. Helper `build(prepared, units)` there
  captures the LayoutGraph via the plugin's `layout` with `cellMeasurer`.
- `packages/conformance/src/flowchart-prepare-literals.spec.ts`: scans `prepare.ts` for numeric
  literals; only counts (0/1/2), font weights/caps and the config cap are allowed.
- Byte identity: SHA-256 of every SVG over e2e/diagrams/flowchart + flowchart-v12-specs.json
  (856 items, 836 render) identical before/after.

Size: mermaid ESM bundle, minified + gzip -9: 91,900 → 92,039 B (+139 B).
