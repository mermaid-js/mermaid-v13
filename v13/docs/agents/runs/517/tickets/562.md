- `usecaseView(src)` → `{ bodyStart, view }` (core preprocess + `sourceView`, default options). `lex(src, bodyStart, view)` (`parser/lexer.ts`) → `Lexed { tokens, input, at, to }`: the `TokenStream` (trivia included, ends in EOF), `input: LexText` (v12's text and per-character source ranges), and per token its `[at, to)` in `input.text` (-1 for removed spans). `lexText(src, from, view)`: the text alone. `LexText.start`/`end` share a forward cursor: call them in non-decreasing order (documented), or the cost turns quadratic. - `usecaseTokens(src)` → `{ kind, text, range, at }[]`: what v12's lexer saw (no removed spans, no EOF), `text` with entity placeholders decoded, the appended `\n` clipped (last `Newline` zero-width at the end).
- `UsecaseTokenKind` (`T`, `parser/tokens.ts`): one kind per Chevrotain token type; `NEWLINE` = `Kind.Newline`, `COMMENT` (a `%%` line v12 left, e.g. `%%` alone) = `Kind.Comment`, `HWS` skipped. `KEYWORDS` (v12 order), `ANY_CASE` (include/extend), `WORD` and `LABEL_TEXT` (v12's categories, `kindSet`s for T2), `CHEVROTAIN_NAMES` (test use).

**How it lexes:** it builds v12's exact text once (view text from the first non-blank, CRLF/CR as LF with a directive-split CR LF as two, tag quotes, `#x;` as `ﬂ°x¶ß` / `ﬂ°°123¶ß`, `\n` appended) and ports the three modes rule for rule. The gate asserts that text equals the oracle's captured input on every compared source. Placeholder characters map to the `#` / `;` they stand for; a dropped style `;` belongs to the token before it.

**Rules T2 must know** (oracle-checked): keyword then longer `\w` run → `IDENTIFIER` (`actors`, `TBD`), else the keyword even before `-` (`actor-x` = `ACTOR DASH IDENTIFIER`; a keyword-prefixed word is never `CSS_IDENTIFIER`). `1.5px`/`.5` `NUMBER`, `1mg`/`1.` → `IDENTIFIER` (+`DOT`). `---o` = `MARKERLESS_SOLID IDENTIFIER`; `--xyz` = `FORWARD_CROSS IDENTIFIER`; `o-->` = `BACKWARD_CIRCLE LABEL_PUNCTUATION`. `actor A %% x` lexes clean (`PERCENT PERCENT`): reject in the parser. `&lt;…` lexes clean (`CSS_PUNCTUATION` …). `#amp;` outside strings is `LABEL_SYMBOL IDENTIFIER|keyword LABEL_SYMBOL` (texts `&`, `amp`, `;`). Only errors: unclosed `"`/`'` and a line break in stereotype mode (Chevrotain stays in that mode over it; v13 does the same).
