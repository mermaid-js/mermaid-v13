# #556 T4 SVG renderer and local shapes: handoff

Branch `feature/556_block_render`. The renderer, the shape drawers and the plugin's `render` in `packages/diagram-block`; no core, shared-list or other-package change (theme users come from the source scan, so `pnpm regen` only rewrote `theme-variables.md`; `gen:config` wrote MIGRATION.md from `migration/block.md`).

## Exports

- `@mermaid-js/diagram-block`: `block` is now a full `DiagramPlugin<BlockModel, BlockLayout>` (`render` added; still no manifest, `configDefaults` or `labels`). `renderBlock(model, layout, ctx, w)`, type `BlockRenderContext` (`config`, `theme`, `idPrefix`, `version`, `warn`).
- `./testing`: `renderBlockForTest(source, { config?, idPrefix?, outline?, measurer? })` → `RenderedBlock { svg, model, ast, layout, config, warnings, rejected, gradient, themeStyle }` (parse → layout → render through the plugin, stream writer with the theme's gradient and an optional outline drawer). `blockTestConfig(pre, integrator?, warn?)` and `blockTestTheme(config, { idPrefix?, warn? })` take the new optional arguments.
- Files: `src/render/{render,paint,edges,arrowheads,metrics,context,harness,index}.ts` (root and nodes, paints (`NodePaint`, `EdgePaint` with its own widths and label colours), edges and edge labels, flowchart's inline heads keyed by `BlockArrowType`, the render constants); `src/shapes/draw.ts` (`drawShape(w, shape, outline, ShapePaint)`: one table from each shape to its drawer); `shapes/leaf.ts` exports `FRAME_INSET` and now credits Pele.

## SVG

`svg.mermaid.mermaid-block` > `g.block` > per block in pre-order `g.node.<classes|default>.flowchart-label` (`data-id`, `data-ast`, composites' `data-color-id`, translated to the centre) > shape (`label-container`; composite `rect.basic.cluster.composite.label-container`; block arrow `polygon.label-container.block-arrow`) and `g.label[data-id]` > `text`; then each `path.edge-thickness-*.edge-pattern-*.flowchart-link` (`data-id`, `data-ast`) and its `.marker` heads; then each `g.edgeLabel[data-id]` > `rect` + `text`. Leaves go through `w.outline` (`node`, `divider`); the rest is plain (D447).
