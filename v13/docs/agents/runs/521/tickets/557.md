# #557 T6 language facet: handoff

Branch `feature/557_block_language`. The `./language` facet of `packages/diagram-block`, the parser's probe, the shared goldens and the conformance specs; no manifest (T5).

## Exports (`@mermaid-js/diagram-block/language`, new subpath)

- `language` = `blockLanguage` (`LanguageFacet<BlockDocument>`): `parse`, `categories`, `namespaces` `[['block'], ['class']]`, `isValidId`, `completions`, `hover`. Also `blockCategories`, `blockDocs`, `BlockTokenKind`, `blockTokens`, `detectBlock`, `parseBlock` and the AST types. Inputs: `parser/`, `facet/`, `generated/`, `codes.ts`, `model.ts` (types); `workspace.yaml` has `languageBundle.renderer` (render, layout, shapes, plugin, index, testing, test-context).
- **Probe** (R-LANG-7): `parseBlock(text, { probe })`: the lexer records jison's start condition per step (`INITIAL`, `string`, `NODE`, `ARROW_DIR`, `CLASS`, …); the parser calls `c.tested(kinds)` at each decision point (`parser/expected.ts`: header, statement start, `end` only in a composite holding a statement, shape, span, link, label, closer, directions, edge label, `classDef`/`class`/`style` parts) through a `ProbeCursor`; `recover()` freezes it. Nothing else changes (probe spec).
- **Completion** (`facet/completions.ts`): `block`/`block-beta` at the header; at a statement start `columns`, `space`, `block:`, `block`, `classDef`, `class`, `style`, `end` (in a non-empty composite), and the used ids with their labels; after `columns ` `auto`; right after a complete block the link kinds, its shapes if it has none, `space` and the ids; a half-typed link every link that lexes from it (`a <` → `<-->`, `<==>`, `<-.->`); after a labelled edge's text its closing links; after a link the ids; at the end of any id its shapes (`a["a"]` … `a<["a"]>(right)`), after `block:` those only; in `(…)` the directions; after `class`/`style` the `\w` ids, after `class a` the class names. Nothing in labels, shapes, style text, comments, directives, front matter.
- **Hover** (`facet/hover.ts`): keyword, link and direction docs (generated); a block (id, shape or label) its shape, label, directions, span, columns and children (composites), parent, classes; an anonymous `block` its doc and the same facts; a class its styles and users.
- **Folding**: composites only (the parser records header and composite statement spans, nothing else).
- **Symbols/rename** (D448): T2's symbols; `isValidId` refuses names outside `NODE_ID` and names that do not lex as one id (`end`, `space`, `class`); existing ids by the service's clash check; class names `\w+`, not `DEFAULT`.
