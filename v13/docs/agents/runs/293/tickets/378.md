## `GanttModel` (`src/model.ts`, for T3 #379)
- `source`: the parsed text (front matter included); every `range` is an offset into it. Build `MermaidError('SEMANTIC', …, { source: model.source })` from it in layout.
- Settings as v12's DB held them after the parse: `dateFormat`/`axisFormat`/`todayMarker` (`''` when unset), `tickInterval?`, `includes`/`excludes` (merged lower-cased tokens, v12 `mergeTokens`), `inclusiveEndDates`, `topAxis` (D273), `weekday?` (undefined → `gantt.weekday`, D279; v12 default `sunday`), `weekend` (`'saturday'` default). Values untrimmed (`substr(n)`).
- `title?` (last in-text, else front matter, D218), `titleAst?` (in-text title's `st:<n>`), `accTitle`, `accDescr` (trimmed, `\n\s+` folded).
- `sections[]`: `{ ast: 's:<name>', text }`; `tasks[]` in source order, `vert` included: `{ ast, id, text (trailing blanks kept), section? (index), tags[], fields[], start?, end, prevId?, range, dataRange }`.
  - `fields` are the trimmed non-tag fields. 1 → `task<n>`, start undefined (= end of last task with id `prevId`); 2 → `task<n>`, start, end; 3+ → id, start, end. `fields.length > 3` is T3's "too many fields" error (v12 gave no id and no counter; v13 takes `fields[0]`).
  - `prevId`: the previous task's id (v12 `prevTaskId`); undefined on the first task → T3's "first task with no start" error. References resolve last-wins by id; `order` is not stored (vert `-1`, else a counter over non-vert tasks, as `ganttV13Snapshot` derives it).
- `clicks[]`: `{ ast: 'click:<n>', ids (split on `,`, untrimmed), href?, call?: { name, args? }, range }`. Unknown ids are kept (D276 is T3's). `warnings` (none today).

## AST and errors
- Flat in source order (`src/parser/ast.ts`): `Header`, `Setting` (`setting`, `value`), `Title`/`AccTitle`/`AccDescr`, `Section`, `Task` (`task`, `text`, `data`), `Click` (`ids`, `href?`, `callback?: AstCallback`). Ids `t:<id>` (`@n` repeats), `s:<name trimmed>` (`@n`), `click:<n>`, `st:<n>` (header `st:1`, a tags-only task). Section spans fold to the next section (D259).
- Errors: `UNEXPECTED`, `UNCLOSED_DESCRIPTION`, `UNCLOSED_STRING` (link), `UNCLOSED_CALLBACK_ARGS`, `UNCLOSED_CALLBACK` (`call f` with no `(`), `GANTT_TASK_NO_DATA` (data only tags; semantic, the statement stands). Recovery: next line, or a token on a later line.
