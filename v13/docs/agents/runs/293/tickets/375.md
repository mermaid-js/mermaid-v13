# Ticket 375: T0 core, `now` and `availableWidth` on the render context (branch feature/375_gantt-now)

**`@mermaid-js/core`** (`packages/core/src/pipeline/types.ts`), on `RenderContext`, both optional and additive:
- `now?: number`: the instant the diagram treats as now, ms since the epoch. The `mermaid` API always sets it.
- `availableWidth?: number`: `RenderOptions.availableWidth` in the profile's units (px for SVG; for text output the `ascii.maxWidth` columns, as `ctx.layout()` already got). `undefined` unless the caller asked.

**`mermaid`** (`packages/mermaid/src/api.ts`):
- `RenderOptions.now?: number | Date` (D270). `contextFor` resolves it as `+(options.now ?? Date.now())`, so every `render()`, `renderSync()` and each `mount()` re-render (which calls `renderSync`) reads the clock once when no `now` is passed (D275). It is not a config key: front matter `now:` does nothing.
- `now` is in neither the parse cache key nor the default id prefix (D274). There is no render cache, so nothing else keys on it.
- `MountOptions` gets no `now`: mount defaults it per render. Add it there if a caller needs a fixed `now` through `mount`.

**How gantt uses it (T3, #379):** in `layout(model, ctx)`, read `ctx.now` and `ctx.availableWidth`. D272 width: `gantt.useWidth ?? ctx.availableWidth ?? 1200`. `ctx.now` is typed optional; through the `mermaid` API it is always a number, so a fixture-built context must set it.

**No clock read (static check):** `eslint.config.js` adds a block for `packages/core/src/**` and `packages/diagram-*/src/**` (specs excluded) with `no-restricted-syntax` on `Date.now()`, `new Date()` with no arguments and `Date()`. The enum selector moved to a shared `NO_ENUM` constant so the block keeps it. Fixtures `tools/eslint-plugin/fixtures/clock.ts` and `fixed-date.ts`, rows in `rules.spec.ts`. So gantt's own code cannot read the clock either.

**Test helpers:** `packages/mermaid/src/render-now.spec.ts` has `probe()`, a `layoutKind: 'custom'` plugin whose layout records `ctx.now` and `ctx.availableWidth` and draws them in a `<desc>`. It covers fixed `now` (number and `Date`) on `render`/`renderSync`, the per-call default under fake `Date` timers, front matter not setting it, one parse for many `now`s, and `availableWidth` through the render option and `mount()` (fixed number, `true` with a stubbed `getComputedStyle`, absent).
