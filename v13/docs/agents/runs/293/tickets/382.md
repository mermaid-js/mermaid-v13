## Exports (`@mermaid-js/diagram-gantt/language`)
- `language` / `ganttLanguage` (`LanguageFacet<GanttDocument>`), `ganttCategories`, `ganttDocs`, and the parser surface (`parseGantt`, `detectGantt`, `ganttTokens`, `GanttTokenKind`, types).
- Symbols, kind `task` (namespace `[['task']]`): the id of a 3-field task (def), `after <ids>` in the start field and `until <ids>` in the end field (v12's regex), `click` ids (refs). Last-wins: earlier tasks with the same id are refs. No symbol for `task<n>` names v12 gives tasks without an id, nor for a name a removed span cuts (`src/parser/task-ids.ts`).
- `parseGantt(text, { probe })` records expectations (`tested` at the header, every statement start, task data, click ids, `href`/`call`, the callback name); the lexer records jison start conditions as modes.
- Completion: header; statements at a line start or on the header line (each re-lexed, as timeline); `href`/`call` after the ids; task ids in a click (also in the blanks `click` took); in task data the tags (while only tags come before), `after`/`until`, the ids after them, duration units after a number; days after `weekday`/`weekend`, day words after `excludes`/`includes`.
- Hover: a task id shows its task, section and tags; keywords show their grammar doc (the keyword only); in task data a tag, `after`, `until`.
