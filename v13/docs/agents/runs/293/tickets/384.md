# #384 I1 interactions spec: handoff (branch feature/384_gantt-interactions)

## What changed
- `packages/plugin-interactions/src/gantt.spec.ts` (new): bar and label bind once each, v12's argument split and the task id as default (rows from mermaid@12's `ganttDb.setClickFun` + `bindFunctions`, run through the conformance oracle under `loose`), dotted names, `click a,b`, unknown ids, a task defined after its `click`, section titles not bound, repeat `bindFunctions`, `href` + `call` on one task (either order), unsafe URLs (`URL_REFUSED`, callback still bound), `CALLBACK_IGNORED` once without the plugin, PAYLOADS svg unchanged (R-SEC-2).
- **Plugin change (additive):** the `callback` feature binds `g.node[data-id]` as before; an id with no such node binds its `clickable` elements with that `data-id` (`clickables()` in `src/index.ts`): gantt's bar (`rect`) and label (`text`). v12's `clickable` class is set by the layout only on the task a `click` marks, so unknown ids and later tasks bind nothing and section titles never do.
- **Plugin fix:** `callbackArgs` drops a lone `"` to `''` (v12's `substr(1, -1)`, same in flow, class and gantt DBs); it kept `"`. `index.spec.ts` gains the row.
- **Gantt change:** the plugin's `parse` wraps `parseGantt` in `withCallbackClaims(result, ctx.claims)` (`src/parser/callbacks.ts`): `CALLBACK_IGNORED` once, at the first `click` with a `call`, in `diagnostics` and `model.warnings`, unless `callbacks` is claimed. `parseGantt` itself is unchanged (`parser.ts` is at the 800-line lint cap).
- `vitest.config.ts`: `gantt.spec.ts` joins `GANTT_SPECS` (UTC + LA runs, not `workspace`). `plugin-interactions` devDepends on `@mermaid-js/diagram-gantt` (lockfile: 3 lines).
- README and `.changeset/plugin-interactions-gantt.md`.

## How to use
- Until #385: `registerExternalDiagrams([gantt], { replace: true })`, then `[interactions]`; `render(id, text, { now })`, `result.bindFunctions(el)`.
- #385: drop the `replace` (and the devDependency if `mermaid` brings gantt).

## Oracle (v12, `loose`)
`cb()`, `cb( )` → `[id]`; `cb("x, y", 2, "q")` → `['x, y','2','q']`; `cb(a,,b)` → `['a','','b']`; `cb(,)` → `['','']`; `cb("")`, `cb(")` → `['']`; `cb("a"b")` → `['a"b']`; `cb('a, b')` → `["'a","b'"]`. `click a, b …` is a v12 parse error; unknown ids bind nothing. v12 bound `[id=<diagram>-<id>]` and `…-text`.
