## Parser and grammar changes

- **Probe** (R-LANG-7): `ProbeCursor` with a probe; `tested` at the header, each statement start (a boundary's adds `}`), the end of the text, and each argument; `recovering()` in recovery; the lexer records jison's start condition (`INITIAL`, `macro`, `attribute`, `string`, `string_kv`, `string_kv_key`, `string_kv_value`, `acc_title`, `acc_descr`, `acc_descr_multiline`).
- **Symbols:** every positional alias, end and target is an occurrence at its argument's range (bare or quoted); one not written as it is is dropped by the service, so its rename is refused. `$alias`, `$parentBoundary` (a boundary) and a relation's `$from`/`$to` record their value. Model, AST and diagnostics unchanged (parity and v12 specs green).
- **Grammar file:** the header rule's doc wins hover; modes switch (`pop push`) instead of `pop pop`, so Monarch and Lezer stay right after a macro (they were wrong after the first statement). Same tokens on every input.
