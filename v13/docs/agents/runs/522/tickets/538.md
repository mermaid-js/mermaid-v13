## Exports (`@mermaid-js/diagram-c4`)

- `C4TokenKind` (`src/parser/tokens.ts` `T`): one kind per jison terminal (`Deployment_Node`/`Node` share `Node`, `Rel_Up`/`Rel_U` share `RelU`, and so on), plus no-token kinds `ArgsOpen`, `ArgsClose`, `Comma`, `QuoteOpen` (blanks + `"`), `QuoteClose`, `KeyStart` (blanks + `$`), `KeyEquals` (`=`, blanks, `"`), `ValueClose`, `AccDescrBlockStart`, `AccDescrBlockEnd`. `NEWLINE` is `Kind.Newline` (its range holds the blanks before the last line break of the run); a mid-line `%%` (with the line breaks it eats) is `Kind.Comment`; skipped blanks are `Kind.Space`. `KEYWORDS` (spelling → kind, headers first) is internal.
- `JISON_NAMES`: kind → jison terminal (dev/test only).
- `c4Tokens(src)` → `C4Token[] { kind, text, range }`: significant tokens, `text` = `cook(range)` (entities decoded, CRLF as LF, removed spans cut). No action rewrites in c4.jison, so no `text(j)` wrapper.
- Internal for #539: `lex(src, bodyStart, view)` in `src/parser/lexer.ts` → full `TokenStream` (trivia included, ends in `Kind.EOF`); build `view` as `parser/index.ts` does (default `sourceView` options).

## Token facts the parser needs (oracle-checked)

- The lexer is v12's, D452 included: an unquoted `STR` runs over `)` and line breaks to the next comma, `%%` eats the line break, lone `title` takes the next line, any line holding `direction XY` after the token start (a quoted label too) is one `Direction*` token. Coordinator's decision: #539 makes D452's two lexing changes in this lexer (an unquoted argument stops at `)` and at a line end; a trailing `%%` keeps its line break), each listed as a gate exclusion in `lexer-parity.spec.ts` (none today). The rest of D452 is parser work.
- `Kind.Error` is one character and lexing goes on in the same state (`Person (a)`: error at the blank, then the arguments lex). After a macro keyword at the end the appended line break is an error, so `EofInStruct` follows only an error.
- End-of-text empties: an unclosed quote ends in an empty `Str`; `accTitle:`/`accDescr:` at the end in an empty value; an unclosed `accDescr {` in an empty `AccDescrBlockValue`; `$k="` in a zero-width `StrValue`.
- Entities become a placeholder before lexing (`title Caf#233;` is one title); tag quotes `="x"` inside `<tag>` read as `'`; a `;` v12 dropped from a `style…:#…;` line belongs to the token before it.
