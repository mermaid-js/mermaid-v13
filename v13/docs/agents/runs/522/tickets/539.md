## D452 in the lexer (3 gate exclusions, `conformance/src/c4/d452.ts`)

Unquoted argument `[^,)\n]+` and a line break leaves the arguments (parser: `UNCLOSED_ARGUMENTS`); a mid-line `%%` keeps its line break (parser joins line breaks only across a comment, so an empty `accDescr {}` between two stays v12's reject); a `title` right before a line break is a lone title (the brief said parser work; it needs the lexer). After an error, a line break in the macro or `$name=` state is a zero-width error that leaves those states (jison stopped at the error; ungated), so recovery goes on at the next line. Exclusions classify the first differing token; the lexer gate pins the plain sources and counts (368/43/23).
