## Measurement order (pitfall 16)

Everything is measured before it is placed, with two exceptions, both measured before the box they set is sized: a boundary's header is measured in `placeGrid`'s callback, since with both wraps on its wrap width is the width its contents take (bottom-up); a relation's label and `[techn]` after routing, since their wrap width is the route's `room` (88 px across a column gap, else 160) and they slide along the line routing chose.
