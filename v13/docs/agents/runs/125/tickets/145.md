- Config (`gen:config`): section and every key the layout/renderer reads `honoured`; `messageMargin` (v12 never read it) and the `actorFont`/`noteFont`/`messageFont` helpers `ignored`; `forceMenus` and the section `theme` stay `pending` (menus are #147; section theme pending as flowchart and ER). Per-key font sizes/families honoured with no default (the maintainer decision): unset they follow the theme `fontSize`/`fontFamily`, so the schema's 14/16 and per-key families are gone and listed under "Changed defaults". No `SECTION_OWNERS` row / `configDefaults`: the metrics table holds v12's lengths (D108) and generated defaults would force the 14 px fonts. No new theme variables (`gen:theme` unchanged).
- Test seams removed: conformance `render-api.ts` header swap (now `sequenceApi()` = fresh `createMermaid()`), `sequenceAsciiTest`, the conformance-hosted language goldens (moved to `language-service/goldens/sequence`, spec deleted; two no-offer cases renamed `not-code-*`), the bench eager facet rows (`preload({types:['sequence']})`).
- Language service specs: the "type with no facet" examples use `journey`; keyword completion lists `sequenceDiagram`.
- Bench `ascii-size`: measures one type's text path (`asciiPaths`: core/ascii + that type's entry), the gate takes the largest; summing every type's drawing reached 16.1 KB with three types. ascii.md "Size" and intro updated; with state in (no text form) the CLI now exits 2 on `stateDiagram --format ascii`: ascii.md says so and a CLI spec pins it.
- Front-matter `title`: not drawn in SVG (D122, as flowchart and state); the `title` statement is; text prints the front-matter title. MIGRATION.md "Sequence SVG structure" row; font change in "Config behaviour".
- Baselines: 26 fixtures in `e2e/diagrams/sequence/baseline/` (participants, messages, notes, blocks, activations, text, 9 themes), all agree with v12 in the parity spec; in the gallery under `sequence/`. The 219 sequence e2e files now run in `mmd-snapshots`.
- Specs: `mermaid/src/sequence.spec.ts` (render, renderSync, SYNTAX, svg+ascii, text output, front-matter title, config, slim), CLI sequence text, `ascii-size.spec` per-type paths.
