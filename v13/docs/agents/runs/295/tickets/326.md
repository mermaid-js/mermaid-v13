## What changed

- `diagram-flowchart/src/render/assets.ts` `drawIcon(w, view, attrs, paint, icon)` returns whether the glyph was drawn. With a glyph: the frame (`square`/`circle`/`rounded`) is borderless (`stroke` = its `fill`: palette slot, `mainBkg` or the `fill` style); the glyph's wrapper `<g transform="translate(-size/2, top)">` gets `color` = the node's `stroke` style, else `nodeBorder`. Under `useGradient` (neo, neo-dark) with no `stroke` style, the glyph's `currentColor` fills and strokes become `url(#<id>-gradient)` (`painted()`), no `color`; fixed colours (`#ff9900`) stay. D186's stand-in is gone wherever a glyph is drawn.
- Not drawn (no extension, unresolved, placeholder): the frame exactly as before, outline (gradient under neo) included. Corpus with no extension: 0 SVG diffs over 2348 files × svg/ascii; only warnings changed, in the 8 icon-shape files.
- Warnings, once per render, after the nodes (`iconsNotDrawn`): with no glyph extension flowchart gives `ICON_NOT_RENDERED` itself ("Icons are not rendered without an icons extension: icon shapes draw their frame alone.", through `ctx.inline.warn`, so core's label warning and it are one). With an extension, the extension gives it (D291). Next to an `ICON_NOT_RENDERED` (`ctx.inline.notRendered('icon')`), the deprecated `ICON_UNAVAILABLE`: "ICON_UNAVAILABLE is deprecated and goes in the next alpha: read ICON_NOT_RENDERED. Icons not drawn: "fa:nope", "user"; an icon with a form draws its frame alone." (up to 8 names, 60 chars each). Placeholder render: `PLACEHOLDER` only. MIGRATION.md (flowchart "Icon shapes" bullet, neo gradient), changeset `flowchart-icon-shapes.md`.
- The e2e page (`packages/dev/src/adapter.ts`) draws with the icons plugin and the static packs of I3's `packages/dev/src/icon-packs.ts` (#324; this branch had the same edit and took I3's in the merge).
- Baselines: `e2e/diagrams/flowchart/baseline/icons/{default,redux,neo,neo-dark}.mmd` (beside I3's `label-icons-*`) (no form, each form, `pos: t`, an aws glyph at `h: 64`, a `style` stroke + fill).

## Decisions

- An unresolved icon keeps today's outlined frame (D186's gradient under neo), not a borderless one: byte-identical without the extension, and a borderless `mainBkg` frame vanishes on a `mainBkg` page.
- The alias names the shapes' icons (the extension's `ICON_NOT_RENDERED` may not: a prefix-less name such as `user` is named only when met first) and goes only with `ICON_NOT_RENDERED`; an extension with glyphs that declines without warning leaves the render quiet (D291: the extension warns).
- Glyph colour ignores the palette slot (v12: `stroke` style ?? `nodeBorder`); the frame takes the slot's fill.

## Unmet

- D301: no node-outline hook on this branch yet, so the frame is not sketched under hand-drawn. The glyph is its own `<g>` after the frame; the hook should take the frame's `rect`/`circle` only.
