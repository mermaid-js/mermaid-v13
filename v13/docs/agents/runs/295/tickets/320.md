# #320 I1: resolver and body converter (D295)

Branch `feature/320_resolver`. Consumer: I2 #322 (the extension, providers, glyph slot).

## Exports (`@mermaid-js/plugin-icons`, private until I2)

- `getIcon(pack, name) → IconData | undefined`: `@iconify/utils` `getIconData` with defaults filled (16 × 16 at 0, 0; pack then icon then nearest alias wins; rotations summed mod 4, flips xor'd). Pack data is untrusted: own properties only, an icon needs a string `body` and an alias a string `parent` (else unresolved), non-finite offsets, non-positive sizes and non-integer rotations count as unset; alias chains over 64 count as broken.
- `iconBox(icon) → { viewBox, transform }`: `iconToSVG`'s box and one transform string (`rotate(…) translate(…) scale(…)`), undefined when the icon neither turns nor flips.
- `convertBody(body) → { nodes: SvgFragment[], simplified }`: linear scanner, no markup passed through. Keeps `g path rect circle ellipse line polyline polygon text` (+ `tspan` inside `text`). Drops every other element with its subtree. `style="…"` declarations become attributes (style wins). Values: geometry → numbers (written by core's `num`, 2 decimals), `d` verbatim after the path charset check, `points` → numbers (SVG number grammar: `1-1`, `.5.5`), `transform` rebuilt from checked functions, paint/opacity/stroke/font through core `checkStyle`/`checkColor`, `fill-rule`/`clip-rule`/`text-anchor`/`dominant-baseline` by keyword. `id`, `class`, events and unknown attributes dropped. `display="none"` drops the element. Entities decode with core's `entityAt` (now exported from `@mermaid-js/core/text`, one line).
- `buildIcon(icon) → { viewBox, nodes, simplified }`: the two above, nodes wrapped in `<g transform>` when needed. I2 places it (nested `<svg viewBox>` or scale+translate) and warns `ICON_SIMPLIFIED` when `simplified`.
- Core (additive): `fill-rule`, `clip-rule` in the allow-list (`allowlist.ts`, `AttrTypes`: `'nonzero' | 'evenodd'`; `inert.ts` checks the keyword).

## Tests and helpers

- `resolve.spec.ts` (aliases, loops, prototype names, transforms), `body.spec.ts` (keeps, drops), `parity.spec.ts` (every icon and alias of `fa6-solid`, `mdi`, `logos` and a built pack covering rotate −1…5 × flips × offset boxes × two alias levels: data equal to `getIconData`, viewBox and wrapped body equal to `iconToSVG`), `icon.spec.ts` (every pack icon `assertInert`; unsimplified icons keep every shape), `security.spec.ts` (core `PAYLOADS` + `V12_XSS_CASES` + 36 SVG attacks in 12 positions: inert, kept tags only).
- `src/markup.fixtures.ts` `markup(nodes, viewBox?)`: writes fragments through core's stream writer (excluded from the build).
- Dev deps for parity only: `@iconify/utils` 3.1.7 (v12's), `@iconify-json/{fa6-solid,mdi,logos}`.

## Decisions (not in D295)

- `simplified` also covers dropped drawing elements (`defs`, `mask`, `use`, `image`, unknown) and dropped references (`clip-path`, `mask`, `filter`, `marker-*`) and every rejected value of a drawing attribute (`d`, `points`, `transform`, `x`/`y` lists, sizes, paints), and a body cut short inside a tag, comment or CDATA, not only `url()` paints; `title`/`desc`/`metadata`/comments are silent. logos: 469 of 2,282 icons simplified (465 use `url(#…)`); fa6-solid and mdi: none.
- `tspan` is kept inside `text` (allow-listed already; v12's `unknownIcon` uses it).
- Package is `"private": true` with no manifest; I2 adds the manifest, drops `private`, adds a changeset, and adds `@iconify/utils` to `UPSTREAMS` in `tools/release/src/licenses.ts` (marker `https://github.com/iconify/iconify`, holder `Vjacheslav Trushkin`). `THIRD_PARTY_NOTICES` already lists `src/resolve.ts`. Note the tool also asks for Pele's line in any notices with a derived file; I2 either adjusts that rule or adds it.
- Nesting past 32 levels is dropped; past 256 open elements the rest of the body is dropped (linear scan).
