# #322 I2: `@mermaid-js/plugin-icons` (the extension)

Branch `feature/322_package`. Consumers: I3 #324 (label fixtures), I4 #326 (flowchart icon shapes), I5 #328 (mindmap), I6 #330.

## Exports

- `icons` (also default), an `ExtensionPlugin`: `claims: ['icons']`, one pattern provider (D296 regex), `glyphs`, `resources` (`provides: []`, `missing` reports `{ kind: 'iconPack', name }` per pack a diagram names that is `pending` or `failed`; SVG only). Types `IconifyJSON`, `IconifyIcon`, `IconifyAlias` (core's). Published (no `private`), manifest `{"plugin":"extension","id":"icons","entry":"./dist/index.js","export":"icons"}`. I1's `getIcon`/`buildIcon`/`convertBody` are internal now.
- Use: `await mermaid.registerExternalDiagrams([icons]); mermaid.registerIconPacks([{ name: 'fa', icons }])`, then `render()`, or `prepare()` before `renderSync`.
- Label icon: box `size·w/h × size`, baseline `0.875·size` (size = label font size), node `<g transform="[translate(…)] scale(s)">`. `currentColor` fills are left off where nothing above them in the icon sets a fill, so they inherit the label's fill (its text colour, as v12's `.label-icon path`).
- Glyph: `iconName(name, fallbackPrefix)` (port of `stringToIcon`: `prefix:name`, `@provider:prefix:name`, `prefix-name`, a simple name only with a fallback), fitted xMidYMid meet into the square, numbers to 1e-6. Keeps `currentColor`: the diagram sets `color` (I4).
- Pending pack the last `missing()` reported (placeholders): empty 1em box in labels, `undefined` for glyphs (frame only); the API warns `PLACEHOLDER`. A pending pack it did not report is unresolved ("has not loaded: call prepare() first").
- `ICON_NOT_RENDERED`: one per render, naming each unresolved icon of the diagram (labels, then glyph names, up to 8) with why: no pack registered, pack failed (`error()` cut to 60), not Iconify JSON (`get()` checked: object with an `icons` object), no such icon. `ICON_SIMPLIFIED`: one per render naming the simplified icons.

## Tests and helpers

## Sizes

## Decisions

- Names in `ICON_NOT_RENDERED`/`ICON_SIMPLIFIED`: the deduper keeps the first message per code, so the first icon met lists the diagram's others, from what the last `missing()` saw (per packs object). A glyph name with no pack is named only when met (a fallback may resolve it).
- Label colour: `currentColor` fills inherit the label fill; a `currentColor` stroke stays (the page's CSS colour), since SVG cannot point a stroke at the label fill.
- Glyph names split as v12's `stringToIcon` (dash form too), not only `prefix:name`.
- `tools/release/licenses.ts`: `@iconify/utils` in `UPSTREAMS`; Pele's text is not required when every ported file comes from another upstream.
- Pending packs that `missing()` did not report are unresolved, not placeholders (as math's `reported`).

## Unmet

None of #322's criteria. Label icons with `currentColor` strokes (lucide-style packs) draw in the CSS colour, not the label's; flowchart still warns `ICON_UNAVAILABLE` beside `ICON_NOT_RENDERED` for an unresolved shape icon (I4, D299 alias).
