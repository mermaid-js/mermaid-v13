# Ticket 9: measurers (branch feature/9_m1 @ 8b34fe04d)
**`@mermaid-js/core/text`** (DOM-free):
- Types: `Measurer { width(text, font, style): number; metrics(font): VerticalMetrics; readonly id }`, `FontKey { family, size, weight }` (family = CSS stack string), `StyleBits = number`, `VerticalMetrics { ascent, descent, lineHeight }` (px).
- `Style` = `{ Bold: 1, Italic: 2, Mono: 4, Sub: 8, Sup: 16, Underline: 32 } as const` (no enum). `SMALLER = 1.2` (sub/sup size divisor).
- `tableMeasurer` (id `'table'`): first family in the stack with a table wins (`trebuchet ms`, `verdana`, `arial`), unknown -> Arial. Bold table when `Style.Bold` or `weight >= 600`. Wide chars (CJK, Hangul, fullwidth, astral/emoji) = 1 em; combining marks, ZWSP/ZWJ/bidi marks, SHY, BOM, variation selectors, C0/C1 controls = 0; other non-Latin-1 = the face's mean a–z advance. Mono = 0.6 em (wide 1.2 em). Italic/Underline don't change widths. `metrics()` from hhea: lineHeight = ascent + descent + lineGap.
- `DEFAULT_FONT_FAMILY = '"trebuchet ms", verdana, arial, sans-serif'`; `resolveFontFamily(fontFamily?, cssVariable?)`: `--mermaid-fontFamily` value first (it is what the SVG draws with), then config, then default; trims and drops trailing `;` (v12's schema default has one). `familyNames(stack)` parses a stack.
- Generated tables: `packages/core/src/text/metrics.ts` (`FACES`), 1.4 KB gz. Measurer + tables minified ≈ 2.1 KB gz, so label layout (#10) has ≈ 3.9 KB of the 6 KB budget.

**`packages/mermaid/src/measurer.ts`** (not exported from the mermaid index; #15 should import it):
- `selectMeasurer({ measurer?, deterministic? })`: integrator measurer (used even with `deterministic`) > `tableMeasurer` when deterministic > shared `canvasMeasurer()` (one module-level instance, cache shared across renders) > `tableMeasurer`.
- `canvasMeasurer()` (id `'canvas'`, null without canvas): font string `[italic ]<bold|weight> <size>px <family|monospace>`, LRU 20k per CSS font, no caching while `document.fonts.check` is false, all caches dropped when `document.fonts.size` changes. `metrics()` uses `fontBoundingBoxAscent/Descent` (lineHeight = sum, no line gap), falls back to the table.
- DOM reading of `--mermaid-fontFamily` (getComputedStyle) is left to the DOM adapter (#16); pass the value to `resolveFontFamily`.

**gen-metrics:** `pnpm --filter @mermaid-js/gen-metrics generate [fontDir]` (default `/System/Library/Fonts/Supplemental`). `tools/gen-metrics/src/{font,generate,sources,cli}.ts`. The freshness spec is skipped where the fonts are missing (Linux CI). A size spec caps the tables at 1.5 KB gz.

**Tests:** `packages/core/src/text/measurer.spec.ts` (known font advance literals), `packages/mermaid/src/measurer.spec.ts` (`FakeBrowser` stubs `OffscreenCanvas` + `document.fonts` with `vi.stubGlobal`; reload the module with `vi.resetModules()` per test because of the shared instance), `tools/gen-metrics/src/*.spec.ts`.
