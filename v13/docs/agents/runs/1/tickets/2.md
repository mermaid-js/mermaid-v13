# Ticket 2: scaffolding (branch feature/2_scaffolding)
**Layout.** `packages/{core,diagram-flowchart,mermaid,plugin-interactions}` are published. `packages/{conformance,bench}` and `tools/{gen-metrics,gen-config,gen-grammar}` are private. Every module is an empty `export {}`.
- `@mermaid-js/core` exports `.`, `./parser-kit`, `./layout`, `./svg`, `./text`, `./theme`, `./config`, each mapping to `src/<sub>/index.ts`.
- `mermaid` is versioned 13.0.0-alpha.0. The other packages are 0.0.0.
- diagram-* and plugin-* take core as a `peerDependency` plus a devDependency (`workspace:^`). They never list it under `dependencies`. mermaid lists core and diagram-flowchart under `dependencies`.
- conformance has `"mermaid-v12": "npm:mermaid@^12.2.0"` as a devDep, so use `import ... from 'mermaid-v12'`. The plain name `mermaid` is the workspace v13 package.
**Exports and resolution.** Each export entry is `{ "mermaid-source": "./src/x.ts", types: "./dist/x.d.ts", default: "./dist/x.js" }`.
- tsc (`customConditions`) and vitest (`resolve.conditions`) resolve the TS sources, so no build is needed before tests or typecheck.
- `tsconfig.build.json` clears the condition and emits `dist/`.
- Use relative imports with a `.ts` extension. `rewriteRelativeImportExtensions` is on.
**tsconfig.** The root `tsconfig.json` is the base: strict, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`, lib ES2022, `types: []`. That means core and diagram packages have no DOM and no node types. `packages/mermaid` and `plugin-interactions` add the DOM lib. Private packages add `types: ["node"]`. `tools/tsconfig.json` covers tools/eslint-plugin, check-deps and workspace.
**Commands (all fast, `pnpm check` is about 4s).**
- `pnpm lint`: eslint + prettier + cspell. eslint is the non-type-aware typescript-eslint config, on purpose for speed.
- `pnpm typecheck`: tools tsc, then `pnpm -r typecheck`.
- `pnpm test`: `vitest run` with the root `vitest.config.ts`. Includes `packages/*/src/**/*.spec.ts` and `tools/**/*.spec.ts`. Node environment, no DOM shim.
- `pnpm check:deps`: R-PERF-2 dependency check.
- `pnpm build`: `pnpm -r` tsc into `dist/`.
- `pnpm check`: lint, typecheck, deps and test together. Don't call it `pnpm ci`; that is a pnpm builtin.
**Lint rules.** `eslint.config.js` plus the local plugin `tools/eslint-plugin/index.js`.
- `mermaid/import-boundaries` applies to `packages/*/src`:
  - core imports nothing.
  - diagram-* imports only `@mermaid-js/core[/*]`.
  - mermaid imports only core and diagram-*.
  - Relative imports may not leave their package.
  - `*.spec.ts` files may also import `vitest` and `node:*`.
  - plugin-*, conformance and bench are unrestricted for now.
- `mermaid/no-nested-quantifier` applies to `packages/*/src`. It flags a variable quantifier inside a quantifier with max > 1, so `(?:x{3})+` is OK.
- core and diagram-* only: `no-restricted-globals` (every browser-only global, plus `navigator` and `globalThis`), `no-console`, and `mermaid/no-global-config` (calls to getConfig, getSiteConfig, setConfig and similar).
- Everywhere: no TS enums, `consistent-type-imports`, `no-only-tests`.
- Proof is in `tools/eslint-plugin/rules.spec.ts`. It lints `tools/eslint-plugin/fixtures/*.ts` as if they lived at a workspace path. To add a rule, add a fixture and a table row there.
**Adding a package.** Copy `packages/diagram-flowchart`: package.json, tsconfig.json, tsconfig.build.json. Name it `@mermaid-js/diagram-<type>`. Keep `dependencies` empty, or check:deps fails. Then run `pnpm install`. Tests go next to the source as `src/**/*.spec.ts`, importing `vitest` explicitly (no globals).
**CI.** `.github/workflows/ci.yml` runs lint, typecheck, unit tests, check:deps and build, plus a placeholder smoke-render matrix (node20, deno, worker, chromium, firefox, webkit) that only echoes for now. Ticket 14/15 should fill it in. I deleted the v12 workflows that ran builds, e2e and releases.
**e2e.** `e2e/` (2376 `.mmd` fixtures, helpers, specs) and `playwright.config.ts` are kept as they were, but they are parked: excluded from eslint, prettier, tsc and vitest. Their v12-only deps (applitools, argos, monocart, js-yaml, globby) and the `pnpm dev` server are gone. Ticket 17 has to re-add them.
