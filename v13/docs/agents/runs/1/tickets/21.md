# Ticket 21: flowchart grammar + gen-grammar + differential (branch feature/21_m1 @ 5d508e540)
**Grammar file** `packages/diagram-flowchart/grammar/flowchart.ebnf` (normative, R-PARSE-9). Format documented in `tools/gen-grammar/src/ebnf.ts` header:
- `@lexer`: `@modes …;` then ordered rules `<modes> NAME /re/ actions :scope ;` (`-` = no token; actions `push(m) pop push-once(m) empty fold attach-next attach-prev`). jison semantics: first match in file order, one last try at end of input.
- `@trivia`: comment/directive rules for highlighters only (preprocess layer). `@grammar`: EBNF (`[ ] { } ( ) | ? * +`); `name @Type = …` builds an AST node; first rule = start.
- Lexer input = the text v12 handed its lexer (header comment lists the rewrites). Built dev-only by `packages/conformance/src/flowchart/grammar/lexer-input.ts` with v12's own regexes, position-mapped (`MappedText`).
**`@mermaid-js/gen-grammar`** (private, `tools/gen-grammar/src/index.ts`): `parseGrammar(text) → Grammar`; `buildLexer(g).lex(text) → {tokens: LexToken{name,text,start,end,outerStart,outerEnd}[], error}`; `buildParser(g).parse(names) → ParseNode | undefined` (Earley); `astOf(tree) → AstShape[]`; sentence generator `emptyModel/learnDerivation/learnToken/buildGenerator(parser, model).generate({seed,maxDepth,maxTokens})`; `textMate/monarch/lezerGrammar/lezerTokens/syntaxDoc`; `generate(read)` / `GRAMMARS` (add a diagram type here when it gets a grammar); `mapped/replaceMapped/sliceMapped/appendMapped/sourceRange`.
- Commands: `pnpm gen:grammar`, `pnpm check:grammar` (in `pnpm check` and CI). Outputs: `packages/diagram-flowchart/grammar/generated/{flowchart.tmLanguage.json, flowchart.monarch.json, flowchart.grammar, flowchart.tokens.js}` (force-tracked: `generated/` is gitignored) and `v13/docs/syntax/flowchart.md`.

**Findings / known gaps:**
- Grammar fact found by the differential: after shape data, blanks must lead to `&` (v12 LALR quirk); grammar matches oracle, hand-written already did.
- Hand-written: a semantic error (LINK_STYLE_INDEX, SHAPE_DATA YAML) stops its statement before the separator, so a syntax error after it in the same statement is not reported. Differential skips accept/reject for those (both reject anyway).
- YAML: core `parseYaml` accepts shape data js-yaml rejects (e.g. `label:  shape: stadium, label: "database""""event`); v12 rejects, v13 accepts. Not syntax; for #5/#17 (fuzz/limits).
- Highlighters are line-based approximations (mode closed by a line break closes at EOL; `push-once` pushes every time). Monarch is checked with a mini interpreter, not monaco. LSP/editor adapters are R-LANG-2 (M2.5).
- AST comparison covers types/nesting/ranges, not names/labels (model parity covers those).
