# Ticket 10: label layout (branch feature/10_m1 @ 3d38c4164)
**`@mermaid-js/core/text`** (`packages/core/src/text/label.ts`, `entities.ts`):
- `layoutLabel(raw, font: FontKey, maxWidth, measurer, { markdown?, style? }?) → MeasuredLabel`. `maxWidth = Infinity` means break only at explicit breaks. `markdown: true` for v12 `labelType: 'markdown'` text (backticks/quotes already stripped by the parser). `style` = base StyleBits (e.g. from classDef font-style).
- `MeasuredLabel extends LabelBox` (the #12 writer type, re-exported from core/text along with `LabelSpan`): `lines: Run[][]`, `indents[]`, `widths[]` (indent included), `width`, `height = lines*lineHeight`, `lineHeight` and `baseline` from `measurer.metrics(font)` (no gap invented), `left?: true` when the label has bullets.
- `Run extends LabelSpan`: `{ text, style, width, bold?, italic?, attrs? }`. Inline code sets `style & Style.Mono` and `attrs['font-family'] = 'monospace'` (the table measures Mono at 0.6 em). Pass the result straight to `writer.label(box, cx, cy, attrs)`.
- **Writer change (additive, in #12's `svg/writer.ts`)**: `LabelBox` gained optional `left`, `width`, `indents`. With `left`, lines are `text-anchor="start"` at `cx - width/2 + indents[i]`; without it output is unchanged.
**Behaviour.**
- Fast path: no `< & * _ \` \\ \n \r \t SHY ZWSP` and no double space (and, in markdown, no leading `- `) → measured once; wraps only if it overflows.
- Plain: breaks at `\n`, the two chars `\n`, CRLF, `<br\s*/?>`. Empty lines kept. Spaces collapse as in SVG. `*`, `_`, backtick, `- ` stay literal.
- Markdown: `<br>`/newline break, blank lines dropped, common indent removed; `**`/`__` bold, `*`/`_` italic (no intra-word `_`, needs a closer), `` `code` ``, backslash escapes. Emphasis is per line; HTML tags stay open across lines.
- Bullets: markdown line `- x`/`* x`; nested (◦) when indented more than the last top-level item; top-level •. Nested indent = width of `• `; hanging indent = bullet + space width.
- HTML: b/strong → Bold, i/em → Italic (nesting counted); other HTML element tags dropped, text kept; anything else literal. Entities: ~45 named + numeric; unknown stay literal.
- Wrap: greedy at spaces; CJK per character with kinsoku (Pele's piece regex); ZWSP break (dropped from output); SHY break shows `-` only at a break; a word wider than the box is split at characters (surrogates, ZWJ sequences and zero-width marks kept together), so `width <= maxWidth` always.
**Size:** layoutLabel + entities, minified ≈ 3.15 KB gz (incl. Style), inside the ≈ 3.9 KB left.
**Tests:** `packages/core/src/text/label.spec.ts` (Arial 10px table widths), `svg/writer.spec.ts` (left-aligned label), `packages/conformance/src/labels.spec.ts`: all node/edge/subgraph labels of `e2e/diagrams/flowchart` from the v12 **oracle** (no parser needed): no overflow at default font/200px; markdown labels without bullets match v12's own `markdownToLines` (imported from the mermaid@12 core chunk that exports it, found by scanning); plain labels match the text v12's HTML shows.
**O-5:** the e2e flowchart corpus uses only `<br>` and `<strong>` (plus `<img>`, which draws nothing). No sub/sup/u/a. List left as in the ticket.
