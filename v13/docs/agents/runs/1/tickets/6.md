# Ticket 6: parser kit (branch feature/6_m1)
All from `@mermaid-js/core/parser-kit` (`packages/core/src/parser-kit/index.ts`). No module state: create helpers per parse.
**Reference example: `parser-kit/tiny-grammar.spec.ts`**, a complete lexer + recursive-descent parser on the kit. Copy its shape.
**Tokens.** `Kind` = shared kinds `{EOF:0, Newline:1, Comment:2, Directive:3, Space:4, Error:5}`. Diagram kinds start at
`FIRST_DIAGRAM_KIND` (16): `const T = { Id: FIRST_DIAGRAM_KIND, … } as const`. `TokenWriter`: `push(kind,start,end,text)`,
`finish(srcLength)` → `TokenStream {kind:Uint16Array,start/end:Uint32Array,text:string[],length}`; always ends in one EOF.
Lexers emit `Newline` for `\r\n`/`\n`/`\r` (one token) and `Comment`/`Directive` as trivia; never rewrite the source.
**Chars.** `charTable([flag,'chars'],…)` → `Uint8Array(128)`; `hasClass(table,code,flags)`. `isSpace isBlank isLineEnd
isDigit isLetter isHex isWord`. `isUnicodeLetter(code)` = v12 flow.jison `UNICODE_TEXT` (identical to the reference implementation's table).
Table is `unicode-table.ts`, generated: `tools/gen-grammar/src/gen-unicode.ts <flow.jison> <out>` (usage in file header).
**Scanner.** `matchAt(re,src,at)` → end or -1; `execAt` → match; both require `/y` (throw TypeError otherwise).
`scanWhile(src,at,pred)`, `lineEnd(src,at)` (index of next \n/\r), `newlineAt(src,at)` → 0|1|2.
**Positions.** `Range {start,end}` = original offsets everywhere. `new LineIndex(src)`: `position(off)` → 0-based
`{line,column}`, `offset(line,col)`, `lineCount`. Use for MermaidError line/column and front-matter offsets (#5).
**Parsing.** `new TokenCursor(stream, trivia = TRIVIA)` skips Comment/Directive/Space (not Newline): `kind text start end
range pos`, `peek() next() at(k) eat(k)`. `kindSet(...kinds)` / `inKindSet`. `syncTo(cursor, kindSet(Kind.Newline, T.Semi))`
skips to the boundary without consuming it, returns the skipped Range (R-PARSE-4: report, sync, continue).
**Diagnostics.** `Diagnostic {severity:'error'|'warning'|'info', code, message, range, expected?, related?: {message,range}[]}`.
`new Diagnostics()`: `.error/.warning/.add(…, extra?)`, `.unexpected(code, range, names, found)` → "Expected a, b or c,
got X." with `expected` set; `.list`, `.hasErrors`. For unclosed constructs pass `related: [{message, range: opener}]` (#5 fence).
`new ExpectedTable([['an arrow such as `-->`',[T.Arrow,…]], …])`: `.names(kinds)` (≤5, table order), `.name(kind)` for "got".
**AST ids.** `AstId` = string; `AstNode<T> {id,type,range,children?}` — extend per node kind (`FlowNodeStmt extends AstNode<'Node'>`).
`new AstIds()`: `node(n)` `n:A`,`n:A@2`; `edge(a,b)` `e:A>B`,`e:A>B#2`; `subgraph(id)` `s:id`(`@2` on reopen); `statement(kind)`
`<kind>:<n>` 1-based per kind document-wide (flowchart: pass `'st'` or a kind name — #8 decides). `%>@#` in names percent-encoded.
**Result.** `new ParseState()` holds `diagnostics, symbols, statements, ids`. `symbol(name,kind,range,'def'|'ref')`,
`statement(kind,range)`, `beginStatement(kind,start)`/`endStatement(span,end)` nest block children (subgraph folding),
`result(model, ast, tokens, {keepTokens})` → `ParseResult<M,A> {model,ast,diagnostics,symbols,statements,tokens?}`.
`ParseOptions {keepTokens?}`: map `config.internal.keepTokens` to it (config key not added here).
**Tests/guards.** Unit specs per block in `parser-kit/*.spec.ts`; `tools/workspace/parser-kit-state.spec.ts` fails on
top-level `let`/`var` or mutable-collection consts in parser-kit (TS AST check).
**Known gaps.** Size: 2.5 KB gz code + 0.7 KB Unicode table = 3.2 KB minified+gz vs the 2 KB estimate (no automated size gate;
measured with esbuild from the pnpm store). No snippet/caret formatter (R-ERR-2) and no MermaidError type: pipeline ticket.
Statement ordinal is per kind across the document, not per parent scope. Root AST id is the diagram's choice (tiny uses `doc`).
