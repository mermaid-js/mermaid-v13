# Ticket 8: flowchart lexer/parser/model (branch feature/8_m1 @ 74d4aa97b)
**Exports from `@mermaid-js/diagram-flowchart`** (`src/parser/*`):
- `parseFlowchart(text, { preprocessed?, maxEdges = 500, inheritDir = false, claims?, keepTokens? }) → ParseResult<FlowModel, FlowDocument>`. `text` is the WHOLE source (front matter included); every range is into it. Pass `preprocessed` (core `preprocess(text)`) from the pipeline; without it the parse runs preprocess itself and keeps its diagnostics. Never throws; reject = any `severity: 'error'` diagnostic.
- `flowchart` plugin object `{ id, aliases, detector, parse }` (`src/plugin.ts`); `detectFlowchart(text) → 'flowchart-v2' | 'flowchart-elk' | undefined`.
- `FlowModel { direction, vertices[], edges[], defaultInterpolate?, defaultStyle?, classes[], subgraphs[], tooltips: [id, text][], links[], callbacks[], accTitle, accDescr, warnings }` — arrays, insertion order, JSON-plain. Vertex/edge/subgraph field names = v12 FlowDB (`type` = v12 shape/bracket type: `square`, `round`, `cyl`…); each has `ast` (AstId). Text is as v12's parser read it: `#quot;` → `&quot;`, `="x"` in tags → `='x'`, CRLF → LF; NOT sanitised; `link` is the raw URL (check with core/svg `checkUrl` at render time).
- AST types `FlowDocument, FlowHeader, FlowChainStmt (Node+Edge children), FlowNodeStmt, FlowEdge, FlowSubgraph, FlowSimpleStmt`. Ids: `n:A`, `n:A@2`, `e:A>B`, `e:A>B#2`, `s:<id>`, `style:1`, `chain:3`, `header:1`. Renderer writes `ast` as `data-ast`.
- Symbols: kinds `node` (def = mention that creates the vertex), `class` (def = classDef), `subgraph`, `edge` (`id@`). Statements: `header, chain, style, classDef, class, linkStyle, click, direction, accTitle, accDescr, subgraph` (subgraph nests children).
- `flowchartTokens(src)`, `FlowTokenKind`, `JISON_NAMES` (dev/editor; lexer-parity gate).
- Warnings: `CALLBACK_IGNORED` (unless `claims` has `callbacks`), `STYLE_UNKNOWN_NODE`. Error codes: `UNEXPECTED`, `UNEXPECTED_CHARACTER`, `UNCLOSED`, `UNCLOSED_STRING`, `UNCLOSED_SUBGRAPH`, `UNEXPECTED_END`, `UNKNOWN_DIRECTION`, `ENTITY_OUTSIDE_LABEL`, `UNKNOWN_SHAPE`, `SHAPE_DATA`, `LINK_STYLE_INDEX`, `EDGE_LIMIT`.
