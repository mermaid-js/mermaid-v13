# Ticket 12: core/svg (branch feature/12_m1, worktree .claude/worktrees/t12)
**Import** everything from `@mermaid-js/core/svg` (source `packages/core/src/svg/`). Test fixtures from `@mermaid-js/core/svg/testing`.
**Writer** (`writer.ts`). Use `streamWriter()` by default. Use `treeWriter()` only when a postRender hook is registered: it has `.tree: SvgTree`, and `.finish()` serialises the edited tree.
- `SvgWriter`: `open(tag, attrs?)`, `close()`, `leaf(tag, attrs?)`, `text(s)` (only inside text/tspan/title/desc), `label(box, cx, cy, attrs?)`, `path()`. Both backings are byte-identical.
- An element with no children is written self-closed (`<g/>`), whether it came from `open`+`close` or from `leaf`. `text('')`, and text that escapes to nothing, is a no-op.
- Attrs are `Partial<Record<AllowedAttr, typed value>>` (`types.ts` `AttrTypes`). Key order is the output order, `undefined` is skipped, numbers go through `num()` (2 dp), NaN/Infinity throws RangeError. Unknown tag/attr throws TypeError, and so does `href` anywhere but a/image.
- `viewBox: [x,y,w,h]`, `points: [x0,y0,x1,y1,…]`, `d: w.path().moveTo().lineTo().curveTo().quadTo().arcTo().close().done()`, `transform: translate()/rotate()/scale()/transforms(...)`.
- `<a target="_blank">` always gets `rel="noopener noreferrer"`. It is replaced in place if given, or appended last. `SvgTree.setAttr` does the same.
**LabelBox** (writer.ts, my contract for #10/#14): `{ lines: LabelSpan[][], lineHeight, height, baseline }`. `baseline` is the distance from a line's top to its baseline, taken from measurer ascent; it is not size*0.35.
- `LabelSpan`: `{ text, bold?, italic?, underline?, strike?, attrs? }`.
- One plain span writes `<text … x y text-anchor="middle">t</text>`.
- Otherwise: `<text text-anchor="middle" xml:space="preserve">`, then one tspan per span. The first span of each line carries x/y. An empty line writes `" "`. Bold/italic come out as `font-weight="bold"`/`font-style="italic"`, so mono and theme fonts have to go through `span.attrs`.
**Branded values.** These are the only legal sources:
- `SafeUrl` from `checkUrl(url, {securityLevel?, linkSchemes?, warn?})`.
- `SafeColor` from `checkColor(s)`.
- `SafeLength` from `checkLength(s)` or `px(n)`.
- `ThemeRef` from `themeRef('--name', fallback?)`. The name must match `--[A-Za-z0-9_-]+`.
- `StyleText` from `styleText({prop|--custom: branded|number})`, for the root's `max-width` and alias declarations.
- `SafeValue` is what `checkStyle` emits.
- Paint is `SafeColor | ThemeRef | 'none' | 'currentColor' | 'transparent'`.
**Safety checks.**
- `resolveSecurityLevel(v, warn)` returns `'default'|'strict'`. loose/antiscript/sandbox/unknown map to default and emit `SECURITY_LEVEL`.
- `checkUrl` returns undefined plus `URL_REFUSED` when a URL is refused: a bad scheme on the raw, entity-decoded or percent-decoded form, `//host` or `\\host`, `<`/`>`, or empty. Strict allows relative URLs only.
- `checkLinkTarget(t, warn)` keeps `_self`/`_blank`/`_parent`/`_top`. Anything else is dropped with `LINK_TARGET_DROPPED`.
- `checkStyle(decls: string[], warn)` returns `{ shape: Attrs, text: Attrs }` as presentation attrs, ready to spread into `open/leaf`. `color` goes to text `fill`, and `opacity` goes to both. An unknown prop warns `STYLE_PROPERTY_DROPPED`; an unsafe value warns `STYLE_VALUE_DROPPED`. It takes the parser's split array, not a `;` string.
- Warnings are `{code, message}` via `Warn`. #14 should forward them to `ctx.warn`.
**assertInert** (`inert.ts`): `assertInert(svg, {securityLevel?, linkSchemes?})` throws; `inertProblem()` returns the reason string. The pipeline should run it on the output after postRender hooks.
- It rejects any `<style>`. #13's `theme:'auto'` needs an opt-in option for var-only `<style>`, which is not built yet.
**Testing exports.** `PAYLOADS` (Pele's hostile strings) and `V12_XSS_CASES` (`{id, source?, text?, urls?, styles?, values?}`). Run `source` through `render` + `assertInert` in #14.
