- Completion: `ishikawa`, `ishikawa-beta` where the header goes (case-insensitive prefix, after blank and comment lines); nothing in the body, comments, directives or front matter.

- Hover: keyword doc; a cause's depth, parent, side, sub-cause count and clamp; the effect's cause count.
- Folding: each cause's subtree (T2's nested spans). Rename: that label only; refuses a line break, a leading keyword or `%%`, edge blanks, and a name that does not read back.
