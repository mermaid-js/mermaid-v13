- `parseIshikawa(src, { preprocessed?, keepTokens? })` → `ParseResult<IshikawaModel, IshikawaDocument>`; never throws. - Codes (`src/codes.ts`): `ISHIKAWA_EMPTY` (no effect and no error, at the header), `ISHIKAWA_INDENT_CLAMPED` (one per parse, at the first cause indented less than the first cause, every such cause in `related`).
- AST (`src/parser/ast.ts`), flat in source order: `Effect` (`effect`) and `Cause` (`cause:<i>.<j>…`, 1-based tree position, D497), each with `text` and `indent`, a cause with `level`.
