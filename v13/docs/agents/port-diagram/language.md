# Language-service support for a ported type (R-LANG-3)

Every type ported after M2.5 ships a language facet that passes the shared golden suite (R-LANG-3, D89, D99). This is the checklist; flowchart is the worked example (`packages/diagram-flowchart/src/language.ts`, `packages/language-service/goldens/flowchart/`).

## Checklist

1. **Facet.** Export a `LanguageFacet` named `language` from the package's `./language` subpath (`src/language.ts`): `id`, `parse` (the parser-only entry, tokens kept on request), `isValidId(name, kind)` per symbol kind, `categories` (generated by gen-grammar, never hand-written) and `namespaces` (which symbol kinds share names: flowchart groups `node` and `subgraph`). The subpath loads the parser and tables only: copy the bundle check in `packages/bench/src/language-bundle.spec.ts`.
2. **Registry.** The manifest's `language` entry makes `gen:registry` give the type's `firstPartyFacets` row a `load`. From then on the suite requires its goldens.
3. **Parse output.** Symbols whose range is exactly the name (the service drops any other, so a quoted id gets no definition or rename), one statement span per statement with block children (folding), AST ranges (astAt), and N diagnostics for N errors (pitfall 8).
4. **Goldens.** Add `packages/language-service/goldens/<id>/<feature>/<case>.mmd` for every feature in `REQUIRED_FEATURES` (`src/testing/goldens.ts`): diagnostics, definition, references, rename, astAt, folding, semanticTokens (completion and hover join when they land). Mark cursors with `|` (a literal `|` is `\|`), set a rename target with `%% rename-to: X`. Cover every symbol kind and namespace, each block statement, an error-recovery case and a refused rename. Write the `.out` with `vitest run packages/language-service -u` and review every line: the first `-u` writes whatever the service says.
5. **Corpus properties.** `src/property.spec.ts` (every query at every token boundary of `e2e/diagrams/**`, no throw, in budget) and `src/rename-round-trip.spec.ts` (rename, re-parse, same model modulo the name) pick the type up from its corpus folder with no change. Add each finding to the spec's known list only with a GAPS.md entry and an owner.
6. **Oracle expectations.** Copy `packages/conformance/src/flowchart/service-symbols.spec.ts`: v12's model decides which names have one definition, which classes and groups exist, and which members sit inside which fold.
7. **Budget.** Report `pnpm --filter bench language`-style numbers for a 50k-character document of the type (R-LANG-4: update + every query ≤ 10 ms on the reference runner). Timing tests in PR CI assert ratios only (`packages/bench/src/language-budget.spec.ts`).

**Done when** `goldens.spec.ts` lists the type under "the port checklist" with no missing feature, the property and round-trip specs are green with no new known entry, and the oracle spec is green.

## Adding a feature (not a port)

A new query adds a method on `DocumentSnapshot` and a folder `goldens/<id>/<query>/`. The runner discovers it with no code change: a feature with no renderer in `FEATURES` runs through the snapshot method of the same name (per `|` marker when the fixture has any) and prints ranges as `l:c-l:c "text"`. Add a renderer only when that output reads badly, and add the feature to `REQUIRED_FEATURES` when every facet must support it.
