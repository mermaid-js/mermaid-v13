# Round 0 baseline review

Formal headless Node round 0 completed on 2026-11-10. This is a measurement baseline;
no optimization hypothesis was implemented, evaluated for fit, or delivered.
[REPORT.md](REPORT.md) and [RESULTS.json](RESULTS.json) are generated by the documented
report command. This review explains their scope and implications without changing the evidence.

## Completion and provenance

All 15 jobs have valid formal completion receipts: ten A/A blocks, Pelé, trailing-comment,
cache, diagnostics, and gates. Each timing comparison covers the same 5,000 records with
three warmups per side and seven alternating measured pairs. The fixed 500-index browser
subset was preserved. Eight invalid attempts remain in the scheduler journal and private
archives; none is included in the aggregates. Earlier P26 and failed acceptance evidence
remain preserved. Completed P26 blocks were not reused under P27.

The exact acceptance report is `.tmp/perf-validation-p27-20261110-02/acceptance.json`,
SHA-256 `bd6f316e636934f5f5046fde8f13ee1ad9c867794efab4d186d0bb32f9aeb2fb`.
It has `validationProfile: "node"`, `sourceStable: true`, and `ready: true`. Node 24.16.0,
pnpm 10.30.3, all 57 harness tests, `pnpm check` (895 files and 18,577 tests), security,
size budgets, and real-host acceptance passed. Formal workers used the pinned Node binary,
no runtime flags and unset `NODE_OPTIONS`.

The measurement environment follows Knut's P27 amendment: observed background load,
1,536 ms aggregate CPU per 1,000 ms interval, derived from the calibration p95 plus 20%.
The per-process field equals that total and adds no separate restriction. This is not an
idle-host result. The serial coordinator did no other work while the runner was active.

The report was regenerated from the same frozen inputs and all six generated files were
byte-identical. Workspace source fingerprint, sample/source hashes, browser subset, acceptance
and raw evidence hashes were verified. The private verification receipt is
`.tmp/perf-round-0-p27/publication-verification.json`. The complete frozen header and artifact
manifest are published beside this review; raw diagrams and process logs stay private.

## Timing interpretation

| Measurement | Result | Meaning |
| --- | ---: | --- |
| A/A spread | 2.46746% | Predeclared absolute log-distance estimator across ten whole-sample blocks |
| P12 speed-gain threshold | 7.40237% | max(0.5%, 3 × spread); fixed for subsequent candidate evaluation |
| Summed v13/Pelé time | 1.46038 | v13 takes 46.04% longer; P2 target of 0.95 is unmet |
| Summed median v13 time in Pelé comparison | 3.794495 s | Sum of 5,000 per-record medians, not benchmark wall time |
| Summed median Pelé time | 2.598290 s | Same aggregation and sample |
| Pelé/v13 per-record geomean | 0.614884 | Distinct from the ratio of summed times |
| Trailing-comment/reset-hook geomean | 1.025683 | 2.57% higher time in this diagnostic comparison |
| Cache-on/cache-off geomean | 0.776007 | 22.40% lower time with existing cache retained between repeated renders |

All ten A/A head/base geomeans are below 1 (0.97592–0.98291), although both sides use
identical renderer artifacts. That is a directional measurement imbalance, not a speedup.
Its cause has not been established. The predeclared absolute-distance spread includes it;
do not subtract it, lower the threshold, or claim small improvements from these comparisons.
The trailing-comment difference is close to this noise scale and is diagnostic evidence,
not proof of a candidate optimization.

The cache comparison measures warmed repeated rendering of the existing cache. Knut clarified
in P28 that production caching must remain unchanged; only the benchmark must avoid cache
hits. Round 0 already clears caches before timing, so it measures the intended uncached path.
The previously proposed one-slot replacement and production-removal hypothesis 3a are withdrawn.
There is no P18/P12 exception or delivery decision pending.

Size buckets contain 1,426 tiny, 3,088 small, 459 medium and 27 large records. Their individual
ratios are in RESULTS.json. The small large-diagram population limits how broadly its result
can be interpreted; neither bucket boundaries nor membership were changed.

## Scope and stopping point

Node A/A byte and protected-surface gates passed for all 5,000 records. Browser validation,
pixel equality on the 500-index subset, and e2e remain **pending/unverified**. This report
establishes neither browser performance nor output-lane candidate acceptance. The sample
covers the common renderable population selected during preparation, not the entire corpus.

Round 1 has not started. Review this baseline with Knut before implementing or measuring any
optimization hypothesis. P28 resolves the former P18/P12 question. Existing hypotheses remain proposals, and the
round-0 hypothesis ledger is empty.
