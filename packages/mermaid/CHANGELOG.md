# mermaid

## 13.0.0-alpha.4

### Minor Changes

- [#1046](https://github.com/mermaid-js/mermaid-v13/pull/1046) [`1150d57`](https://github.com/mermaid-js/mermaid-v13/commit/1150d57673281d14c490c08f4750517ee4443e3f) Thanks [@knsv-bot](https://github.com/knsv-bot)! - feat: `initialize({ fontTables })` adds font tables to the table measurer, which measures Node and worker renders and every render under `deterministic: true`. A brand font is then measured as itself, not as Arial, and `deterministic: true` keeps it. The tables load in a chunk of their own with the first `prepare()`, `render()` or `preload()`, which rejects with `MermaidError { code: 'SEMANTIC' }` for a malformed table; `renderSync` before that throws `NOT_LOADED`. `@mermaid-js/core/text/font-tables` exports `createTableMeasurer({ faces })` for the same tables.
