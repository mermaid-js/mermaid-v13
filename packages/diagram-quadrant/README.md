# @mermaid-js/diagram-quadrant (v13 alpha)

The quadrant chart plugin for Mermaid v13: the `QuadrantModel` contract and the layout, a port of v12's `quadrantBuilder.ts` (spec #289). The parser, renderer and registry manifest land in later tickets; until then the package registers nothing.

> [!WARNING]
> Alpha: APIs can change between builds. Pin an exact version.
