# @mermaid-js/core (v13 alpha)

The DOM-free engine of Mermaid v13: the plugin contract, parser kit, text measurement, layout, SVG writer, theme and config. It has no runtime dependencies.

You don't use this package directly. Install [`mermaid`](https://www.npmjs.com/package/mermaid) for every diagram type, or use `mermaid/slim` with the `@mermaid-js/diagram-*` packages you need. Each package has its own alpha version, and `mermaid` pins the exact versions it was released with.

> [!WARNING]
> Alpha: APIs can change between builds. Pin an exact version.
