## 13.0.0-alpha.1

### Patch Changes

- [#255](https://github.com/mermaid-js/mermaid-v13/pull/255) [`aac2097`](https://github.com/mermaid-js/mermaid-v13/commit/aac2097c19d3b1517e8aa701003cd8f8397e4f8c) Thanks [@knsv-bot](https://github.com/knsv-bot)! - feat: first release of `@mermaid-js/plugin-math`. Register it with `mermaid.registerExternalDiagrams([math])` and TeX between `$$` delimiters in flowchart labels is typeset by MathJax into SVG paths. MathJax is loaded only by `prepare()`/`render()` for a diagram with math; `renderSync` before then throws `NotLoadedError` naming `math "tex"`, or draws the TeX as written with a `PLACEHOLDER` warning when placeholders are asked for, and `preload({ math: true })` loads it up front. TeX that does not parse is shown as written with a `MATH_ERROR` warning. Core: extension plugins can declare `resources` that `prepare()` loads, and inline providers get a `warn` sink.
