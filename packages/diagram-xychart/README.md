# @mermaid-js/diagram-xychart (v13 alpha)

The XY chart plugin for Mermaid v13, for `xychart` and `xychart-beta`. So far it holds the lexer, gated against Mermaid 12's jison lexer; the parser, model, layout and SVG renderer follow.

> [!WARNING]
> Alpha: APIs can change between builds. Pin an exact version.
