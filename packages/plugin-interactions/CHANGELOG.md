## 13.0.0-alpha.4

### Patch Changes

- [#1122](https://github.com/mermaid-js/mermaid-v13/pull/1122) [`b4e7a70`](https://github.com/mermaid-js/mermaid-v13/commit/b4e7a707c08d7ee54292d1165b7602eac6ec65de) Thanks [@knsv-bot](https://github.com/knsv-bot)! - refactor: `@mermaid-js/core/parser-kit` exports `callbackArgs`, which class diagrams and the interactions plugin now share. `@mermaid-js/diagram-class` no longer exports the `ClassWarning` type and `@mermaid-js/diagram-requirement` no longer exports `RequirementLayoutWarning`: use `Warning` from `@mermaid-js/core`, which has every field they had. - [#1117](https://github.com/mermaid-js/mermaid-v13/pull/1117) [`f5f5226`](https://github.com/mermaid-js/mermaid-v13/commit/f5f5226ced06cc7cd62dc8ece2618513f92eca24) Thanks [@knsv-bot](https://github.com/knsv-bot)! - refactor: kanban and mindmap share their class names and token tables, mindmap asks core for placeholder icons, and `@mermaid-js/diagram-xychart` no longer re-exports `tokenValue` and `V12Text` of `@mermaid-js/shared` from its root (`tokenValue` is in `./testing`); output is unchanged.

- [#1132](https://github.com/mermaid-js/mermaid-v13/pull/1132) [`ade9f95`](https://github.com/mermaid-js/mermaid-v13/commit/ade9f95d7ba97fadc1306c3da0b19812a80212d3) Thanks [@ashishjain0512](https://github.com/ashishjain0512)! - fix: click callbacks and menus bind on a page holding several diagrams even when an element id contains a tab or a line break, and the CodeMirror highlighter recognises a diagram whose first line ends in a `%%` comment, as the language service already did.

- [#686](https://github.com/mermaid-js/mermaid-v13/pull/686) [`0ef50dc`](https://github.com/mermaid-js/mermaid-v13/commit/0ef50dc23dbaa9ef734270d1de431d126f76b7ec) Thanks [@knsv-bot](https://github.com/knsv-bot)! - feat: embedded diagrams. A flowchart or state diagram can hold a whole diagram of any type in a `mermaid <id>["Title"] { … }` block, drawn as one node that edges connect to. Blocks nest up to four levels, fold with `id@{ view: collapsed }` (a folded block is not parsed or loaded), render in text output, and get errors and highlighting in the language service. See `v13/docs/embedded-diagrams.md` and ADR-15.

- [#716](https://github.com/mermaid-js/mermaid-v13/pull/716) [`95d01d1`](https://github.com/mermaid-js/mermaid-v13/commit/95d01d19c663bdf6ea561cff8bb4da80f55cbc39) Thanks [@knsv-bot](https://github.com/knsv-bot)! - fix: click callbacks (`click A call fn()`, `click A callback`, class `callback A "fn"`, gantt `click a call fn()`) now run only with `initialize({ securityLevel: 'loose' })`, as in Mermaid v12. Under any other level the plugin binds no callback and the render adds one `CALLBACK_IGNORED` warning. Links, tooltips and actor menus are unchanged. If you use callbacks, set `securityLevel: 'loose'` next to registering the plugin.
